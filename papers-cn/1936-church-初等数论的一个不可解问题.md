# 初等数论的一个不可解问题 [^1]

**An Unsolvable Problem of Elementary Number Theory**

> 作者:阿隆佐·丘奇(Alonzo Church)〔译注1〕,普林斯顿大学
> 原载 *American Journal of Mathematics*, Vol. 58, No. 2(1936 年 4 月),pp. 345–363
> 译自 JSTOR 扫描件 `papers/ An Unsolvable Problem of Elementary Number Theory-Alonzo Church.pdf`(个人学习用途)

## 1. 引言

有一类初等数论问题,可以表述为如下形式:要求找出一个 n 元正整数**有效可计算函数(effectively calculable function)** `f`,使得 `f$x₁, x₂, …, xₙ$ = 2` 成为某个以 `x₁, x₂, …, xₙ` 为自由变元的初等数论命题为真的充要条件。[^2]

这类问题的一个例子是:找出一种方法,对任意给定的正整数 n 判定是否存在正整数 x、y、z 使得 `xⁿ + yⁿ = zⁿ`。因为这可以解释为:要求找出一个有效可计算函数 `f`,使得 `f$n$` 等于 2 当且仅当存在正整数 x、y、z 使得 `xⁿ + yⁿ = zⁿ`。显然,"函数 f 是有效可计算的"这一条件是问题不可或缺的部分,因为没有它问题就变得平凡了。

这类问题的另一个例子是拓扑学中的问题:找出闭三维单纯流形在同胚意义下的完整有效可计算不变量组。鉴于拓扑复形可以用关联矩阵表示,这个问题可以解释为一个初等数论问题。事实上,众所周知,一个关联矩阵组表示一个闭三维流形这一性质,以及两个关联矩阵组表示同胚复形这一性质,都可以纯粹用数论术语来描述。如果我们以某种直接的方式枚举那些表示闭三维流形的关联矩阵组,那么立刻可以证明,所考虑的问题(找出闭三维流形的完整有效可计算不变量组)等价于如下问题:找出一个正整数有效可计算函数 `f`,使得 `f$m, n$` 等于 2 当且仅当枚举中第 m 个和第 n 个关联矩阵组表示同胚复形。其他例子读者很容易想到。

本文的目的是提出一个有效可计算性的定义,它被认为能令人满意地与这类问题通常赖以表述的那种相当模糊的直观概念相符,并通过一个例子证明:并非这类问题中的每一个都是可解的。〔译注2〕

## 2. 变换与 λ-可定义性

我们选取一个特定的符号表,由符号 `{`、`}`、`(`、`)`、`λ`、`[`、`]` 以及一个可数无穷的符号集 `a, b, c, …`(称为**变元(variables)**)组成。〔译注3〕我们定义"公式"一词指由这个符号表中的符号构成的任何有限序列。术语**良构公式(well-formed formula)**、**自由变元(free variable)**与**约束变元(bound variable)**随后按归纳定义如下。单独一个变元 `x` 是良构公式,并且其中 `x` 的出现是 `x` 作为自由变元的出现;若公式 `F` 与 `X` 是良构的,则 `{F}$X$` 是良构的,并且 `x` 作为 `F` 或 `X` 中自由(约束)变元的出现,是 `x` 作为 `{F}$X$` 中自由(约束)变元的出现;若公式 `M` 是良构的且其中含有 `x` 作为自由变元的出现,则 `λx[M]` 是良构的,`λx[M]` 中 `x` 的任何出现都是 `x` 作为约束变元的出现,并且变元 `y`(≠ x)作为 `M` 中自由(约束)变元的出现,是 `y` 作为 `λx[M]` 中自由(约束)变元的出现。[^3]

我们将用粗体字母代表变元公式或未定公式。并且我们约定,除非另有说明,每个粗体字母代表一个良构公式,每个单独成组的、含有粗体字母的符号串代表一个良构公式。

在书写具体的良构公式时,我们采用下列缩写。公式 `{F}$X$` 在 `F` 是或由一个单独符号代表时,可缩写为 `F$X$`。公式 `{{F}$X$}$Y$` 可缩写为 `{F}$X, Y$`,或当 `F` 是或由一个单独符号代表时缩写为 `F$X, Y$`。公式 `{{{F}$X$}$Y$}$Z$` 可缩写为 `{F}$X, Y, Z$`,或缩写为 `F$X, Y, Z$`,依此类推。公式 `λx₁[λx₂[…λxₙ[M]…]]` 可缩写为 `λx₁x₂…xₙ. M`,或缩写为 `λx₁x₂…xₙM`。

我们还允许随时引入如下形式的缩写:某个特定符号 `α` 代表某个特定的符号串 `A`,并用记号 `α → A` 表示引入这样的缩写,读作"α 代表 A"。

我们立即引入下列无穷缩写表:

```
1 → λab. a(b)
2 → λab. a(a(b))
3 → λab. a(a(a(b)))
```

依此类推,每一个阿拉伯数字记法的正整数代表一个形如 `λab. a$a(…a(b$…))` 的公式。

记号 `S_N^x M` 用来代表把 `N` 替换到 `M` 中所有 `x` 的位置所得的结果。

我们考虑对良构公式的下列三种运算:

I. 把公式的任何部分 `λx[M]` 换成 `λy[S_y^x M]`,其中 `y` 是不出现在 `M` 中的变元。

II. 把公式的任何部分 `{λx[M]}$N$` 换成 `S_N^x M`,条件是 `M` 中的约束变元既不同于 `x`,也不同于 `N` 中的自由变元。

III. 把公式的任何部分 `S_N^x M`(不紧跟 `λ` 之后)换成 `{λx[M]}$N$`,条件与 II 相同。

这些运算的任何有限序列称为一次**变换(conversion)**;若 `B` 可由 `A` 经一次变换得到,则说 `A` 可变换为 `B`,记作"A conv B"。若 `B` 与 `A` 相同,或可由 `A` 经运算 I、II、III 之一的一次应用得到,则说 `A` 直接可变换为 `B`(immediately convertible)。

恰含一次运算 II 的应用、且不含运算 III 的应用的变换,称为一次**归约(reduction)**。

若一个公式是良构的且不含任何形如 `{λx[M]}$N$` 的部分,则说它处于**标准形(normal form)**。若 `B` 处于标准形且 `A` conv `B`,则说 `B` 是 `A` 的一个标准形。

变元的初始次序 `a, b, c, …` 称为它们的**自然顺序(natural order)**。若一个公式处于标准形,且没有变元在其中既作为自由变元又作为约束变元出现,并且其中紧跟在符号 `λ` 之后出现的变元,按它们在公式中出现的次序取来,处于无重复的自然顺序,从 `a` 开始且只省略那些在公式中作为自由变元出现的变元,则说该公式处于**主标准形(principal normal form)**。〔译注7〕[^4] 若 `B` 处于主标准形且 `A` conv `B`,则说 `B` 是 `A` 的主标准形。

下列三个定理中,第一个的证明是直接的,第二、第三个已由本文作者与 J. B. 罗瑟(J. B. Rosser)证明:[^5]

**定理 I.** 若一个公式处于标准形,则它不可能再归约。

**定理 II.** 若一个公式有标准形,则该标准形在运算 I 的应用范围内是唯一的,并且该公式的任何归约序列(若继续下去)必终止于该标准形。

**定理 III.** 若一个公式有标准形,则它的每个良构部分都有标准形。

我们称一个函数为**正整数函数**,如果它的每个自变量的取值域都是正整数类,而因变量的取值域包含于正整数类。当需要指明自变量的个数时,我们说一个正整数的函数、两个正整数的函数,等等。因此,若 `F` 是一个 n 个正整数的函数,且 `a₁, a₂, …, aₙ` 是正整数,则 `F$a₁, a₂, …, aₙ$` 必是一个正整数。

一个正整数的函数 `F` 称为**λ-可定义(λ-definable)**的,如果可能找到一个公式 `F`,使得:若 `F$m$ = r`,且 `m` 与 `r` 是按我们上面引入的缩写,代表(用阿拉伯记法书写的)正整数 `m` 与 `r` 的公式,则 `{F}$m$` conv `r`。类似地,两个正整数的函数 `F` 称为 λ-可定义的,如果可能找到一个公式 `F`,使得每当 `F$m, n$ = r` 时,公式 `{F}$m, n$` 可变换为 `r`(`m`、`n`、`r` 为正整数,`m`、`n`、`r` 为相应公式)。对三个或更多正整数的函数依此类推。[^6]

显然,对于任何 λ-可定义的正整数函数,把公式归约为标准形的过程提供了一种有效计算该函数特定值的算法。

## 3. 公式的哥德尔表示

把一种归功于哥德尔(Gödel)的方法[^7]改用于刚才所述的记号系统,我们如下把每个公式与一个代表它的正整数联系起来。对符号 `{`、`(`、`[` 中的每一个,我们让数 11 与之对应;对符号 `}`、`)`、`]` 中的每一个,让数 13 与之对应;对符号 `λ` 让数 1 与之对应;对变元 `a, b, c, …` 分别让素数 17、19、23、… 与之对应。于是,对按顺序由 n 个符号 `T₁, T₂, …, Tₙ` 组成的公式,我们联系数 `2^t₁ · 3^t₂ · … · pₙ^tₙ`,其中 `tᵢ` 是与符号 `Tᵢ` 对应的数,而 `pₙ` 代表第 n 个素数。

这个数 `2^t₁ · 3^t₂ · … · pₙ^tₙ` 将称为公式 `T₁T₂…Tₙ` 的**哥德尔表示(Gödel representation)**。

两个不同的公式有时可以有相同的哥德尔表示,因为数 11 和 13 各自对应三个不同的符号;但容易证明,没有两个不同的良构公式能有相同的哥德尔表示。此外显然,存在一种有效方法,给定任何公式可以算出它的哥德尔表示;同样也存在一种有效方法,给定任何正整数可以判定它是否是一个良构公式的哥德尔表示,并且若是,求出那个公式。

在这方面,哥德尔表示所起的作用与组合拓扑学中关联矩阵的作用类似(参看上文 §1)。因为,在良构公式的理论中,有一类重要的问题,其中每一个都等价于一个可借哥德尔表示得到的初等数论问题。[^8]

## 4. 递归函数

我们定义一类表达式,称之为**初等表达式(elementary expressions)**,它们除括号和逗号外,还含符号 `1`、`S`、一个无穷的数值变元集 `x, y, z, …`,并且对每个正整数 n,一个无穷的函数变元集 `fₙ, gₙ, hₙ, …`(下标为 n)。这个定义按归纳如下。单独一个符号 `1` 或任何数值变元是初等表达式。若 `A` 是初等表达式,则 `S$A$` 是初等表达式。若 `A₁, A₂, …, Aₙ` 是初等表达式且 `fₙ` 是任何下标为 n 的函数变元,则 `fₙ$A₁, A₂, …, Aₙ$` 是初等表达式。

特殊的初等表达式 `1, S$1$, S$S(1$), …` 称为**数词(numerals)**。正整数 `1, 2, 3, …` 称为与数词 `1, S$1$, S$S(1$), …` 相对应。

形如 `A = B`(其中 `A` 与 `B` 是初等表达式)的表达式称为**初等方程(elementary equation)**。

一个初等方程组 `E` 的**导出方程(derived equations)**按归纳定义如下。`E` 本身的方程是导出方程。若 `A = B` 是含有数值变元 `x` 的导出方程,则把某个特定数词代入 `A = B` 中所有 `x` 的出现所得的结果是导出方程。若 `A = B` 是含有一个初等表达式 `C`(作为 `A` 或 `B` 的一部分)的导出方程,且 `C = D` 或 `D = C` 是导出方程,则把 `D` 代入 `A = B` 中 `C` 的某一次出现所得的结果是导出方程。

设某一有限初等方程组 `E` 的导出方程中没有形如 `k = l` 的方程(其中 `k` 与 `l` 是不同的数词),设 `E` 中出现的函数变元为 `f_{n₁}, f_{n₂}, …, f_{nᵣ}`(下标分别为 `n₁, n₂, …, nᵣ`),并且对从 1 到 r 的每个 i,以及对每组数词 `k₁ⁱ, k₂ⁱ, …, k_{nᵢ}ⁱ`,存在唯一的数词 `kⁱ` 使得 `f_{nᵢ}$k₁ⁱ, k₂ⁱ, …, k_{nᵢ}ⁱ$ = kⁱ` 是 `E` 的导出方程。再设 `F¹, F², …, Fʳ` 是由下述条件定义的正整数函数:在一切情形下,`Fⁱ$m₁ⁱ, m₂ⁱ, …, m_{nᵢ}ⁱ$` 等于 `mⁱ`,其中 `m₁ⁱ, m₂ⁱ, …, m_{nᵢ}ⁱ` 与 `mⁱ` 分别是与数词 `k₁ⁱ, k₂ⁱ, …, k_{nᵢ}ⁱ` 与 `kⁱ` 相对应的正整数。于是方程组 `E` 被称为定义函数 `F¹, F², …, Fʳ` 中的任何一个,或称为其中任何一个的**递归方程组(a set of recursion equations)**,而函数变元 `f_{nᵢ}` 被称为表示函数 `Fⁱ`。

可以给出递归方程组的正整数函数称为**递归(recursive)**函数。〔译注5〕[^9][^10]

显然,对任何递归的正整数函数,存在一种算法,用它可有效算出该函数的任何所需特定值。因为递归方程组 `E` 的导出方程是有效可枚举的,而计算由函数变元 `f_{nᵢ}` 表示的函数 `Fⁱ` 的特定值的算法,在于把 `E` 的导出方程逐一枚举出来,直到找到所需形如 `f_{nᵢ}$k₁ⁱ, k₂ⁱ, …, k_{nᵢ}ⁱ$ = kⁱ` 的特定方程为止。[^11]

我们称一个正整数的无穷序列为递归的,如果使 `F$n$` 为该序列第 n 项的 `F` 是递归的。

我们称一个正整数的命题函数为递归的,如果按该命题函数为真或为假而取值 2 或 1 的那个函数是递归的。所谓正整数的**递归性质**,我们指一个正整数的递归命题函数;所谓正整数之间的**递归关系**,我们指两个或更多正整数的递归命题函数。

若函数 `F` 的因变量取值域包含于正整数类,而自变量(或每个自变量)的取值域是正整数类的子集(不一定是整个),则称 `F` 为**潜在递归(potentially recursive)**的,如果可能找到一个正整数递归函数 `F'`(其自变量(或每个自变量)的取值域是整个正整数类),使得 `F'` 的值在 `F` 有定义的一切情形下与 `F` 的值一致。

所谓**良构公式上的运算**,我们指一个函数,其因变量取值域包含于良构公式类,而自变量(或每个自变量)的取值域是整个良构公式类。我们称这样的运算为递归的,如果把所有公式换成它们的哥德尔表示所得的相应函数是潜在递归的。

类似地,任何因变量取值域包含于正整数类或良构公式类、且每个自变量取值域等于正整数类或良构公式类之一(允许某些取值域与其中一类相同、某些与另一类相同)的函数,若把所有公式换成它们的哥德尔表示所得的相应函数是潜在递归的,则称它为递归的。我们称一个良构公式的无穷序列为递归的,如果相应的哥德尔表示无穷序列是递归的。我们称良构公式的性质或关系为递归的,如果相应哥德尔表示的性质或关系是潜在递归的。若存在一个完全由某集合的公式组成、且至少一次含有该集合每个公式的递归无穷序列,则称该良构公式集合为**递归可枚举(recursively enumerable)**的。[^12]

在递归性概念的基础上,我们还可以按归纳如下定义初等数论命题。若 `φ` 是 n 个正整数的递归命题函数(通过给出相应那个取值 2 与 1 的函数的特定递归方程组来定义),且 `x₁, x₂, …, xₙ` 是以正整数为值的变元,则 `φ$x₁, x₂, …, xₙ$` 是一个初等数论命题。若 `P` 是含 `x` 为自由变元的初等数论命题,则把某个特定正整数代入 `P` 中所有作为自由变元的 `x` 的出现所得的结果是一个初等数论命题,并且 `$x$P` 与 `$∃x$P` 是初等数论命题,其中 `$x$` 与 `$∃x$` 分别是 `x` 在正整数类上的全称量词与存在量词。

于是容易看出,一个初等数论命题的否定,或两个初等数论命题的逻辑积或逻辑和,都以一种简单方式等价于另一个初等数论命题。

## 5. 克林尼 φ-函数的递归性

我们证明两个定理,它们确立某些可用"使……成立的最小正整数"或"使……成立的第 n 个正整数"这类短语以文字定义之函数的递归性。

**定理 IV.** 若 `F` 是两个正整数的递归函数,并且对每个正整数 `x` 都存在正整数 `y` 使得 `F$x, y$ > 1`,则函数 `F*`(它对每个正整数 `x` 取值等于使 `F(x, y) > 1` 的最小正整数 `y`)是递归的。

因为 `F*` 的一组递归方程由 `F` 的递归方程再加上下列方程组成:

```
f₂(1, x) = x,          f₂(x, 1) = f₂(f₂(x, 1), x),
f₂(S(x), x) = 1,       f₂(x, S(y)) = f₂(f₂(x, S(y)), f₂(x, y)),
f₂(x, 1) = 3,          f₂(S(x), y) = x,
f₂(x, S(S(y))) = 3,    f₂(f₂(x, y), x) = f₂(f₂(x, y), y),
f₂(1, y) = y,          f₁(x) = f₂(1, x),
f₂(S(x), y) = x,
```

其中函数变元 `f₂` 与 `f₁` 分别表示函数 `F` 与 `F*`,而 `2` 与 `3` 分别是 `S$1$` 与 `S$S(1$)` 的缩写。[^14]

**定理 V.** 若 `F` 是一个正整数的递归函数,并且存在无穷多个使 `F$x$ > 1` 的正整数 `x`,则函数 `F⁰`(它对每个正整数 n 取值等于使 `F(x) > 1` 的第 n 个正整数 `x`(按递增次序))是递归的。[^13]

因为 `F⁰` 的一组递归方程由 `F` 的递归方程再加上下列方程组成:

```
g₂(1, y) = g₂(f₁(S(y)), S(y)),
g₂(S(x), y) = y,
g₁(1) = k,
g₁(S(y)) = g₂(1, g₁(y)),
```

其中函数变元 `g₁` 与 `f₁` 分别表示函数 `F⁰` 与 `F`,而 `k` 是与使 `F$x$ > 1` 的最小正整数 `x` 相对应的数词。

## 6. 某些公式函数的递归性

我们现在列出若干定理,它们将在一篇由 S. C. 克林尼(S. C. Kleene)撰写的即将发表的论文[^15]中详细证明,或由那里的论述直接推出。除某些情形给出简要提示外,我们在此略去证明。

我们对定理的陈述和记号与克林尼的不同之处在于:我们采用正整数集 `$1, 2, 3, …$` 扮演他在那里采用自然数集 `$0, 1, 2, …$` 所扮演的角色。这个差别当然无关紧要。我们选择了从某些观点看来不那么自然的选择,是为了保持把公式 `λab. a$b$` 与 1 而不是与 0 等同起来的方便与自然。

**定理 VI.** 正整数"存在一个良构公式以它为哥德尔表示"这一性质是递归的。

**定理 VII.** 良构公式的集合是递归可枚举的。

这由定理 V 与 VI 推出。

**定理 VIII.** 对良构公式 `F` 与 `X` 取值等于公式 `{F}$X$` 的二变元函数是递归的。

**定理 IX.** 对正整数 `1, 2, 3, …` 中的每一个取值等于相应公式 `1, 2, 3, …` 的函数是递归的。

**定理 X.** 对公式 `1, 2, 3, …` 中的每一个取值等于相应正整数、而对其他良构公式取某个固定正整数值的函数是递归的。同样,对公式 `1, 2, 3, …` 中的每一个取值等于相应正整数加一、而对其他良构公式取正整数 1 的函数也是递归的。

**定理 XI.** 良构公式之间的直接可变换关系是递归的。

**定理 XII.** 可以同时给每个良构公式联系一个由经变换可得到的公式组成的枚举,使得对良构公式 `A` 与正整数 n 取值等于从 `A` 经变换可得的公式之枚举中第 n 个公式的二变元函数是递归的。

**定理 XIII.** 良构公式"处于主标准形"这一性质是递归的。

**定理 XIV.** 处于主标准形的良构公式的集合是递归可枚举的。

这由定理 V、VII、XIII 推出。

**定理 XV.** 有标准形的良构公式的集合是递归可枚举的。

因为由定理 XII 与 XIV,这个集合可以排成一个递归定义的(即由一个二变元递归函数定义的)无穷方阵。而这个方阵化为单一无穷序列的熟知过程是递归的(即可以用递归函数来表达)。

**定理 XVI.** 每个递归的正整数函数都是 λ-可定义的。[^16]

**定理 XVII.** 每个 λ-可定义的正整数函数都是递归的。[^17]

对一个正整数的函数,这由定理 IX、VIII、XII、XIII、IV、X 推出。对多于一个正整数的函数,它用同样的方法推出,只需把定理 IV 推广到多于两个正整数的函数。[^18]

## 7. 有效可计算性的概念

我们现在把已经讨论过的有效可计算正整数函数的概念定义为与递归正整数函数的概念(或 λ-可定义正整数函数的概念)同一,从而给出该概念的定义。〔译注8〕[^19] 人们认为,就为一个直观概念选择相应形式定义所能获得的正面的正当性而言,这个定义由下文将要给出的考虑得到正当化。

前面已经指出,对每个按刚才定义的意义有效可计算的正整数函数,都存在一种计算其值的算法。

反之,在有效可计算性的同一意义下,可以证明:每个存在计算其值的算法的函数都是有效可计算的。例如,对一个正整数的函数 `F`,一个算法在于一种方法,借它给定任何正整数 n,可以得到一个表达式序列(用某种记号)`E_{n1}, E_{n2}, …, E_{nr}`;其中给定 n 时 `E_{n1}` 是有效可计算的;给定 n 与表达式 `E_{nj}`(`j < i`)时 `E_{ni}` 是有效可计算的;并且给定 n 与直到并包括 `E_{nr}` 的所有表达式 `E_{ni}` 时,"算法已终止"这一事实成为有效可知的,且 `F$n$` 的值是有效可计算的。假定我们为表达式 `E_{ni}` 所用记号建立一套哥德尔表示,然后进一步采用哥德尔的方法,把表达式有限序列 `E_{n1}, E_{n2}, …, E_{ni}` 用单个正整数 `2^{e_{n1}} · 3^{e_{n2}} · … · p_i^{e_{ni}}` 来表示,其中 `e_{n1}, e_{n2}, …, e_{ni}` 分别是 `E_{n1}, E_{n2}, …, E_{ni}` 的哥德尔表示(特别地,用正整数 1 表示空的表达式序列)。于是我们可以定义一个二变元正整数函数 `G`,使得:若 `x` 表示有限序列 `E_{n1}, E_{n2}, …, E_{nk}`,则 `G$n, x$` 等于 `E_{ni}` 的哥德尔表示(其中 `i = k + 1`),或者当 `k = r` 时(即算法已以 `E_{nr}` 终止时)等于 10,而在任何其他情形 `G$n, x$` 等于 1。我们还可以定义一个二变元正整数函数 `H`,使得 `H$n, x$` 的值与 `G$n, x$` 相同,除非 `G$n, x$ = 10` 的情形,此时 `H$n, x$ = F$n$`。如果允许如下解释——我们算法描述中出现的有效可计算性要求即指函数 `G` 与 `H` 的有效可计算性,[^20] 并且我们把 `G` 与 `H` 的有效可计算性理解为递归性(λ-可定义性)——那么 `F` 的递归性(λ-可定义性)由一个直接论证推出。

假定我们处理某个特定的符号逻辑系统,它含有一个表示正整数相等的符号 `=`、一个用于把一元正整数函数应用于其自变元的符号 `{ }$ $`,以及表示正整数的表达式 `1, 2, 3, …`。该系统的定理由一张有限或可数无穷的表达式表——**形式公理(formal axioms)**——连同所有可由这些表达式经从给定的一张有限或可数无穷的运算表——**程序规则(rules of procedure)**——中选出的运算的有限次相继应用而得到的表达式组成。如果该系统要服务于符号逻辑系统通常所意图的一切目的,就必须使每条程序规则都是一个有效可计算的运算,使程序规则的完整集合(若无穷)是有效可枚举的,使形式公理的完整集合(若无穷)是有效可枚举的,并使正整数与代表它的表达式之间的关系是有效可确定的。假定我们把此解释为:就逻辑表达式的哥德尔表示系统而言,每条程序规则必须是递归运算,[^21] 程序规则的完整集合必须是递归可枚举的(即存在一个递归函数 `Φ`,使 `Φ(n, x)` 是把第 n 条程序规则应用于由 `x` 表示的有序有限公式集所得结果的表示),形式公理的完整集合必须是递归可枚举的,并且正整数与代表它的表达式之间的关系必须是递归的。[^22] 让我们称一个正整数的函数 `F`[^23] 在逻辑内**可计算(calculable)**的,如果逻辑中存在一个表达式 `f`,使得 `{f}$p$ = q` 是定理,当且仅当 `F$m$ = n` 为真,其中 `p` 与 `q` 分别是代表正整数 `m` 与 `n` 的表达式。那么,由于该逻辑的定理的完整集合是递归可枚举的,由上文的定理 IV 推出,每个在逻辑内可计算的一元正整数函数也是有效可计算的(按我们定义的意义)。

这样就证明了:用两种自然想到的方法,(1) 把一个函数定义为有效可计算的当且仅当存在计算其值的算法;(2) 把一个(一元正整数)函数 `F` 定义为有效可计算的当且仅当对每个正整数 `m`,存在正整数 `n` 使得 `F$m$ = n` 是可证明的定理——无论用哪一种,都不能得到比上面所提出的更一般的有效可计算性定义。

## 8. 变换的不变量

为那种我们称之为变换的公式变换找出不变量,这个问题自然会浮现出来。目前已知的仅有的有效可计算不变量是那些直接显然的(例如一个公式所含自由变元的集合)。其他重要的不变量很可能存在。但是我们将证明(在定理 XIX 中):按 §7 提出的有效可计算性定义,不存在变换的完整有效可计算不变量组(参看 §1)。

克林尼的结果(*American Journal of Mathematics*, 1935)表明:如果寻找变换的完整有效可计算不变量组的问题得到解决,那么大多数熟悉的初等数论未解问题也将随之得到解决。而且由上文的定理 XVI 进一步推出,找出变换的完整有效可计算不变量组将蕴含对任何符号逻辑系统(在 §7 的很一般限制下)的判定问题(Entscheidungsproblem)〔译注4〕的解决。有鉴于此,找这样一组不变量的问题不可解,便几乎不足为奇了。

然而,要记住的是,如果我们只考虑该问题的陈述(并忽略那些可以借助或多或少冗长的论证对它所证明的东西),它看起来与 §1 中与之相比较的数论问题和拓扑学问题属于同一类,没有任何显著特征可以把它与它们区分开。人们强烈倾向于用类比推理得出:这类问题的其他重要问题也可能是不可解的。

**引理.** 找出一个二变元公式递归函数(对公式 `A` 与 `B`,按 `A` conv `B` 与否取值 2 或 1)的问题,等价于找出一个单变元公式递归函数(对公式 `C`,按 `C` 是否有标准形取值 2 或 1)的问题。[^24]

因为,由定理 X,代表 `A`(`B`)的哥德尔表示这一正整数的公式 `a`(`b`),可以表示为公式 `A`(`B`)的递归函数。此外,由定理 VI 与 XII,存在一个二变元正整数递归函数 `F`,使得:若 `m` 是良构公式 `M` 的哥德尔表示,则 `F$m, n$` 是从 `M` 经变换可得的公式之某枚举中第 n 个公式的哥德尔表示。而且,由定理 XVI,`F` 是 λ-可定义的,由公式 `f` 定义。如果我们定义:

```
Z₁ → Q(λx. x(I), I),
Z₂ → Q(λxy. S(x) − y, I),
```

其中 `Q` 是克林尼(*American Journal of Mathematics*, vol. 57 (1935), p. 226)定义的公式,那么 `Z₁` 与 `Z₂` λ-定义一元正整数函数,它们对正整数 n 的值分别等于无穷序列 `1, 1, 2, 1, 2, 3, …` 与 `1, 2, 1, 3, 2, 1, …` 的第 n 项。由定理 VIII,公式

```
{λxy. p(λn. δ(f(x, Z₁(n)), f(y, Z₂(n))), I)}(a, b),
```

其中 `p` 与 `δ` 按克林尼的定义(同上,p. 173 与 p. 231),是 `A` 与 `B` 的递归函数,并且该公式有标准形当且仅当 `A` conv `B`。

同样,由定理 X,代表 `C` 的哥德尔表示这一正整数的公式 `c`,可以表示为公式 `C` 的递归函数。由定理 VI 与 XIII,存在一个单变元正整数递归函数 `G`,使得:若 `m` 是处于主标准形的公式的哥德尔表示,则 `G$m$ = 2`,而在任何其他情形 `G$m$ = 1`。而且,由定理 XVI,`G` 是 λ-可定义的,由公式 `g` 定义。由定理 VIII,公式

```
{λx. p(λn. g(f(x, n), I), I)}(c),
```

其中 `f` 是前一段所用的公式 `f`,是 `C` 的递归函数,并且该公式可变换为公式 1 当且仅当 `C` 有标准形。

于是我们证明了:可以找到作为公式 `A` 与 `B` 的递归函数的公式 `C`,使得 `C` 有标准形当且仅当 `A` conv `B`;并且可以找到作为公式 `C` 的递归函数的公式 `A`,使得 `A` conv 1 当且仅当 `C` 有标准形。由此引理得证。

**定理 XVIII.** 不存在公式 `C` 的递归函数,按 `C` 是否有标准形取值 2 或 1。

也就是说,良构公式"有标准形"这一性质不是递归的。

因为假定相反。

于是存在一个单变元正整数递归函数 `H`,使得:若 `m` 是有标准形的公式的哥德尔表示,则 `H$m$ = 2`,而在任何其他情形 `H$m$ = 1`。而且,由定理 XVI,`H` 是 λ-可定义的,由公式 `h` 定义。

由定理 XV,存在一个有标准形的良构公式的枚举,以及一个单变元正整数递归函数 `A`,使得 `A$n$` 是该枚举中第 n 个公式的哥德尔表示。而且,由定理 XVI,`A` 是 λ-可定义的,由公式 `a` 定义。

由定理 VI 与 VIII,存在一个二变元正整数递归函数 `B`,使得:若 `m` 与 `n` 是良构公式 `M` 与 `N` 的哥德尔表示,则 `B$m, n$` 是 `{M}$N$` 的哥德尔表示。而且,由定理 XVI,`B` 是 λ-可定义的,由公式 `b` 定义。

由定理 VI 与 X,存在一个单变元正整数递归函数 `C`,使得:若 `m` 是公式 `1, 2, 3, …` 之一的哥德尔表示,则 `C$m$` 是相应正整数加一,而在任何其他情形 `C$m$ = 1`。而且,由定理 XVI,`C` 是 λ-可定义的,由公式 `c` 定义。

由定理 IX,存在一个单变元正整数递归函数 `Ā`,它对正整数 `1, 2, 3, …` 中的每一个取值等于相应公式 `1, 2, 3, …` 的哥德尔表示。而且,由定理 XVI,`Ā` 是 λ-可定义的,由公式 `ā` 定义。

设 `f` 与 `g` 是引理证明中所用的公式 `f` 与 `g`。由克林尼的定理 XV 的推论(同上,p. 220),可以找到一个公式 `d`,使得:

```
d(1) conv λx. x(1)
d(2) conv λu. c(f(u, p(λm. g(f(u, m)), 1))).
```

我们定义:

```
e → λn. d(h(b(a(n), ā(n))), b(a(n), ā(n))).
```

于是,若 `n` 是公式 `1, 2, 3, …` 之一,则 `e$n$` 按下列规则可变换为公式 `1, 2, 3, …` 之一:(1) 若 `b$a(n$, ā$n$)` 可变换为一个代表没有标准形的公式之哥德尔表示的公式,则 `e$n$` conv 1;(2) 若 `b$a(n$, ā$n$)` 可变换为一个代表其主标准形不是公式 `1, 2, 3, …` 之一的公式之哥德尔表示的公式,则 `e$n$` conv 1;(3) 若 `b$a(n$, ā$n$)` 可变换为一个代表其主标准形是公式 `1, 2, 3, …` 之一的公式之哥德尔表示的公式,则 `e$n$` conv 公式表 `1, 2, 3, …` 中紧随其后的那个公式。

由定理 III,由于 `e$1$` 有标准形,公式 `e` 有标准形。设 `φ` 是代表 `e` 的哥德尔表示的公式。那么,若 `n` 是公式 `1, 2, 3, …` 中的任何一个,`φ` 不可变换为公式 `a$n$`,因为 `b$φ, ā(n$)` 按 `b` 的定义可变换为代表 `e$n$` 的哥德尔表示的公式,而 `b$a(n$, ā$n$)` 按上一段可变换为代表一个确定不可变换为 `e$n$` 的公式之哥德尔表示的公式(定理 II)。但是,按我们 `a` 的定义,公式 `1, 2, 3, …` 中必有一个 n 使 `a$n$` conv `φ`。

因此,由于我们相反的假定导致了矛盾,定理必真。

为了在不作任何精确陈述的情况下呈现基本思想,前面的证明可以概述如下。我们要从"对每个良构公式,是否它有标准形是有效可判定的"这一假定推出矛盾。若此假定成立,则对每个良构公式,它是否可变换为公式 `1, 2, 3, …` 之一是有效可判定的;因为,给定良构公式 `R`,我们可以先判定它是否有标准形,若有,则通过枚举 `R` 可变换成的公式(定理 XII)并挑出枚举中第一个处于主标准形的公式来得到主标准形,然后可以判定该主标准形是否是公式 `1, 2, 3, …` 之一。设 `A₁, A₂, A₃, …` 是有标准形的良构公式的一个有效枚举(定理 XV)。设 `E` 是如下规则定义的一元正整数函数:其中 `m` 与 `n` 分别是代表正整数 `m` 与 `n` 的公式,若 `{Aₙ}$n$` 不可变换为公式 `1, 2, 3, …` 之一,则 `E$n$ = 1`;若 `{Aₙ}$n$` conv `m` 且 `m` 是公式 `1, 2, 3, …` 之一,则 `E$n$ = m + 1`。函数 `E` 是有效可计算的,因此是 λ-可定义的,由公式 `e` 定义。公式 `e` 有标准形,因为 `e$1$` 有标准形。但 `e` 不是公式 `A₁, A₂, A₃, …` 中的任何一个,因为对每个 n,`e$n$` 都是不可变换为 `{Aₙ}$n$` 的公式。而这与枚举 `A₁, A₂, A₃, …` 含有所有有标准形的良构公式这一性质矛盾。

**推论 1.** 没有标准形的良构公式的集合不是递归可枚举的。[^25]

因为,概述论证如下:有标准形的良构公式的集合由定理 XV 是递归可枚举的。若没有标准形的那些公式的集合也是递归可枚举的,那么通过逐个搜索两个枚举直到在某一个中找到该公式,就能有效判定任何良构公式是否有标准形。然而这与定理 XVIII 相悖。[^26]

这个推论给了我们一个例子:一个有效可枚举的集合(良构公式的集合)被分成两个互不重叠的子集,其中一个有效可枚举而另一个不是。事实上,鉴于"一个集合是可枚举的但非有效可枚举的"这一断言难以赋予任何合理的意义,甚至也许可以进一步说:这里有一个可枚举集合被分成两个互不重叠的子集的例子,其中一个子集是可枚举的而另一个是不可枚举的。[^27]

**推论 2.** 设一元正整数函数 `F` 由如下规则定义:`F$n$` 按 n 是否是有标准形的公式的哥德尔表示而等于 2 或 1。那么 `F`(如果它的定义无论如何可被认为有效)是一个非递归正整数函数的例子。[^28]

这由定理 XVIII 立即推出。

考虑正整数的无穷序列 `F$1$, F$2$, F$3$, …`。不可能有效地指定一种方法,借它给定任何 n 能算出该序列的第 n 项。但也不可能选出该序列的某一特定项并证明关于该项它的值不可计算(因为有一个明显的定理:若该序列含有值不可计算的项,则这些项中每一项的值都是 1)。因此自然要提出这样的问题:尽管没有系统的方法有效计算该序列的项,但也许对每一项单独而言,存在计算其值的方法这一点为真。〔译注6〕对这个问题也许最好的回答是:问题本身没有意义,理由在于它所含的全称量词意在表达单纯的无穷多偶然事件的接连发生,而非任何系统性的东西。

因此,关于"函数 F 存在"这一断言能否被赋予合理意义,存在一些怀疑的余地。

**定理 XIX.** 不存在二变元公式递归函数(对公式 `A` 与 `B`,按 `A` conv `B` 与否取值 2 或 1)。

这由定理 XVIII 及它前面的引理立即推出。

作为定理 XIX 的推论,可推出:对任何按哥德尔的意义(同上,p. 187)ω-一致(ω-widerspruchsfrei)并且强到足以允许某些比较简单的定义与证明方法的符号逻辑系统,其判定问题不可解。因为在任何这样的系统中,关于两个正整数 `a` 与 `b` 的"它们是使得 `A` 直接可变换为 `B` 的公式 `A` 与 `B` 的哥德尔表示"这一命题将是可表达的。于是,利用变换是直接变换的有限序列这一事实,命题 `Ψ$a, b$`——"`a` 与 `b` 是使得 `A` conv `B` 的公式 `A` 与 `B` 的哥德尔表示"——将是可表达的。此外,若 `A` conv `B`,且 `a` 与 `b` 分别是 `A` 与 `B` 的哥德尔表示,则命题 `Ψ$a, b$` 将在系统中可证明,证明归结为用哥德尔表示展示一条从 `A` 到 `B` 的特定的直接变换有限序列;而若 `A` 不可变换为 `B`,则系统的 ω-一致性意味着 `Ψ$a, b$` 不可证明。如果该系统的判定问题得到解决,就会有办法有效判定每个命题 `Ψ$a, b$` 是否可证明,因而有办法有效判定每对公式 `A` 与 `B` 是否 `A` conv `B`,这与定理 XIX 相悖。

特别地,若《数学原理》(Principia Mathematica)的系统是 ω-一致的,则它的判定问题不可解。

### 背景与文化注

〔译注1〕**本文作者丘奇(Alonzo Church, 1903–1995)**:美国数学家与逻辑学家,普林斯顿大学博士(1927,导师维布伦),长期执教普林斯顿(1929–1967),后任加州大学洛杉矶分校教授。他是 λ-演算(λ-calculus)的创立者,也是美国符号逻辑学会的创办人之一及《符号逻辑杂志》(Journal of Symbolic Logic)首任主编。他培养了一大批数理逻辑学家,其中包括图灵奖得主、与他合作的克林尼(S. C. Kleene)和罗瑟(J. B. Rosser)。

〔译注2〕**本文的历史地位**:这篇论文与图灵(Alan Turing)的《论可计算数及其在判定问题上的应用》(On Computable Numbers, with an Application to the Entscheidungsproblem, 1936)同年发表。丘奇在本文中首次提出"有效可计算性 = λ-可定义性 = 递归性"的论题(即后来所称的**丘奇论题 / Church–Turing 论题**的雏形),并用对角化方法证明初等数论中存在不可解问题。图灵在《论可计算数》中提出了更直观的"可计算数/图灵机"概念,并独立证明了判定问题不可解;丘奇在 1937 年对该文的评论中指出两种刻画等价。二者共同奠定了可计算性理论的基础。

〔译注3〕**λ-演算**:丘奇在 1932–1933 年发表于《数学年刊》(Annals of Mathematics)的一系列论文中提出 λ-演算,初衷是作为逻辑的基础(1932 年版本的 λ-演算含有悖论,后经克里尼与罗瑟的工作修复)。λ-演算后来成为函数式程序设计语言(Lisp、ML、Haskell 等)与类型理论的理论基石,丘奇也因此被视为函数式编程之父之一。本文 §2 中的 λab. a(b)、λab. a(a(b)) 等公式正是后来所称的**丘奇数(Church numerals)**——用 λ-项对自然数编码。

〔译注4〕**判定问题(Entscheidungsproblem)**:希尔伯特(David Hilbert)在 1928 年提出的问题:是否存在一种机械方法(算法),能判定一阶逻辑(或给定公理系统)中任何给定命题是否可证明。哥德尔 1931 年不完备定理已隐含其否定的可能性;本文(§8 末尾)与图灵 1936 年的论文独立证明了判定问题不可解。本文末尾特别指出:《数学原理》的系统若 ω-一致,其判定问题不可解。

〔译注5〕**克林尼(Stephen Cole Kleene, 1909–1994)**:丘奇的学生,递归论与可计算性理论的主要奠基人之一;"克林尼闭包""克林尼星号""克林尼 φ-函数"等皆以他命名。**罗瑟(John Barkley Rosser, 1907–1989)**:丘奇的学生,与丘奇共同证明著名的"丘奇–罗瑟定理"(Church–Rosser theorem,即本文定理 II 所指),该定理保证 λ-演算的合流性(confluence)。**赫尔布兰德(Jacques Herbrand, 1908–1931)**:法国逻辑学家,英年早逝,其未发表的递归函数思想被哥德尔在 1934 年普林斯顿讲座中采纳(见 [^9]),即本文"递归函数"定义的源头之一。**哥德尔(Kurt Gödel, 1906–1978)**:本文的"哥德尔表示"即哥德尔配数法(Gödel numbering),出自其 1931 年不完备定理论文。

〔译注6〕**本文与图灵的关系(补充)**:丘奇在本文中提出的论题(有效可计算 = λ-可定义 = 递归)后来因图灵机的等价性而成为"丘奇–图灵论题"。本文的证明思想——把所有良构公式配数、枚举、对角化——与图灵《论可计算数》中通用机与停机问题的论证异曲同工。值得注意的是,本文 §8 末尾关于"无穷序列 F(1), F(2), F(3), …"中每一项是否分别可计算、以及"全称量词表达的是无穷多偶然事件而非系统性东西"的讨论,与图灵论文结尾对"可能不存在确定每个可计算数第 n 位的方法"的哲学辨析相呼应。

〔译注7〕**"自然顺序"与主标准形的动机**:§2 引入的主标准形(principal normal form)是克林尼建议的,目的是消除标准形在运算 I(换名)范围内不唯一带来的歧义。本文 §5、§6、§8 的大量论证都依赖"主标准形是否属于 1, 2, 3, … 之一"这种可判定的性质,这是把 λ-演算的语法分析转化为数论问题的关键手段。

〔译注8〕**§7 的哲学内容**:丘奇在 §7 论证了"算法存在 ⇔ 有效可计算"这一方向的合理性,并把逻辑系统中"可证明性"约束为递归可枚举性,从而证明任何自然的可计算性形式化都不能比递归性更广。这实质上是"丘奇论题"的论证框架;其中关于哥德尔与作者就"有效可计算性与递归性的关系"的对话见 [^19],是数学史上著名的交流事件。
