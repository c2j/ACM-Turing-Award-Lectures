## Part II. Chemical Theory of Morphogenesis(化学形态发生理论)

### 1. 细胞集合的形态原方程.线性情形(Morphogen equations for an assembly of cells. The linear case)

**〔印刷页 88〕**

在图灵(1952)中,反应-扩散系统的理论是就生物体几何形状为一环细胞、且反应速率可视为浓度的线性函数这一情形发展的。本部分将要给出的方程则适用于任意的几何形状与任意的反应速率函数。与先前一样,本研究假设几何形状在整个过程中保持不变。这个假设当然不可能总是满足——事实上,倘若化学浓度的变化终究丝毫不影响生长,它们也就无足轻重了——但生长的速率多半足够缓慢,以致所达成的化学浓度平衡不致受到生长的可察觉影响。〔译注1:图灵(1952)即《形态发生的化学基础》,见本卷 [`08-形态发生的化学基础.md`](08-形态发生的化学基础.md);下文引作"图灵(1952)"处均同。〕

对生物体的描述可分为几何与化学两部分,分别涉及其中各种形态原(morphogen)的扩散与反应。"形态原"一词系图灵(1952)所引入,在那里它实际上意指"与形态发生有关的化学物质"。本文将给它一个限制稍严的含义,即:**其浓度的变化由数学理论中的一个变量来描述的化学物质**。生物体在任一时刻 `t` 的状态可用 `MN` 个数 `r_{mn}`(`m` = 1, 2, …, `M`;`n` = 1, 2, …, `N`)描述,其中 `r_{mn}` 是第 `m` 种形态原在第 `n` 个细胞中的浓度。这种描述默认无须区分同一细胞之内的不同位置;这个假设多半成立,因为细胞内部通常有相当可观的原生质流动,会使内容物得到充分的混合。不必假设各细胞体积相等,可设第 `r` 个细胞的体积为 `v_r`。物质从一个细胞流向另一个细胞的速率,当然与流动物质在两细胞中的浓度差成正比:即第 `m` 种形态原从细胞 `r` 流向细胞 `s` 的速率与 `r_{mr} − r_{ms}` 成正比。它还必须与一个量 `g_{rs}` 成正比,后者只依赖于细胞 `r` 与 `s` 之间隔墙的几何形状,而与流动的物质无关;此外还有一个因子 `μ_m`,即所述形态原穿过细胞壁材料(假定所有细胞壁由相同材料构成)时的扩散常数。

**〔印刷页 89〕**

暂不考虑化学反应时,系统的方程为〔译注2:本篇显示公式的排版在源文本层中几乎全部失落于 OCR 之外(仅余编号与零星片段),下文所有编号公式均据残迹、正文叙述及图灵(1952)的理论重构;个别存疑处另加注说明。〕:

```
           μ_m
dr_mr/dt = ──── Σ_{s≠r} g_rs (r_ms − r_mr)          (II.1.1)
           v_r
```

若定义 `g_{rr}` 为

```

```

则 (II.1.1) 可写成更方便的形式

```

           v_r
```

或者,令 `Γ_{mn} = √v_n · r_{mn}`,写成〔译注3:`√v_n` 中开方的归属(乘在 `v_n` 上抑或除之)无法从残迹判定;此处取能使矩阵 `g_{rs}/√(v_r v_s)` 对称、并与下文"该矩阵对称"一语相合的约定。〕

```
dΓ_mr = μ_m Σ_s (g_rs / √(v_r v_s)) Γ_ms           (II.1.3)
```

```
− g_rs / √(v_r v_s) = Σ_k α_k u_sk u_rk             (II.1.4a)

Σ_k u_rk u_sk = δ_rs                                (II.1.4b)
```

〔译注4:(II.1.4a) 中负号的归属系译者抉择:正文明言"特征值 `α_k` 无一为负",而纯扩散必使浓度差异衰减,二者合观只能把 `α_k` 取为 `-g`(而非 `g`)的特征值;残迹中只见 "`g_{rs}` = Σ α_k u_sk u_rk" 之形。〕若再令

```
ξ_mk = Σ_r u_rk Γ_mr                               (II.1.5)
```

从而

```
Γ_mr = Σ_j u_rj ξ_mj                               (II.1.6)
```

方程便简单地化为

```
dξ_mk
─────  = − μ_m α_k ξ_mk                            (II.1.7)
  dt
```

特征值 `α_k` 为实数,因为 `g_{rs}` 是实对称的。它们之中没有一个为负,这可以从物理上看出:倘若其中某个为负,(II.1.7) 就会给出一些使浓度差随时间增大的解。只要有生物体是连通的,为零的 `α_k` 就只能有一个,因为此时对每个 `m`,方程在时间中不变的线性无关解只有一个。

**〔印刷页 90〕**

至于化学反应,要点在于:它们的进行速率只依赖于**同一个细胞**内各种形态原的浓度。在图灵(1952)中,主要的兴趣集中于反应速率为浓度的线性函数的情形;只要涉及的只是浓度的微小变化,这个假设就是相当合理的。这一线性情形的理论当时是在一个颇为特殊的几何假设——生物体由一环细胞构成——之下完成的。然而这个限制完全是不必要的,引入它只是为了让所考虑的问题足够明确,从而使论证更易于普遍理解。即将看到,该情形下得到的结论可以直接搬到细胞的任何排列方式上。

设在 `M` 种形态原的浓度为 `Γ_1, Γ_2, …, Γ_M` 时,第 `m` 种形态原每单位体积的产生速率为 `f_m(Γ_1, …, Γ_M)`。于是同时描述扩散与反应的方程为

```
           μ_m
dr_mr/dt = ──── Σ_s g_rs r_ms + f_m(r_1n, …, r_Mn)   (II.1.8)
           v_r
```

**〔印刷页 91〕**

这些方程可以经 (II.1.3)、(II.1.6) 式的代换化为与 (II.1.7) 类似的结果。

若 `Γ⁽³⁾_mn` 是一些与 `Γ_mn` 相类似的变量,只是它们描述的是对平衡的偏差〔译注5:上标 (3) 照录残迹,其含义(逐级变换后的第三组变量)手稿未作说明;亦有排印讹变的可能。〕,并且这些偏差小到可以把反应速率当作它们的线性函数来处理,那么变换后的方程成为

```
dΓ⁽³⁾_mn
────────  = − μ_m α_n Γ⁽³⁾_mn + Σ_k a_mk Γ⁽³⁾_kn        (II.1.9)
    dt
```

其中 `a_{mk}` 是 `df_m/dΓ_k` 在平衡浓度处的值。可以看到,这些方程分离成 `N` 组互相独立的、每组含 `M` 个方程的方程组。在每一组方程里,系统的几何只在通过扩散矩阵 `g_{rs}/√(v_r v_s)` 的特征值 `α_k` 进入问题。对于图灵(1952)中所考虑的细胞环,`α`(在该文中记作 `U`)的一切可能非负值都可能出现,而且也都曾被纳入考虑;任何其他几何排列也不可能给出更丰富多样的 `α` 值。

(II.1.9) 的解可写为

```
Γ⁽³⁾_mn(t) = Σ_l X_ln(t) S_mln                     (II.1.10a)

X_ln(t) = X_ln(0) exp{p_l t}                       (II.1.10b)
```

其中

```
(p_l(α_n) + μ_m α_n) S_mln = Σ_k a_mk S_kln        (II.1.11)
```

从 (II.1.11) 中消去诸 `S_mln`,便得到 `p` 与 `α` 之间的一个代数关系。对每个 `α` 值,有 `M` 个 `p` 值满足该关系,并有 `M` 组相应的解 (II.1.10)。图灵(1952)的绝大部分内容正是讨论这个 `α`–`p` 关系,以及它在不同化学条件下的各种形状。此处不宜重复那一分析,但可以提一提与当前问题有关的若干要点。显然,(II.1.10b) 中最重要的项是 `Re(p)` 最大的那些项,因为只有它们增长得最快。实际上,只要线性假设保持成立,最终便可略去除具有最大 `Re(p)` 的分量之外的一切分量。在图灵(1952)中,各种可能性是按照当 `Re(p)` 达到最大值时 `p` 与 `α` 的取值情形分类的:`α` 可以为零、有限或无穷,`p` 可以为实或复,共六种备选情形,并曾以适当设计的假想化学反应逐一实现之。其中最令人感兴趣、也是本文唯一要考虑的情形,是在最大值处 `p` 为实数、`α` 有限且非零的情形。这就是所谓的"**驻波**(stationary waves)"情形。

**〔印刷页 92〕**

当生物体只含有限多个细胞,或细胞虽无限小而整个生物体体积有限时,特征值 `α_k` 是离散的。此时使 `Re(p)` 达到最大值的 `α` 只能有限多个。不过,这个数目超过一绝非罕见。事实上,若系统具有某种几何对称性,(II.1.11) 特征方程出现重根将绝非例外之事:因为把一个对称操作作用于 `S_mln` 时,它就被变成对应于**同一**特征值的特征向量。该向量自身或许恰具有所论的对称性;但若不具有(而没有理由非具有不可),则对称操作就把它变换成另一个解,特征根必定是重的。若对应于最大 `Re(p)` 有一个 `k` 重根,则极限解含有 `k` 个参数。当把二次项计入之后,这种局面会被大大改观。

对许多目的而言,用细胞来描述生物体并不方便。让每个细胞的体积趋于零、细胞数目相应增加,取这一极限在数学上也许更令人满意。无须假设所得的连续组织是均匀的或各向同性的;其实也无须把这套理论在任何细节上贯彻到底。在任何具体情形中都存在某个线性算子,记作 `∇²`,使得浓度为 `c`、扩散常数为 `μ` 的物质之扩散满足定律

```
dc/dt = μ ∇²c                                      (II.1.12)
```

计入反应后,方程变为

```
∂r_m/∂t = μ_m ∇²r_m + f_m(r_1, …, r_M)             (II.1.13)
```

与有限情形一样,可以把生物体内位置的任意函数按算子 `∇²` 的特征函数展开,类似地进行与 (II.1.5) 相对应的展开;本节理论的其余部分即可应用于这一展开。

### 2. 关于叶序化学的一些假设(Assumptions concerning the chemistry of phyllotaxis)

**〔印刷页 93〕**

解 (II.1.13) 的行为随函数 `f_m` 与各扩散性 `β_m`〔译注6:原文此处作 "diffusibilities β_m";本节其余处扩散常数仍记 `μ_m`,两记号所指相同。〕的不同可以取极不相同的形式。若再让形态原的浓度影响生物体的生长,这种多样性还会进一步增大。图灵(1952)曾提示,这也许正是基因所含化学信息被转换为几何形式的主要途径。倘若果真如此,那么任何一种特定类型的解剖结构都只能从所有可能的化学反应系统中一个较小的子集中产生:倘若它能从全部系统中产生,则别的解剖形态就无从存在了。特别地,并非一切反应系统都适合于描述叶序现象。本文第二部的目的,就是要描述化学反应在何种条件下适合于此目的,求出描述这些反应进程的一个偏微分方程,并考察该偏微分方程的行为。遗憾的是,无法先验地断言其他反应系统能描述的行为范围有多广。它看起来能够给出可能解的极大多样性,但这种多样性是否足以刻画生命形式的一切多样性,并不容易判定。

将要采用的主要假设是:

(a) 反应系统具有一个均匀平衡,而且对该平衡的小偏差满足驻波条件(见图灵(1952)第 52 页)。

(b) 对均匀状态的偏差不太大:大到线性近似不再适用,但又小到二次项及更高次项的效应可以视作不外乎微扰。

(c) 有意义的波长只有两类:要么非常长,要么相当接近最优波长。

当不打算假设反应速率函数为线性时,可以:

(i) 对系统的化学作出某些完全确定的假设,从而得到确定的反应速率函数;或者,

(ii) 承认反应速率函数可以是浓度的任意函数;或者,

(iii) 假设反应速率是浓度的多项式;或者,

(iv) 假设反应速率是浓度的二次函数。

反应速率为多项式的假设可以由质量作用定律直接辩护。然而知道这一点并无多大好处。况且,在处理具体情形时,人们往往宁愿使用非多项式的函数,因为这样一来,如果某些反应进行得很快,常可减少形态原的数目,即所需考虑的变量数目。反应速率是浓度二次函数的假设更有用一些,尽管表面上显得相当任意且有效性有限。但它其实可以得到与多项式假设同样充分的辩护。辩护论证既可用纯数学形式表述,也可用物理语言表述,虽然二者实质上是同一个论证。物理论证是:稀溶液中的一切化学反应要么是单分子的,要么是双分子的。三个分子发生反应时,其中必有两个先行相遇、形成某种大概或多或少不稳定的结合体,然后才与第三种物质反应。当把这些不稳定物质统统算作形态原时,就只剩下单分子与双分子反应,从而反应速率中也只剩线性项与二次项。要坚持这个观点,或许有必要把分子的激发态当作另一种化合物的分子来处理,但这样做显然无可厚非。

**〔印刷页 94〕**

数学论证同样通过引入新变量来进行;愿意的话,可以把这些变量想象为代表某种假想中间产物的浓度,即按照把反应分解为单分子与双分子反应的某个可能方案引入的产物。

要用二次速率函数就必须添设额外变量,这在那种本来就得承诺不定但有限个浓度变量的理论性讨论中显然算不上什么缺点。

虽然方程不再是线性的,方便的做法仍是沿用线性理论中的同样代换,即首先

```
r_mj = h_m + Σ_r Γ⁽¹⁾_mr v_rj                       (II.2.1)
```

其中 `f_m(h_1, …, h_M) = 0` 对一切 `m` 成立,亦即 `h_1, …, h_M` 代表一个均匀平衡。自然,若对系统内出现的每一种(溶液中的)物质都设有变量,则 `h_1 = h_2 = … = h_M = 0` 便是一个这样的平衡;但出于若干理由,最好不假定 `h_1, …, h_M` 取这些值。如果某些浓度实际恒定而未设变量的物质被略去了,零值就可能不是平衡。此外,零平衡绝不是一个有代表性的平衡,图灵(1952)所述的现象并非都能在这种平凡形式的平衡下出现。

**〔印刷页 95〕**

从 (II.1.10) 中消去诸 `X_ln(0)` 所得方程的 `M` 个不同根可记为 `p_l(α)`,`l` = 1, 2, …, `M`,并且存在数 `W_ml(α)` 使

```
(p_l(α) + μ_m α) W_ml(α) = Σ_s a_ms W_sl(α)        (II.2.2)
```


**〔印刷页 96〕**

### 3. 小生物体的方程(Equations for small organisms)

**〔印刷页 98〕**

若生物体的尺寸与最优波长相比不甚大,特征值 `α_r` 通常会分得很开——重根处除外。在这种情形下,上一节的若干近似可以更有说服力地得到辩护,因为在两个重要区间——即近最优波长区与近零区——各自可能只有一个需要考虑的 `α` 值。近最优波长的那个值很可能是重的;但如前已指出,对连通的生物体,零根是单根:`V_j(t)` 因此与位置无关。按 `V` 代表一种可扩散毒物的浓度这种观点,就是说生物体足够小,以致可以假定毒物在其上均匀分布。另一方面,函数 `U_j(t)` 必须是具有**同一**特征值的扩散特征函数的线性组合,换言之,即波长相同的波的组合。设 `𝒦` 是一个线性算子,它把一切不具有适当波长的分量统统滤去,则方程可写为〔译注14:(II.3.1)、(II.3.2) 残迹仅余 "`(P−HV)U_i + G𝒦U…`" 与 "`V = 𝒦U²`" 之形;系数与算子的确切归属系重构。〕

```
V = 𝒦 U² .                                          (II.3.2)
```

### 6. 随机扰动的影响(Effects of random disturbances)

**〔印刷页 101〕**

若有一个值 `p_k(α_r)` 超过其余一切值,则对几乎一切初始条件,项 `exp{i p_k(α_r)t}` 终将远远大于贡献于 `r_{ms}` 的任何其他项。此时系统的终极状态几乎与初始条件无关。即便终究要把非线性项计入,这也多半要等到这个占优势的项把其余各项甩开之后才会发生。然而,"存在若干个不同特征向量、其相应的扩散特征值 `α_r` 全都相等"的情形绝非罕见。在这种情形下,"甩开"论证只不过告诉我们:最终只须把使 `p_k(α_r)` 取最大值的那些特征向量包括进和式中;至于这些特征向量应以何种比例组合,它却丝毫未曾言明。按 §II.1 所阐述的理论,这本可以通过在某个早期时刻给出全部形态原的全部浓度而定出,此后一切时刻的浓度便随之确定。然而 §II.1 的理论在这一点上是出了错的,因为有一些被忽略了的小效应。这些效应在多数情形无关宏旨,但有时却不然,例如当系统临近一个不稳定平衡时。所涉的主要效应大概是:

(1) 化学反应的统计本性;

(2) 扩散的统计本性;

(3) 反应速率因细胞而异的变化,例如由于不可扩散的催化剂(不计入形态原)浓度互不相同;

(4) 细胞图案的不规则性——适用于细胞图案曾以某种方式被理想化的情形,例如把它视作构成一个球面。

要想为这些被忽略的效应开出一份完整的清单是没有意义的,因为整个研究本来就极其近似;但上面这份清单足以说明这类效应的性质。

只要人们关心的还是偏离均匀平衡的方式,便可以相当有把握地说:即使非线性效应终究要进入考虑,在这些微小扰动起作用的时期内,非线性项仍可略去。也可能出现这样的情形:一个非均匀平衡——其维持有赖于非线性项——变为不稳定,于是又是这些微小效应决定系统实际采取哪条路线。不过在这类情形中,可选的路线往往寥寥无几,而且通常存在一种对称性表明各条可能的路线同等概然:实际上无须任何详细理论。因此本节将假定线性理论适用。这真正意味着:假定在线性扰动发挥作用的期间线性理论适用,而并不把微分方程的推进一直追随到非线性项生效的时刻。本研究还将假定:扩散特征方程诸根的重性完全源于对称性。其局面与光谱理论中所出现的极为相似:在那里,能级的重性几乎总是源于对称性。

看来效应 (3)、(4) 的量级通常要比原子论式的效应 (1)、(2) 大一些。不过后者并未被置之不顾,这主要是因为后者的理论远为令人满意。

愿意的话,可以把一个形态发生系统径直描述为 `MN` 个数——各种形态原在各细胞中的浓度——而不对这些变量另作分类。设 `y_1, …, y_{MN}` 为这些变量,则方程可写成

```

```


也服从正态分布,且其方差为

```

─────  = Σ_s b_rs(t) y′_s(t) + N_r(t),              (II.6.3)
  dt
```


其中〔译注17:(II.6.3)、(II.6.4) 的残迹中夹有 "-ȳ′" 字样,或表示对平衡漂移的修正项;积分下限与求和指标的归属据上下文整理,存疑。〕
