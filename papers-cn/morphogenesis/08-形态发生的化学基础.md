## 1. 胚胎的一个模型.形态原(A model of the embryo. Morphogens)

**〔印刷页 1|原刊页 37〕**

> 建议用一类称为形态原(morphogen)的化学物质系统——它们彼此反应并扩散穿过组织——来解释形态发生的主要现象。这样一个系统,尽管起初可能完全是均匀的,后来却可能由于均匀平衡的失稳(由随机扰动触发)而发展出斑图或结构。本文对这类反应-扩散系统在"孤立细胞环"这一数学上方便、生物学上却不寻常的情形中作相当详细的考察。研究主要关心失稳的发生。发现失稳可以取六种本质上不同的形式。在最有趣的一种形式中,环上出现驻波。文中建议,这或许可以解释例如水螅(Hydra)的触手斑图和轮生叶。文中还考虑了球面上的反应与扩散系统,它看来可以解释原肠胚形成。另一个二维反应系统则产生令人想起斑驳花纹(dappling)的斑图。文中还建议,二维驻波可以解释叶序(phyllotaxis)现象。〔译注1〕
>
> 本文的目的是讨论一种可能的机制,合子的基因可以藉它决定所产生的生物体的解剖结构。理论不作任何新假设,只是提出:某些众所周知的物理定律足以解释许多事实。要完整理解这篇论文,需要良好的数学知识、一些生物学知识和一些初等化学知识。由于不能指望读者是所有这些学科的专家,文中解释了一些可以在教科书中找到的初等事实;若略去它们,论文将难以阅读。

本节将描述生长中胚胎的一个数学模型。这个模型是一种简化、一种理想化,因而也是一种失真。可以希望的是,保留下来加以讨论的那些特征,正是当前知识状况下最为重要的那些。

模型取略有不同的两种形式。其中一种承认细胞理论,但把细胞理想化为几何点;另一种则把生物体的物质想象为连续分布的。不过,细胞并没有被完全忽略,因为物质整体的种种物理和物理化学特性都被假定取与细胞物质相称的数值。

无论采用哪种模型,人们都像对待物理理论那样进行:定义一个称为"系统状态"的实体,然后描述该状态如何由片刻之前的状态来确定。无论哪种模型,状态的描述都由两部分组成:力学部分和化学部分。状态的力学部分描述各细胞的位置、质量、速度和弹性性质,以及它们之间的力。在理论的连续形式中,本质上相同的信息以物质的应力、速度、密度和弹性给出。状态的化学部分(在细胞形式的理论中)由每个细胞的化学组成给出;每种物质在每两个相邻细胞之间的扩散性(diffusibility)也必须给出。

**〔印刷页 2|原刊页 38〕**

在理论的连续形式中,则须给出每种物质在各点处的浓度与扩散性。在确定状态的变化时,应当考虑:

(i) 由牛顿运动定律给出的位置与速度的变化;

(ii) 由弹性与运动给出的应力,其中还要考虑到由化学数据得出的渗透压;

(iii) 化学反应;

(iv) 化学物质的扩散。扩散得以进行的区域由力学数据给出。

这样的叙述忽略了许多特征,例如电性质和细胞的内部结构。但即便如此,它在数学上仍是一个复杂得令人生畏的问题。目前,除了在非常简化的情形中,无法指望在对这类系统的理解上取得任何进展。化学数据与力学数据的相互依赖大大增加了困难,因此只要可能,注意力将限于二者可以分开的情形。弹性固体的数学是一门发展成熟的学科,并且常已应用于生物系统。本文拟关注的毋宁是可以忽略力学方面、而化学方面最为紧要的情形。这些情形有望更有趣味,因为基因本身的特征性作用据推测正是化学的。因此,实际要考虑的系统由不生长的组织块组成,其中有某些物质在进行化学反应,并正在穿过组织扩散。这些物质将称为**形态原(morphogen)**,这个词意在传达"形式产生者"的观念。它并不打算有任何十分确切的含义,而仅仅是这一理论所关心的那类物质。沃丁顿的**引发子(evocator)**提供了形态原的一个好例子(Waddington 1940)。这些引发子扩散进入组织,总能以某种方式说服组织沿着没有它时本会遵循的路线之外的路线发育。基因本身也可以看作形态原,但它们当然构成相当特殊的一类。它们极难扩散。而且,把基因看作独立的分子不过是客套;更准确的说法(至少在有丝分裂时)是把它们看作称为染色体的巨型分子的自由基。不过这些自由基据推测几乎是各自独立地起作用的,因此把基因看作分子不大会引起严重的差错。激素也可看作十分典型的形态原。皮肤色素如果愿意也可看作形态原。但本文要考虑其作用的那些形态原,并不方方正正地落在上述任何一个范畴之内。

基因的功能被推测为纯催化的。它们催化其他形态原的产生,后者又可能只是催化剂。最终,据推测,这条链会引向某些职责并非纯催化的形态原。例如,一种物质可能分解成若干较小的分子,从而增高细胞中的渗透压,促进其生长。于是可以说,基因是通过决定它们所催化的那些反应的速率来影响生物体的解剖形式的。如果假定这些速率就是由基因决定的那些,而且不涉及生物体之间的比较,那么基因本身便可从讨论中除去。

**〔印刷页 3|原刊页 39〕**

同样,任何经由基因的作用而间接获得的催化剂,只要不涉及其浓度的变化,也可以忽略。不过,可能还有其他一些引发子性质的形态原,不能完全置之脑后,但从特定器官形成的角度看,它们的作用仍可能是辅助性的。例如,设在胚胎的某个区域中正有一个"腿引发子"形态原产生出来,或者正扩散进入该区域,而我们试图解释在引发子存在时腿借以形成的机制。那么,把引发子在空间和时间中的分布当作预先给定的,进而考察由它引发的一系列化学反应,便是合理的。此处所考虑的少数几个例子采用的正是这一程序。

## 2. 所需的数学背景(Mathematical background required)

**〔印刷页 3|原刊页 39〕**

本文的大部分只需要中等程度的数学知识。主要需要的是理解常系数线性微分方程的解。(这也是理解力学振荡和电振荡主要需要的东西。)这种方程的解取 `Σ A e^(bt)` 的形式,其中量 `A`、`b` 可以是复数,即形如 `α + iβ`,其中 `α`、`β` 是普通(实)数,而 `i = √−1`。领会这类解的各种可能情形的物理意义极为重要,例如:

(a) 由于这些解通常将是实值的,也可以把它们写成 `Σ ℜA e^(bt)` 或 `Σ ℜ(A e^(bt))` 的形式(`ℜ` 意为"取实部")。

(b) 若 `A = A′e^(iφ)` 而 `b = α + iβ`,其中 `A′`、`α`、`β`、`φ` 为实数,则

`ℜA e^(bt) = A′e^(αt) cos(βt + φ)`.

于是,当 `α = 0` 时,这样的每一项代表一个正弦振荡;`α < 0` 时是一个衰减振荡;`α > 0` 时是一个振幅不断增大的振荡。

(c) 若任何一个数 `b` 具有正的实部,则所考虑的系统是不稳定的。

(d) 经过足够长的时间之后,与 `b` 具有最大实部的那些项相比,所有的项 `A e^(bt)` 都将可以忽略;但除非这个最大实部本身为零,这些占主导地位的项最终要么趋于零,要么趋于无穷值。

(e) (b)和(d)中提到的无限增长,在任何物理或生物学情形中最终都会因解赖以成立的假设失效而被遏止。例如,细菌群体的增长通常被取为满足方程 `dy/dt = ay`(`a > 0`),`y` 为 `t` 时刻的个体数,而此方程有解 `y = A e^(at)`。然而,当因子 `e^(at)` 达到数十亿时,食物供给便不能再看成无限的,方程 `dy/dt = ay` 不再适用。

下面这个相对初等的结果将会用到,但未必为所有读者所知:

`Σ_(h=0)^(N−1) e^(2πihs/N) = 0`,若 `0 < s < N`;但 `= N`,若 `s = 0` 或 `s = N`。

第一种情形,只要注意到左边是一个几何级数便可容易地证明;第二种情形中,所有各项都等于 1。

## 3. 化学反应(Chemical reactions)

**〔印刷页 4|原刊页 40〕**

前面一节已经说明,所要考虑的系统由若干化学物质(形态原)组成,它们在一块给定几何形状的组织中扩散,并在其中彼此反应。什么定律支配这种情形的发展?定律十分简单。扩散遵循通常的扩散定律,即每种形态原从浓度较高的区域移向浓度较低的区域,速率与浓度的梯度成正比,也与该物质的"扩散性"成正比。这很像热传导,扩散性扮演热导率的角色。若没有细胞壁,扩散性将与分子量的平方根成反比。细胞壁上的微孔,在较大分子自身惯性所施加的限制之外,又给它们的移动加上了进一步的不利,而大多数分子根本无法穿过细胞壁。

反应速率将被假定服从**质量作用定律(law of mass action)**。该定律说,一个反应进行的速率与各反应物质的浓度成正比。于是,例如,由反应

`Ag⁺ + Cl⁻ → AgCl`

从硝酸银溶液与氯化钠溶液中生成并沉淀出氯化银的速率,将与银离子 `Ag⁺` 的浓度和氯离子 `Cl⁻` 的浓度的乘积成正比。应当注意,方程

`AgNO₃ + NaCl → AgCl + NaNO₃`

并不被使用,因为它不对应任何一个实际的反应,而对应于若干个反应的最终结局。质量作用定律只能应用于实际的反应。常常有这样的情形:某些物质出现在一组的各个个别反应中,却不出现在整组的最终结局里。例如,反应 `A → B` 实际上可能采取两个步骤 `A + G → C` 与 `C → B + G` 的形式。这时物质 `G` 被描述为催化剂,并说它催化反应 `A → B`。(按这种方案进行的催化已由 Michaelis 与 Menten(1913)详细考虑过。)基因的作用据推测几乎完全是通过催化实现的。它们当然不会在反应中被永久地消耗掉。

有时可以把催化剂的作用仅仅看成改变一个反应的速率。考察上面提到的那个例子,但再设 `A` 能从 `G` 上脱开,即把反应 `C → A + G` 也考虑在内;又设反应 `A + G ⇌ C` 两个方向都远比 `C → B + G` 进行得快。于是 `A`、`G`、`C` 的浓度将由 `A + G → C` 与 `C → A + G` 之间的平衡条件联系,从而(用方括号表示浓度)`[A][G] = k[C]`,`k` 为某个常数。反应 `C → B + G` 当然将以与 `[C]` 成正比的速率进行,也就是与 `[A][G]` 成正比。如果 `C` 的量总比 `G` 的量小,就可以说:催化剂的存在及其数量仅仅改变了反应 `A → B` 的质量作用常数,

**〔印刷页 5|原刊页 41〕**

因为整个过程以与 `[A]` 成正比的速率进行。然而,这种情况并不总能成立。很可能只要还有 `A` 剩下,`G` 就几乎全部取结合的形式 `G′`。在这种情形下,反应以与 `A` 的浓度无关的速率进行,直到 `A` 被完全耗尽。无论哪种情形,整组反应的速率都只依赖于各试剂的浓度,尽管通常并不符合把质量作用定律粗糙地套用到整组化学方程上所得的结果。凡是整组反应中除一个例外、其余都以远快于该例外的速度进行的情形,同样如此。在这些情形中,反应速率是各试剂浓度的函数。更一般的情形则没有任何这类近似可用,只能把所有实际的反应都考虑进来。

于是,按照细胞模型,细胞的数目与位置是预先给定的,各种形态原在细胞之间扩散的速率也是给定的。设有 `N` 个细胞、`M` 种形态原。整个系统的状态由 `MN` 个数给出,即 `N` 个细胞中 `M` 种形态原各自的量。这些数随时间变化,一部分由于反应,一部分由于扩散。要确定其中某个数在任一时刻的变化率中由扩散贡献的部分,只需知道同一种形态原在该细胞及其相邻细胞中的量,以及该形态原的扩散系数。要确定由化学反应贡献的变化率,只需知道所涉及的那个细胞此刻全部形态原的浓度。

用各细胞中的浓度来描述这个系统,当然只是一种近似。举例来说,如果内含物被彻底搅拌,它就是有根据的;或者,它也常常可以在这样的理解下成立:"细胞中的浓度"是某个有代表性的点处的浓度,尽管"一点处的浓度"这个概念本身显然也会带来困难。作者相信,无论用什么论证来为它辩护,这个近似都是好的,而且它无疑是方便的。

把理论的大部分推广到浸没于流体中的生物体、并同时考虑流体内部的扩散与细胞之间的扩散,是可能的。但此类问题不在本文考虑之列。

## 4. 对称性与均匀性的破缺(The breakdown of symmetry and homogeneity)

**〔印刷页 5|原刊页 41〕**

表面上看,这个形态发生理论——其实几乎任何别的形态发生理论也一样——似乎面临一个困难。处于球形囊胚阶段的胚胎具有球对称性;即使有对完美对称的偏离,也不能认为有什么特别的重要性,因为同种生物各胚胎之间的这些偏差差异很大,而由它们发育成的生物体却几乎无从分辨。因此可以认为存在完美的球对称。但是,一个具有球对称性、其状态正因化学反应与扩散而变化的系统,将永远保持球对称。(如果状态按照电学与磁学的定律、或量子力学的定律变化,同样如此。)它当然不可能产生像马这样并非球对称的生物体。

**〔印刷页 6|原刊页 42〕**

这个论证有一个漏洞。论证中假设囊胚对球对称的偏离可以忽略,因为不对称取什么形式无关紧要。然而,存在某些偏离这件事本身是重要的,因为系统可能达到一种失稳状态,其中这些不规则性、或它们的某些分量,倾向于增长。若发生这种情况,通常会达到一个新的稳定平衡,而对称性荡然无存。这种新平衡的多样性通常不会像引起它们的不规则性的多样性那样大。例如,在本文末尾讨论的原肠形成球的情形中,原肠轴的方向可以变化,但仅此而已。

这种情况与电路振荡器中出现的情形非常相似。一个振荡器一旦起振,如何维持振荡通常容易理解;但初识者却不容易明白振荡如何开始。解释是:电路中总有随机扰动存在。频率恰好等于振荡器固有频率的任何扰动都倾向于使它起振。系统的最终命运是以适当的频率振荡,且振幅(和波形)也由电路确定;只有振荡的相位由扰动确定。

如果化学反应与扩散是所考虑的仅有物理变化形式,上述论证可以取略有不同的形式。因为,如果系统起初不具有任何一种几何对称性,而是一块完全均匀、但形状可能不规则的组织,它将无限期地保持均匀。然而实际上,不规则性——包括参与各种反应的分子数的统计涨落——的存在,若系统具有适当类型的失稳,将导致这种均匀性消失。

对称性或均匀性的这种破缺,可以用一对细胞来说明,两细胞最初具有相同的、或非常接近相同的内容物。系统是均匀的:它对于交换两个细胞的操作也是对称的。将设每个细胞的内容物可用两种形态原的浓度 `X` 和 `Y` 来描述。化学反应将被设为:按净计,第一种形态原(`X`)以速率 `5X − 6Y + 1` 产生,第二种(`Y`)以速率 `6X − 7Y + 1` 产生。然而,当这些公式的严格应用会导致某个细胞中一种形态原的浓度变为负值时,则理解为:它改以它通过扩散到达该细胞的速率被销毁。第一种形态原将设为在两细胞间单位浓度差下以速率 `0.5` 扩散,第二种在同一差值下以速率 `4.5` 扩散。现在,若两种形态原在两个细胞中都有单位浓度,则存在平衡:没有任何一种形态原的净穿越细胞壁流动,因为没有浓度差;也没有任何一种形态原在任一细胞中的净产生(或销毁),因为 `X = 1`、`Y = 1` 时 `5X − 6Y + 1` 和 `6X − 7Y + 1` 二者都取值为零。但设两细胞的值为 `X₁ = 1.06`、`Y₁ = 1.02` 与 `X₂ = 0.94`、`Y₂ = 0.98`。于是,在第一个细胞中,两种形态原正以速率 `0.18`、`0.22` 由化学作用产生,而在第二个细胞中以同样速率被销毁。与此同时,扩散引起从第一个细胞到第二个细胞的流动,第一种形态原的速率为 `0.06`,第二种为 `0.18`。

**〔印刷页 7|原刊页 43〕**

总的效果是两种形态原分别以速率 `0.12`、`0.04` 从第二个细胞流向第一个细胞。这一流动倾向于加深两细胞间已经存在的差异。更一般地,若在某时刻 `X₁ = 1+ξ`、`X₂ = 1−ξ`、`Y₁ = 1+ξ/3`、`Y₂ = 1−ξ/3`,则四个浓度此后仍能表示成这种形式,而 `ξ` 以速率 `2ξ` 增长。〔译注3〕于是可以看到,几乎任何从平衡条件出发的小位移都会引起离开平衡的漂移,尽管通常并非沿一条精确的指数曲线。上面的论证里作了一个特殊选择,为的是只用非常简单的数学把这种漂移展示出来。

在可以断言双细胞系统能够不稳定、非均匀继均匀而起之前,必须表明所设的反应速率函数真的能够出现。指定出给出这些函数的具体物质、浓度和温度固然可以把问题最终敲定,但那将很困难,而且多少有违本次探究的精神。替代做法是,只提及一些假想的反应,它们在假定适当的反应常数后,按质量作用定律正好给出所需的函数。描述下面几组就足够了:

(i) 一组以恒定速率 `1` 产生第一种形态原的反应,以及一组以同一速率形成第二种形态原的类似反应;

(ii) 一组以速率 `7Y` 销毁第二种形态原(`Y`)的反应;

(iii) 一组以速率 `6X` 把第一种形态原(`X`)转变为第二种(`Y`)的反应;

(iv) 一组以速率 `11X` 产生第一种形态原(`X`)的反应;

(v) 一组以速率 `6Y` 销毁第一种形态原(`X`)的反应,只要有 `X` 存在。

条件 (i) 可以由 `A → X`、`B → Y` 型的反应实现,其中 `A` 和 `B` 是以大而不变的浓度持续存在的物质。条件 (ii) 由形如 `Y → D` 的反应满足(`D` 为惰性物质),(iii) 由反应 `X → Y` 或 `X → Y + E` 满足。剩下的两组较为困难。要满足 (iv),可以设 `X` 是它自身从 `A` 生成反应的催化剂:实际反应可以是由反应

`A + X → U`

生成不稳定化合物 `U`,随后 `U` 几乎瞬时地分解为

`U → 2X`。

要按 (v) 的要求以与 `Y` 成正比的速率销毁 `X`,可以设有一种催化剂 `C` 以小而恒定的浓度存在,并立即与 `X` 结合,

`X + C → V`。

改型后的催化剂以与 `Y` 成正比的速率与 `Y` 反应,从而恢复催化剂但不恢复形态原 `X`,所经反应为 `V + Y → W`、`W → C + E`,其中后者被假定为瞬时的。〔译注4〕

应当强调,此处描述的反应绝非自然界中最可能引起失稳的那些。选择这些反应来讨论,完全是因为论证易于跟随这一点是可取的。更合理的反应系统在 §10 中描述。

不稳定平衡当然不是一种很自然地出现的条件。它通常需要某种相当人为的干预,比如把一颗弹子放到穹顶上。由于系统总会离开不稳定平衡,它们不会经常处于这种平衡之中。然而,这样的平衡可以自然地出现——经由一个稳定平衡转变为不稳定平衡。例如,一根杆从略高于其重心的一点悬挂着,它处于稳定平衡;但若有一只老鼠爬上杆,平衡最终变为不稳定,杆开始摆动。这个"老鼠与摆"系统的一个化学类比,就是前面描述的系统、同样的扩散性,而两种形态原的产生速率为 `(3+γ)X − 6Y + γ − 1` 与 `6X − (9+γ)Y − γ + 1`。〔译注5〕这个系统当 `γ < 0` 时稳定,而当 `γ > 0` 时不稳定。若让 `γ` 逐渐增大——对应于老鼠向摆的上端跑去——它最终将变为正,平衡随之崩塌。原先讨论的那个系统是 `γ = 2` 的情形,不妨设想对应于老鼠安然无恙地以某种方式到达了摆的顶端,也许是垂直掉上去的。

## 5. 左手型与右手型生物(Left-handed and right-handed organisms)

**〔印刷页 8|原刊页 44〕**

本节的目的是讨论一个也许会被认为足以表明形态原的形态发生理论不可能正确的困难。这个困难主要关乎不具有左右对称(bilateral symmetry)的生物体。论证虽然在此不用数学公式展开,非数学读者仍可能觉得难懂,因此建议他们略过本节,除非他们确实已被此类困难困扰。

说一个生物体具有**左右对称(bilateral symmetry)**,如果它与自身在某个平面中的反射像相同。这个平面当然总得穿过生物体的某部分,特别是穿过它的重心。就本论证而言,考虑可称为"左右手对称(left-right symmetry)"的概念更为一般:若一个生物体在任一组右手直角笛卡尔坐标下的描述,与它在某组左手坐标下的描述相同,则说它具有左右手对称。一个具有左右手对称而不具有左右对称的例子:一个圆柱体,一端印着字母 P,另一端印着 P 的镜像,但两个字母的两条竖笔互不平行。就生物世界而言,这一区别也许只是名异实同,但在数学上不应忽略。

若某物种的个体彼此足够相像,而左右手对称的缺失又足够显著,就有可能把每个个体描述为右手型或左手型,而不至于难以归类。例如在人,可以取 `X` 轴向前,`Y` 轴与之成直角、指向心尖所在一侧,`Z` 轴向上。依这样选定的坐标系是左手系还是右手系,把标本归为左手型或右手型。当然,每个物种都得重新定义一套归类法。

存在不具有左右手对称的生物体,这件事本身并不造成任何困难。前面已经解释过,发育过程中各种对称性如何可以丧失——由于影响该特定标本的特定扰动("噪声")不具备那种对称性,再配合适当类型的失稳。困难在于:有些物种中左手型与右手型的比例非常悬殊。最好先叙述一个表面上表明这不应该发生的论证。

**〔印刷页 9|原刊页 45〕**

这个论证非常一般,可应用于非常广泛的一类形态发生理论。一个实体,若它在某组右手坐标下的描述与它在任何其他同原点右手坐标下的描述相同,则可描述为**P-对称(P-symmetrical)**。于是,例如,一把开瓶器绕原点作一切可能的旋转所取位置的全体的集合,具有 P-对称。若从右手坐标换成左手坐标的变换也可以作,则说该实体是 **F-对称(F-symmetrical)** 的。若把开瓶器换成一个左右对称的物体(如煤斗),或一个左右手对称的物体,就属于这种情形。用这些术语可以说:存在这样的物种,其标本的全体连同旋转后的标本,是 P-对称的,但离 F-对称很远。另一方面,合理地假设:

(i) 物理学定律是 F-对称的;

(ii) 该物种合子(zygote)的初始全体是 F-对称的;

(iii) 扰动的统计分布是 F-对称的。个别扰动当然一般既无 P-对称也无 F-对称。

应当注意,上面定义的 P-对称与 F-对称的概念,甚至适用于"物理学定律"这样精致的实体。还应理解,这些定律是所讨论理论中实际考虑的定律,而非某种尚未发现的理想定律。

由这些假设可以推出,所得生物体的统计分布将具有 F-对称;更严格地说,把这样一个理论推演出来所得的分布将具有这种对称。然而,观察到的成熟生物体的分布没有这种对称。首先,例如,人更多被发现站在脚上而不是头上。这一点可以通过在定律中考虑重力、并相应改变两种对称的定义来修正。但为了论证起见,更方便的是设想某个物种是在无重力环境中养育的,而所得成熟生物体的分布被发现是 P-对称的,却产出右手型标本多于左手型,

**〔印刷页 10|原刊页 46〕**

从而不具有 F-对称。于是,剩下的就是解释这种 F-对称的缺失。

显然,假设 (i)–(iii) 中必有某一个错误,即在正确的理论中,它们之一不成立。在前面描述的形态原理论中,这三个假设全都成立,因此必须承认它有某种缺陷。理论可以这样修正:考虑到形态原的左旋与右旋分子数目并不总相等这一事实。依观点不同,可以把这一点看作使 (i)、(ii) 乃至 (iii) 失效。最简单的说法也许是:合子的全体根本不是 F-对称的,看一看那些分子就能明白。不过,从本文的观点看这不太令人满意,因为这与只用浓度来描述状态的做法不相容。若能找到关于反应与扩散的更精确定律,那会更可取。为了解释左右手生物数目不等,只需表明:存在一些当形态原为左旋或右旋时便不是 F-对称的修正项,且其大小足以解释观察到的效应,这样就够了。想出这样的效应并不很难。它们不必很大,但当然必须大于纯统计性效应,如热噪声或布朗运动。

合子全体不是 F-对称的,也可能有别的原因,例如染色体本身的不对称。如果这些也产生足够大的效应,那就更好了。

尽管这些效应比起统计扰动可能很大,但比起通常的扩散与反应效应,它们几乎可以肯定是很小的。这将意味着,只有在左右手对称正在破缺的那一小段时间内,它们才有可觉察的效应。它们的存在一旦被承认——无论在理论上还是实验上——大概最方便的数学表达,是把它们视为 P-对称地(但非 F-对称地)分布的扰动。不过,本文不再进一步考虑它们。

## 6. 环形细胞链中的反应与扩散(Reactions and diffusion in a ring of cells)

**〔印刷页 10|原刊页 46〕**

当初之所以考虑均匀性的破缺,缘起于形态发生扩散-反应理论中一个表面上的困难。如今困难既已解决,人们或许会以为,问题的这一方面已无理由再追究下去,最好是进而去考察系统远非均匀时会出现什么情形。然而,对均匀性的破缺仍将给予多得多的关注。这主要是因为,"系统仍接近均匀"这一假设使问题落入数学上所能处理的范围之内;即便如此,仍须再作许多进一步的简化假设。给予这一阶段如此关注的另一个理由是,它在某种意义上是最关键的时期。也就是说,倘若对生物体将如何发育尚存疑问,可以设想,在失稳刚刚开始之后对它作一番细致的考察,或许就能把问题定下来;而在任何更早时刻的考察,都决不可能做到这一点。

可以考虑的细胞几何排布多种多样,但有一类构型格外醒目:它的理论特别简单,同时又能极好地展示一般原理。这构型就是由相似细胞组成的一个环。可设这样的细胞共有 `N` 个。必须承认,并不存在可以立即应用环理论的生物学实例;不过,要找到一些使环所阐明的原理得以适用的实例,并不困难。

起初将假设只有两种形态原,或者更确切地说,只有两种有趣的形态原。可能还有其他一些形态原,其浓度既不随空间、也不随时间变化;或者,它们可以因这种那种理由而从讨论中剔除。这些其他的形态原可以例如是涉入两种有趣形态原之间反应的催化剂〔译注6:文本层此处作 "for instanse",当为 for instance 之误(未排除原书排印错误),已按此理解译出。〕。一个完整反应系统的例子见 §10。§§8、9 中还将对三形态原的情形给予一些考虑。读者把结果推广到任意数目的形态原当无困难;不过数目超过三以后,并不出现任何本质上的新特征。

两种形态原将称为 `X` 与 `Y`。这两个字母也将用来表示它们的浓度,这不会引起任何真正的混淆。

**〔印刷页 11|原刊页 47〕**

`X` 在细胞 `r` 中的浓度可写作 `X_r`,`Y_r` 有类似的含义。把"细胞 `N`"与"细胞 `0`"视为同义是方便的,"细胞 `1`"与"细胞 `N+1`"亦然。于是可以说,对每个满足 `1 ≤ r ≤ N` 的 `r`,细胞 `r` 通过扩散与细胞 `r−1`、`r+1` 交换物质。〔译注7:本节源文本中若干记号损坏——斜体 `N` 多被识作 "TV" 或失落,`μ` 识作 "//",`Y` 识作 "V","t = 0" 识作 "/ = 0","≤" 识作 "<" 等——均据上下文复原,不影响译文。〕`X` 的细胞间扩散常数将称为 `μ`,`Y` 的将称为 `ν`。这意味着,在 `X` 的单位浓度差之下,该形态原以速率 `μ` 从浓度较高的细胞流到浓度较低的(相邻)细胞。关于化学反应的速率,也必须作出假设。所能作的最一般假设是:在浓度 `X`、`Y` 之下,化学反应正以速率 `f(X, Y)` 使 `X` 趋于增加,以速率 `g(X, Y)` 使 `Y` 趋于增加。把扩散所致的 `X`、`Y` 变化也计入之后,系统的行为便可由下列 `2N` 个微分方程描述:

`dX_r/dt = f(X_r, Y_r) + μ(X_{r+1} − 2X_r + X_{r−1})`,`dY_r/dt = g(X_r, Y_r) + ν(Y_{r+1} − 2Y_r + Y_{r−1})`(r = 1, …, N)　　(6.1)

若 `f(h, k) = g(h, k) = 0`,则一个孤立的细胞有一个平衡态,浓度为 `X = h`、`Y = k`。环系统也有一个平衡态——或稳定或不稳定——其中每个 `X_r` 都等于 `h`,每个 `Y_r` 都等于 `k`。设系统离这个平衡不远,令 `X_r = h + x_r`、`Y_r = k + y_r` 是方便的。还可以把 `f(h+x, k+y)` 写成 `ax + by`,把 `g(h+x, y+k)` 写成 `cx + dy`。既然 `f(h, k) = g(h, k) = 0`,便无须常数项;又因 `x`、`y` 都假定很小,`x`、`y` 高次幂的各项影响相对甚微,忽略它们是有道理的。`a`、`b`、`c`、`d` 这四个量可以称为**边际反应速率**(marginal reaction rates),合起来可以描述为**边际反应速率矩阵**(marginal reaction rate matrix)。当有 `M` 种形态原时,这个矩阵由 `M²` 个数组成。边际反应速率具有时间倒数的量纲,就像放射性衰变率,后者事实上正是边际(核)反应速率的一个例子。

在这些假设之下,方程可以改写为

`dx_r/dt = a·x_r + b·y_r + μ(x_{r+1} − 2x_r + x_{r−1})`,`dy_r/dt = c·x_r + d·y_r + ν(y_{r+1} − 2y_r + y_{r−1})`　　(6.2)

为求解这些方程,引入新坐标 `ξ_0, ξ_1, …, ξ_{N−1}` 与 `η_0, η_1, …, η_{N−1}`,令

`x_r = Σ_(s=0)^(N−1) ξ_s exp[2πirs/N]`,`y_r = Σ_(s=0)^(N−1) η_s exp[2πirs/N]`　　(6.3)

这些关系也可以写成

`ξ_s = (1/N) Σ_(r=1)^(N) x_r exp[−2πirs/N]`,`η_s = (1/N) Σ_(r=1)^(N) y_r exp[−2πirs/N]`　　(6.4)

`Σ_(r=1)^(N) exp[2πirs/N] = 0`(若 0 < s < N);`= N`(若 s = 0 或 s = N)　　(6.5)

的根,则方程组的解形如

`ξ_s = (A_s + B_s t)e^(p_s t)`,`η_s = (C_s + D_s t)e^(p_s t)`

而 (6.10) 仍然成立。把 (6.3) 代回,并把变量 `x_r`、`y_r` 换成 `X_r`、`Y_r`(实际浓度),解便可写成

`X_r = h + Σ_(s=0)^(N−1) (A_s e^(p_s t) + B_s e^(p′_s t)) exp[2πirs/N]`,`Y_r = k + Σ_(s=0)^(N−1) (C_s e^(p_s t) + D_s e^(p′_s t)) exp[2πirs/N]`　　(6.11)

这里 `A_s`、`B_s`、`C_s`、`D_s` 仍由 (6.10) 相联系,但除此之外是任意的复数;`p_s` 与 `p′_s` 是 (6.8) 的根。

**〔印刷页 13|原刊页 49〕**

表达式 (6.11) 给出了方程组 (6.1) 的通解,所依据的假设是:对均匀性的偏离足够小,函数 `f(X, Y)` 与 `g(X, Y)` 可以放心地取为线性。所给出的 (6.11) 这一形式本身说明不了多少东西,它将在 §8 中得到相当大的简化。另一个隐含的假设关乎随机的扰动影响。严格说来,应当认为这类影响是在持续不断地起作用,但这会使数学处理困难得多,而结论却不至于实质改变。这里(以及 §8 中)的分析所隐含的假设是:系统在 `t = 0` 时刻的状态并非均匀状态,因为它已被扰动推离了那样的状态;而在 `t = 0` 之后,进一步的扰动便被忽略。§9 将在没有后一假设的情况下重新考虑这一理论。

## 7. 连续的组织环(Continuous ring of tissue)

**〔印刷页 13|原刊页 49〕**

作为分离细胞环的替代,也可以考虑连续的组织环。这时,环上一点的位置可以由过该点的半径与一条固定的参考半径所成的夹角 `θ` 来描述。设两种物质的扩散性为 `μ′` 与 `ν′`。它们与上一节的 `μ`、`ν` 并不完全相同,因为 `μ`、`ν` 实际上是以细胞直径作为长度单位,而 `μ′`、`ν′` 则以某一约定单位计——即量度环半径 `ρ` 时所用的同一单位。方程为

`∂X/∂t = a(X−h) + b(Y−k) + (μ′/ρ²)·∂²X/∂θ²`,`∂Y/∂t = c(X−h) + d(Y−k) + (ν′/ρ²)·∂²Y/∂θ²`　　(7.1)

可以看出,它们正是 (6.2) 的极限情形。边际反应速率 `a`、`b`、`c`、`d` 仍如前,是 `∂f/∂X`、`∂f/∂Y`、`∂g/∂X`、`∂g/∂Y` 在平衡位置处的值。方程的通解为

`X = h + Σ_(s=−∞)^(∞) (A_s e^(p_s t) + B_s e^(p′_s t)) e^(isθ)`,`Y = k + Σ_(s=−∞)^(∞) (C_s e^(p_s t) + D_s e^(p′_s t)) e^(isθ)`　　(7.2)

其中 `p_s`、`p′_s` 现在是

`(p − a + μ′s²/ρ²)(p − d + ν′s²/ρ²) = bc`　　(7.3)

的根,并且

`A_s(p_s − a + μ′s²/ρ²) = bC_s`,`B_s(p′_s − a + μ′s²/ρ²) = bD_s`　　(7.4)

此解可以由取解 (6.11) 的极限情形来论证;或者,可以注意到所给的公式确为一个解,于是只须再证明它便是最一般的解,而这只须证明:

**〔印刷页 14|原刊页 50〕**

为适合任意给定的初值,总能够找到 `A_s`、`B_s`、`C_s`、`D_s`。众所周知,角的函数(如 `X`)可以展开为"傅里叶级数"

`X(θ) = Σ_(s=−∞)^(∞) G_s e^(isθ)`(`X(θ)` 为 `t = 0` 时 `X` 的值)

——例如,只须它的一阶导数是连续的即可。若 `Y(θ)` 亦同样展开为

`Y(θ) = Σ_(s=−∞)^(∞) H_s e^(isθ)`(`Y(θ)` 为 `t = 0` 时 `Y` 的值)

则当 `A_s + B_s = G_s`、`C_s + D_s = H_s` 时,所需的初始条件便得到满足。除非 `p_s = p′_s`,满足这些条件的 `A_s`、`B_s`、`C_s`、`D_s` 总是可以找到;这是一个例外的情形,其解在需要时可以作为正常情形的极限求得。

## 8. 一段时间之后环中渐近行为的类型(Types of asymptotic behaviour in the ring after a lapse of time)

**〔印刷页 14|原刊页 50〕**

如 §2 所提醒的,经过一段时间之后,形如 (6.11) 的表达式的行为最终由相应的 `p_s` 实部最大的那些项支配。然而,实部取同一数值的项可能不止一个,这些项将共同支配局面,其余各项相形之下皆可忽略。事实上,这样的"支配项"(leading terms)通常有两项或四项。因为,若 `p_{s₀}` 为其中之一,则 `p_{N−s₀} = p_{s₀}`;由于

`sin²(πs₀/N) = sin²(π(N−s₀)/N)`

所以 `p_{s₀}` 与 `p_{N−s₀}` 是同一个方程 (6.8) 的根。若 `p_{s₀}` 又是复数,则 `ℜp_{s₀} = ℜp′_{s₀}`,于是总起来有

`p_{N−s₀} = p̄_{s₀},  p′_{N−s₀} = p̄′_{s₀}`

不过,通常不必预期还须纳入更多的项。若要 `p_{s₀}` 与 `p_{s₁}` 有相同的实部,那么除非 `s₁ = s₀` 或 `s₀ + s₁ = N`,诸量 `a`、`b`、`c`、`d`、`μ`、`ν` 便须受限制去满足某种特殊条件,而这种条件它们凭偶然殆不可能满足。倘若这样的特殊条件得到满足,确实可以找到必须纳入多至十项的情形,但这些情形并无特殊的物理或生物学意义。以下假定这类偶然关系一概不成立。

已经看到,有必要就支配项之一的 `p_{s₀}` 取实数值还是取复数值区分两种情形。它们可分别称为**定常情形**(stationary case)与**振荡情形**(oscillatory case)。

**定常情形。**经过充分长的时间后,`X_r − h` 与 `Y_r − k` 渐近于下列形式:

`X_r − h = 2ℜ{A_{s₀} exp[2πir s₀/N + It]}`,`Y_r − k = 2ℜ{C_{s₀} exp[2πir s₀/N + It]}`　　(8.1)

**振荡情形。**经过充分长的时间后,`X_r − h` 与 `Y_r − k` 渐近于下列形式:

`X_r − h = 2ℜ{e^(2πir s₀/N) [A_{s₀} e^((I+iω)t) + Ā_{N−s₀} e^((I−iω)t)]}`,`Y_r − k = 2ℜ{e^(2πir s₀/N) [C_{s₀} e^((I+iω)t) + C̄_{N−s₀} e^((I−iω)t)]}`　　(8.2)

**〔印刷页 15|原刊页 51〕**

`p_{s₀}` 的实部记作 `I`,代表 instability(失稳度);在振荡情形,其虚部是 `ω`。借助 `ℜ` 运算(取实部),上两式中每种情形的两个项都各被合并成了一项。

这些公式的含义用波来描述最为方便。在定常情形,环上有 `s₀` 个波瓣(即波峰)的驻波。系数 `A_{s₀}` 与 `C_{s₀}` 之比由 (6.10) 给出,是确定的,因此一种形态原的图样决定了另一种形态原的图样。只要存在真正的失稳,即 `I` 为正,波便随着时间的推移而愈发显著。波的波长可由环的周长除以波瓣数得出。

在振荡情形,解释与此类似,但波现在不是驻波而是行波。它们除波长之外还有速度和频率。频率是 `ω/2π`,速度由波长乘以频率得出。共有两列波,绕环沿相反方向行进。

环上图样的波长并非只依赖化学数据 `a`、`b`、`c`、`d`、`μ′`、`ν′`,还依赖环的周长,因为波长必须能整除环周。然而在某种意义上,存在一个不依赖环之尺寸的"化学波长"(chemical wave-length)。它可以描述为:当环相继做大时,各波长所趋向的极限;或者(至少在连续组织的情形),它可描述为:把半径取得使失稳度 `I` 尽可能大时所对应的波长。不妨这样来设想这幅图景:化学波长是真正的波长,凡属可能即被达成;而在环上,则只好"将就"用一个能精确整除周长的近似值。

虽然定常与振荡两种选择已经穷尽了一切可能,其中仍有几个特例值得单独处理。其一出现于 `s₀ = 0` 时,可称为"极端长波长"(extreme long wave-length)的情形——尽管这个术语也许更宜保留下来,专门描述那样的化学数据:不论环的尺寸如何,`s₀` 恒为零。此外还有"极端短波长"(extreme short wave-length)的情形,这意味着 `sin²(πs₀/N)` 取到尽可能大的值,实现方式是 `s₀` 取 `½N` 或 `½(N−1)`。若把其余的可能性视为构成"有限波长"的情形,则总共有六种子情形。下面将证明,这六种情形每一种都确实能够出现,尽管其中两种需要三种或更多形态原才能实现。

**(a) 极端长波长的定常情形。**例如,当 `μ = ν = ½`、`b = c = 1`、`a = d` 时便出现这种情形。〔译注8:源文本层此处系数残损:(a) 例之 "μ = ν = ½" 识作 "μ = ρ —",p_s 式中正弦的宗量亦失落;(b) 例之 "½" 识作 "J"。均据上下文复原。〕此时

`p_s = a − sin²(πs/N) + 1`

它必为实数,且当 `s = 0` 时最大。在这种情形下,所有细胞的内容物完全相同;没有因扩散而造成的从细胞到细胞的净流动,于是每个细胞的行为就如同它是孤立的一样。每个细胞都处于不稳定平衡之中,并与其余细胞同步地从这一平衡上滑落。

## 9. 对环的数学问题的进一步考察(Further consideration of the mathematics of the ring)

**〔印刷页 18|原刊页 54〕**

本节考虑有关波样发育的若干更精细之点。这些内容主要供有意在此题目上作进一步研究的读者参考,初读时可径行略去。

**(1) 两个形态原情形的一般公式。**取大半径环(或细丝)的极限情形,可在 (6.11) 中写 `sin²(πs/N) = U = (πs/N)²`,或在 (7.3) 中写 `U = s²/ρ²`,从而得到

`(p − a + μ′U)(p − d + ν′U) = bc　　(9.1)`

它有解

`p = ½[a + d − (μ′ + ν′)U ± √{(a − d + (μ′ − ν′)U)² + 4bc}]　　(9.2)`

可以把此式的实部记作 `I(U)`,它代表波长为 `λ = 2πU^(−½)` 的波的失稳度。占主导的波对应于 `I(U)` 的极大值。这一极大值或位于 `U = 0`,或位于 `U = ∞`,或位于曲线中双曲(而非直线)部分的一个驻点上。当最后一种情形发生时,极大值处的 `p`(或 `I`)与 `U` 之值为

`p = I = {aμ′ − dν′ − 2√(μ′ν′)√(−bc)}/(μ′ − ν′)　　(9.3)`

## 11. 结果的重述与生物学解释(Restatement and biological interpretation of the results)

**〔印刷页 30|原刊页 66〕**

某些读者或已略去 §§6–10 的详细数学处理。为便于他们,这里把假设与结果简要重述,重点略有不同。

所考虑的系统,或是由各与其邻胞接触的细胞组成的环,或是连续的组织环。两种情形的效应极为相似;就本摘要而言无须区分。只考虑了含两三种形态原的系统,但结论相当普遍。系统设起初处于稳定的均匀状态,但因某些未指明的影响——如布朗运动、邻近结构的效应、形态上的轻微不规则——而略受扰动。又设所考虑的两三种形态原的反应速率(或扩散性)正在缓慢变化。这些变化或可归因于充当催化剂或燃料供应的其他形态原的浓度变化、细胞的同步生长、或温度的改变。这些变化最终被设想把系统带出稳定状态。系统恰在不稳定时的现象,正是研究的主题。为使问题在数学上可以处理,必须假设系统从不偏离原均匀状态太远。这一假设称为"线性假设",因为它容许以线性函数代替一般的反应速率函数。线性假设是一个严重的假设。其理由在于:它成立的早期所产生的斑图,可望与它不成立的后期流行的斑图有强烈的定性相似。数学理论开头还作了其他较不重要的假设,其详细效应多半已在 §9 中考虑过,定性上无关宏旨。

所得结论如下。自失稳开始,经过一段时间后,出现一个最好用"波"来描述的形态原浓度斑图。可能出现的有六种类型。

**(a)** 平衡浓度与反应速率可能变得使具有环中任一细胞同样内容的孤立细胞也不稳定。若该细胞像一根竖立的棍子倒下那样偏离平衡位置,则在环中,每个细胞都可望同样做。相邻细胞中的偏离可望方向相同,但在远处的细胞,例如在直径两端,则没有理由期望如此。

这是诸情形中最无趣的。不过,它或许能解释"斑驳"(dappled)色彩斑图;图 2 给出了由此类过程产生的二维斑图的一个例子,以与"斑驳"比较。若斑驳斑图要这样解释,它们必须在胚胎仅几英寸长时以潜在形式定下;后来距离会大得使形态原无法借扩散抵达。

**(b)** 此情形与 (a) 相似,只是偏离平衡不是单向漂移而是振荡性的。与 (a) 一样,远距离细胞的内容之间可能不一致。这种代谢振荡大概有许多生物学例子,但作者所知尚无真正令人满意者。

**(c)** 可能有偏离平衡的漂移,它在相邻细胞中方向相反。未知道任何生物学例子。

**(d)** 环上有定常波斑图,无时间变化,只有振幅的缓慢增长,即斑图缓慢地变得愈益显著。连续组织环的情形中,斑图是正弦式的,即一种形态原的浓度对环上位置作图是一条正弦曲线。波的峰将沿环均匀间隔。峰数可近似地由环周除以系统的所谓"化学波长"而得;两形态原情形的化学波长由公式 (9.3) 给出。当然,这样算出的峰数不是整数;实际峰数总将是与之最接近的两个整数之一,且通常就是最近者。失稳度也见于 (9.3)。此情形适用的数学条件由方程 (9.4a)、(9.4b) 给出。此情形的生物学例子将在下面详细讨论。

**(e)** 对两形态原系统,只有 (a)–(d) 可能;但若有三种或更多形态原,就可能有行波。在环上将有两组波,一组顺时针行进,一组逆时针。此情形也有自然的化学波长与频率,一如有波长;未尝试为它们建立公式。

寻找此情形的生物学例子时,无须只考虑环。波可以在任何解剖形态的组织中出现。重要的是知道哪些波长、速度与频率与理论相容。这些量由反应发生的速率(更准确地说,由具有时间倒数量纲的"边际反应速率")以及形态原的扩散性决定。反应速率的可能取值范围极其宽广,甚至连数量级都无法给出。扩散性较有帮助。若假定行波系统中所有无量纲参数都与 §8 所给例子相同,则可以说波的波长与速度之乘积是最易扩散形态原之扩散性的 `3π` 倍。但这一假设当然不真,而且数值常数(此处为 3π)的真正可能范围也绝非显然。精子尾部的运动使人想到可作为这些行波的一个例子。波处于一个细胞之内并不是真正的困难;但传播速度似乎略快,除非数值常数相当大,否则难以解释。

**〔印刷页 31|原刊页 67〕**

**(f)** 相邻细胞位相相反的代谢振荡。作者未知道任何生物学例子。

情形 (d) 的直接例子也不易找到,但这只是因为孤立的组织环非常罕见。另一方面,与环有同类对称性的系统极其常见,可以预期:在适当的化学条件下,这些物体上会发育出定常波,其圆对称将被多角对称所取代。例如,一株植物嫩枝在某一时刻可以具有圆对称,即绕某轴旋转任何角度后看上去本质相同;这嫩枝后来可以发育出叶的一轮(whorl),于是它只在转过叶间角度或其倍数时才不变。这同一个例子也表明了涉及多于一个维度时情形的复杂性。嫩枝上的叶可以不成轮而呈覆瓦状(imbricated)。这一可能性也可作数学分析,将在后一文中详细考虑。在作者看来,生物学上最接近"孤立细胞环"的例子,是(例如)水螅(Hydra)的触手,以及某些植物如车叶草(Woodruff,Asperula odorata)的轮生叶。

水螅有点像海葵,但生活于淡水,约有五到十根触手。从水螅身上切下的一部分会重新安排自身,形成一个完整的新个体。在此过程的一个阶段,个体达到了一端(头部)开口、另一端闭合的管状。头部一端的外径比管其余部分略大。整体仍具有圆对称。在略晚的阶段,对称已丧失到这样的程度:适当的染色会在增宽的头部显示出若干斑块。这些斑块出现在触手随后将出现的地方(CHILD 1941, p. 101 and figure 30)。按照形态原理论,自然可以设想:与组织环情形所考虑的相类似的反应,在增宽的头部进行,导致类似的对称破缺。这情形比细的孤立环复杂,因为水螅的相关部分既不孤立也不很薄。不妨设想头部区域是唯一化学条件足以产生失稳的区域,这是合理的。但在此区域中产生的物质仍可自由扩散到周围活性较小的区域。把数学推广以在特别情形中覆盖这一点并无大困难。但若活性区域太宽,系统便不再近似于细环的行为,也就不能再期望触手形成单独一轮。这一点也未能于本文详论。

就车叶草而言,叶在茎上成轮出现,一轮中叶数变化颇大,有时少至五片,多至九片。同一茎上相继各轮的数目往往相等,但决非必然。可以推测,各轮起源于分生区中的活性组织环,而这些环相距足够远,彼此影响甚微。每轮叶数大概可用上面的法则得出,即以化学波长除环周,尽管这两个量都须赋予某种比环更适合车叶草的新解释。

**〔印刷页 32|原刊页 68〕**

另一个有多角对称的重要例子,由刚从母根突破出来的幼根纤维提供。起初它们在横截面上几乎均匀,但最终出现一圈间隔相当均匀的斑点,这些斑点后来发育成维管束。此处的完整解释同样必须是二维甚至三维问题的,尽管对环的分析仍有启发。横截面很大时,维管束可以排成不止一圈,或近乎随机或近六角形排列。二维理论(本文未述)也能在很大程度上解释这一点。

花表面上或可提供多角对称最明显的例子,而且很可能有许多物种,这一"绕环之波"的理论对之本质正确。但可以肯定它不适用于一切物种。倘若适用,则把花作为一个整体、即把所有物种混同起来看,就不会有非常显著的偏好花瓣数(或花冠裂片数、雄蕊数等)。因为把一切物种计入时,须预期相关之环的直径会在相当大的范围内取几乎一切数值,相邻的直径几乎同样常见;化学波长也可有些变化。于是周长与波长之比的相邻数值应或多或少同等频繁,这就意味着相邻的花瓣数将有大致相同的频率。但事实并非如此:数五极其常见,数七相当少见。依作者之见,这类事实可以在形态原理论的基础上得到解释,且与叶序理论密切相关;此处不能详论。

组织细丝的情形须作一点说明。这种细丝上的平衡斑图,与在浓度取极大或极小的一点切开的环上的斑图相同。这可以解释此类细丝的分节。但应注意,对浸于水中的细丝,理论不能不加修改地适用。

## 12. 球面上的化学波。原肠胚形成(Chemical waves on spheres. Gastrulation)

**〔印刷页 33|原刊页 69〕**

球面上均匀性破缺的处理,不比环的情形难多少。它所依据的球面调和函数理论,却非许多非数学专家所知。下面将述及所用球面调和函数的本质性质,许多读者会更愿意直接跳到本节末段。

此问题涉及的解剖结构是连续组织的空心球,例如囊胚。设其足够薄,可当作"球壳"。后一假设仅是为了数学简化;去掉它,结果也几乎完全相同。如 §7,设有两种形态原,`a、b、c、d、μ′、ν′、h、k` 的意义也与那里相同。算子 `∇²` 在此用来指拉普拉斯算子的切面部分,即 `∇²F` 是

`(1/ρ²)[∂/∂θ(sinθ·∂F/∂θ) + (1/sinθ)∂²F/∂φ²]`〔译注41:此展开式在源文本层中为空白(原为置式),今按球面拉普拉斯算子标准形式补出;θ、φ 为球面上的球极坐标,ρ 为球半径。〕

的缩写。对应于 (7.1) 的方程于是可写作

`∂X/∂t = a(X−h) + b(Y−k) + μ′∇²X`,`∂Y/∂t = c(X−h) + d(Y−k) + ν′∇²Y`　　(12.1)

众所周知(如 JEANS 1927, chapter 8),球面上的任何函数——至少任何可能在物理问题中出现的函数——都可以"按球面调和函数展开"。意即它可表为

`Σ_n Σ_{m=−n}^{n} [P_n^m(cosθ)e^{imφ}]` 之线性组合　　(12.2 前置)

〔译注42:方括号内的表达式称为"n 次球面调和函数";原式的具体系数记号(Γ、J 等)在源文本层中残损,上式仅示意结构。它在环理论中最近的类比是傅里叶分量。n 次球面调和函数的本质性质是:算子 ∇² 作用于它,效果等同于乘以 `−n(n+1)/ρ²`。〕

鉴于此事实,显然 (12.1) 的一个解是

`X = h + Σ_n Σ_m (Aₙᵐ e^(qₙt) + Bₙᵐ e^(q′ₙt)) Pₙᵐ(cosθ) e^(imφ)`,`Y = k + Σ_n Σ_m (Cₙᵐ e^(qₙt) + Dₙᵐ e^(q′ₙt)) Pₙᵐ(cosθ) e^(imφ)`　　(12.2)

其中 `qₙ` 与 `q′ₙ` 是

`(q − a + μ′n(n+1)/ρ²)(q − d + ν′n(n+1)/ρ²) = bc`　　(12.3)

的二根,且

`Aₙᵐ(qₙ − a + μ′n(n+1)/ρ²) = bCₙᵐ`,`Bₙᵐ(q′ₙ − a + μ′n(n+1)/ρ²) = bDₙᵐ`　　(12.4)

〔译注43:(12.2)–(12.4) 之系数下标、指数在源文本层中残损(如 "&«"、"&'" 等),已按球面调和函数标准记法复原;μ′、ν′ 在 (12.3)(12.4) 中与 `n(n+1)/ρ²` 的结合方式据 §7 之 (7.3) 类推,存疑待复核。〕这是最一般的解,因为 `Aₙᵐ`、`Bₙᵐ` 可选得使 `t = 0` 时 `X、Y` 取任何所需值,除非 (12.3) 有二相等根——那时须用与 §7 类似情形相仿的处理。与 §7 的类比确实是显然的,只是对 m 的求和在那里不出现。这求和的含义是:同一波长有许多不同的斑图,可以各种振幅因子叠加。于是,设如 §8 那样某一特定波长占主导,(12.2) 化为

`X − h = e^(qₙ₀t) Σ_m Aᵐ P_{n₀}ᵐ(cosθ)e^{imφ}`,`b(Y − k) = (qₙ₀ − a + μ′n₀(n₀+1)/ρ²)(X − h)`　　(12.5)

**〔印刷页 35|原刊页 71〕**

〔译注44:(12.5) 之第二式 OCR 识作 "(q,lo-a + Cl(n+\))(X—h)",按 (12.4) 之形式复原,存疑。〕换言之,两种形态原的浓度成比例,且都是同一次数 `n₀` 的球面调和函数,`n₀` 使 `qₙ、q′ₙ` 两根中之较大者取最大值。

各种近乎球形的结构——如放射虫骨架——的形式,大概与这些球面调和斑图密切相关。然而,理论最重要的应用似乎是囊胚的原肠胚形成。设化学数据(包括化学波长)当囊胚半径增大时保持不变。要完全具体,设

`μ′ = 2,ν′ = 1,a = −4,b = −8,c = 4,d = 1`

取这些值时,只要半径小于约 2,系统就相当稳定。然而接近此点时,一次调和函数开始发育,出现 `n₀ = 1` 的形如 (12.5) 的斑图。利用

`P₁(cosθ) = cosθ`,`P₁¹(cosθ) = P₁^{−1}(cosθ) = sinθ`

〔译注45:原文此处作 "PJ(cosΘ) = cos 0, P\ (cos Θ) = Px~ (cos Θ) = sin Θ",按 `P₁ = cosθ`、`P₁^{±1} ∝ sinθ` 复原。〕诸事实,可见 `X − h` 形如

`X − h = A cosθ + B sinθ cosφ + C sinθ sinφ`　　(12.6)

它也可解释为

`X − h = A′ cosθ′`　　(12.7)

其中 `θ′` 是半径 `(θ, φ)` 与方向余弦正比于 `B、C、A` 的那个固定方向所成的角,且 `A′ = (A² + B² + C²)^(1/2)`。

分析的结果因此相当简单:在某些不很苛刻的条件下(包括要求球相对较小但正在增大),均匀性破缺的斑图是轴对称的,但不是关于原球极坐标的轴,而是关于由扰动影响决定的某个新轴。第一形态原的浓度由 (12.7) 给出,`θ′` 自新轴量起;`Y − k` 与 `X − h` 成正比。设想第一形态原就是、或助长一种生长激素的产生,则须预期囊胚以轴对称方式生长,但在轴的一端比另一端更快。这在许多情形下可能导致原肠胚形成,尽管这种生长的效应不太容易确定:它们既依赖于组织的弹性性质,也依赖于每一点的生长速率。这一生长必将导致两极有显著差异的旋转体,除非除化学失稳外还有引起轴对称破缺的力学失稳。按此理论,原肠胚形成之轴的方向是完全随机的。实验上也许发现该轴通常在某确定方向,例如动物极方向。这与理论并无本质矛盾,因为合子的任何微小不对称都足以提供决定该轴的"扰动"。

## 13. 非线性理论。数字计算机的使用(Non-linear theory. Use of digital computers)

**〔印刷页 36|原刊页 72〕**

这里建立的"波"理论,本质上依赖于反应速率是浓度的线性函数这一假设;对刚开始离开均匀状态的系统,这假设是站得住的。这类系统作为斑图的首次显现当然有特殊的意义,但它们是例外而非常规。生物体的大部分,在大部分时间里,是从一个斑图发育为另一个斑图,而不是从均匀性发育为斑图。人们也希望能在数学上追踪这个更一般的过程。然而,困难在于:除了陈述方程之外,不能指望对这类过程有任何很包罗的理论。不过,借助数字计算机详细处理少数特殊情形,或是可能的。此法的优点是,不像作更理论性的分析时那样必须作简化假设。应用这类方法时,甚至或许能把问题的力学方面连同化学方面一并考虑。此法的主要缺点是只能得到特殊情形的结果。但这一缺点大概比较次要。即使对本文所考虑的环问题——对它已可能作相当完全的数学分析——一个特殊情形的计算处理也是极有启发性的。将于后一文描述的(如已提及)叶序的形态原理论,将用这种计算方法覆盖;将使用非线性方程。

必须承认,本文能给出的生物学例子非常有限。这可以很简单地归因于:生物现象通常非常复杂。把这与此处所用相对初等的数学结合考虑,几乎不能指望找到许多观察到的生物现象被覆盖。然而,可以认为,这里所处理的想象生物学系统与所讨论的诸原理,对解释真实的生物学形态应有一些帮助。
