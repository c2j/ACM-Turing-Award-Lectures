## Part III. A Solution of the Morphogenetical Equations for the Case of Spherical Symmetry(球对称情形下形态发生方程的一个解)

### 1. 微分方程的化简(Reduction of the differential equation)

**〔印刷页 107〕**

在前一部中我们导出了适用于小生物体的方程,并尝试在化学基础上为这些假设作了辩护。现在感兴趣的是求出浓度函数 `U$θ,φ,t$`,使之满足方程

```
dU/dt = Φ(∇²)U + GU − HUV                              (III.1.1)
```

其中 `V` 由下式定义〔译注2:`V` 的定义式中归一化因子在 OCR 中完全失落;按正文各处数值反推,应为球面上平均值的二倍,即 `V = $1/2π$∫∫ U² dcosθ dφ`(若按第二部的记法亦可写作对球面积元的平均再乘 2)。此式与下文 (III.1.6) 及全部数值解相容,但不敢断言即是原文形式。〕:

```
V = (1/2π) ∫∫ U² dcosθ dφ                              (III.1.2)
```

前面已经证明,解 `U` 必定是扩散本征函数的线性组合;因此不妨设 (III.1.1) 的解形如

```
            n    m
U(θ,φ,t) = Σ  S_m(t) P_n^m(cosθ) e^{imφ}                (III.1.3)
           m=−n
```

其中 `U` 取实值,而诸函数 `P_n^m$cosθ$` 为归一化的连带勒让德函数(normalised Legendre Associated Functions,见附录)。这些函数满足正交关系〔译注3:此式的右端在 OCR 中只剩零星记号;按附录的归一化约定,应为 `2π δ_{nn'} δ_{m,−m'}`,亦即同一 `n` 下指标互为相反数的两个函数乘积沿球面的积分为 `2π`,其余情形为零。〕

```
∫∫ P_n^m(cosθ) P_n^{m'}(cosθ) e^{i(m+m')φ} dcosθ dφ = 2π δ_{nn'} δ_{m,−m'}}   (III.1.4)
```

由于 `U` 是实的,它等于自己的复共轭 `U*`;又因

```
P_n^m(cosθ) = P_n^{−m}(cosθ)
```

故有

```
S_{−m}(t) = S*_m(t).                                    (III.1.5)
```

于是可以由 (III.1.2) 经积分算出 `V`,因为

```
V = (1/2π) Σ_k Σ_m S_k S_m ∫∫ P_n^k(cosθ) P_n^m(cosθ) e^{i(k+m)φ} dcosθ dφ
  =      Σ_k Σ_m S_k S_m · (相应正交积分),
```

再利用关系式 (III.1.4) 与 (III.1.5),即得

```
        n
V = Σ   |S_m|²                                          (III.1.6)
       m=−n
```

在方程 (III.1.1) 中,函数 `Φ$ν$` 可代之以一个常数 `I`,因为对球面调和函数而言

```
ν = −n(n+1)/R².
```

方程 (III.1.1) 于是成为

```
dU/dt = IU + GU − HUV.                                  (III.1.7)
```

**〔印刷页 108〕**

把级数解代入这个方程便得到〔译注4:系数 `L` 的定义式 (III.1.9) 中被积函数的指号顺序(第三个指标取 `m` 还是 `−m`)在 OCR 中无法判定;此处取使三指标之和为零时积分才不为零的约定,与下文 (III.1.18)、(III.2.1) 及附录一致。〕

```
dS_m/dt = (I − HV) S_m + G Σ_{i=−n}^{n} Σ_{j=−n}^{n} S_i S_j L_n^{i,j,−m}     (III.1.8)
```

其中系数 `L_n^{p,q,r}` 定义为(以 μ 记 cosθ):

```
L_n^{p,q,r} = (1/4π) ∫_0^{2π} ∫_{−1}^{1} P_n^p(μ) P_n^q(μ) P_n^r(μ) e^{i(p+q+r)φ} dμ dφ.   (III.1.9)
```

随着时间的推移,`S_m$t$` 将达到由方程 (III.1.8) 所决定的平衡值。因此,假定平衡业已达成,该方程变为

```
(I − HV) S_m + G Σ_{i=−n}^{n} Σ_{j=−n}^{n} S_i S_j L_n^{i,j,−m} = 0           (III.1.10)
```

它可以写成如下形式:

```
[(I − HV)/(−G)] · S_m = Σ_{i=−n}^{n} Σ_{j=−n}^{n} S_i S_j L_n^{i,j,−m}        (III.1.11)
```

为了求解,更方便的做法是解方程

```
T_m = Σ_{i=−n}^{n} Σ_{j=−n}^{n} T_i T_j L_n^{i,j,−m},                          (III.1.12)
```

它不含任何任意常数。若 `T_m` 是这个方程的一组解,则 `S_m = λT_m` 将满足

```
S_m = λ Σ_{i=−n}^{n} Σ_{j=−n}^{n} S_i S_j L_n^{i,j,−m},                        (III.1.13)
```

从而只要选取 `λ` 使得

```
λ = −(I − HV)/G,                                        (III.1.14)
```

则 `λT_m` 便满足 (III.1.11)。这里常数 `V` 由下式给出:

```
V = Σ |S_m|² = λ² Σ |T_m|²,                             (III.1.15)
```

于是关于 `λ` 的最终方程为

```
λ = (I − λ² H Σ |T_m|²)/G.                              (III.1.16)
```

由于对每个 `T_m` 而言 `λ` 都是同一个,由 `T` 给出的分布与由 `S` 给出的分布之间只差一个常数因子。

这样一来,人们便得到下面这组方程:

```
S_m = Σ_{i=−n}^{n} Σ_{j=−n}^{n} S_i S_j L_n^{i,j,−m},                          (III.1.17)
```

未知量 `S_m` 即由此解出。这些解一般说是复的,但可以选取纯实数的解,因为可以证明复解彼此之间只相差一个旋转。

对每一个特定的 `n`,可以把 (III.1.17) 所给出的 `n+1` 个方程逐一枚举出来,写成下面的形状。其中用到了关系〔译注5:(III.1.18) 在 OCR 中仅存选择定则的片段;按附录,`E_n^{p,q,r}` 与 `L_n^{p,q,r}` 的关系及选择定则应为:当 `p+q+r = 0` 时 `E_n^{p,q,r} = 2π·L_n^{p,q,r}`(此时被积函数中的指数因子退化为 1),否则为零;又若 p、q、r 中任何一个的模超过 n,亦规定为零。〕

```
E_n^{p,q,r} = 2π · L_n^{p,q,r},   当 p+q+r = 0;
E_n^{p,q,r} = 0,                  当 p+q+r ≠ 0,或 p、q、r 中任一个的绝对值 > n.   (III.1.18)
```

**〔印刷页 109〕**(本页 OCR 缺页码标记)

当 `n ≤ 8` 时,这些方程为〔译注6:原文在本页逐条印出 `S₀` 至 `S₈` 共九个(按通式为 `n+1` 个)方程;本页公式在 OCR 中破损最重,仅余零星系数与下标。下列方程组按 (III.1.17) 结合 (III.1.18) 的选择定则重构,其通式为:`S_m` 等于所有满足 `p+q=m` 的乘积项 `S_pS_q` 乘以 `E_n^{p,q,−m}` 之和,其中含共轭对的项合并为 2 倍,`m` 为偶数时的"对折"项(`S_{m/2}²`)不乘 2。重构后的结构与原文残存的全部系数碎片(`k,k+1`、`1,4,5`、`2,3,5`、`S₁S₆`、`S₃²` 等)逐项吻合。〕

```
S₀ = S₀² E_n^{0,0,0} + 2 Σ_{k=1}^{n} |S_k|² E_n^{k,−k,0}

S₁ = 2 Σ_{k=0}^{n−1} S*_k S_{k+1} E_n^{k,k+1,−1}

S₂ = 2 Σ_{k=0}^{n−2} S*_k S_{k+2} E_n^{k,k+2,−2} + 2 S₁² E_n^{1,1,−2}

S₃ = 2 Σ_{k=0}^{n−3} S*_k S_{k+3} E_n^{k,k+3,−3} + 2 S₁S₂ E_n^{1,2,−3}

S₄ = 2 Σ_{k=0}^{n−4} S*_k S_{k+4} E_n^{k,k+4,−4} + 4 S₁S₃ E_n^{1,3,−4} + S₂² E_n^{2,2,−4}

S₅ = 2 Σ_{k=0}^{n−5} S*_k S_{k+5} E_n^{k,k+5,−5} + 2 S₁S₄ E_n^{1,4,−5} + 2 S₂S₃ E_n^{2,3,−5}

S₆ = 2 Σ_{k=0}^{n−6} S*_k S_{k+6} E_n^{k,k+6,−6} + 2 S₁S₅ E_n^{1,5,−6} + 2 S₂S₄ E_n^{2,4,−6} + S₃² E_n^{3,3,−6}

S₇ = 2 Σ_{k=0}^{n−7} S*_k S_{k+7} E_n^{k,k+7,−7} + 2 S₁S₆ E_n^{1,6,−7} + 2 S₂S₅ E_n^{2,5,−7} + 2 S₃S₄ E_n^{3,4,−7}

S₈ = 2 S*_0 S₈ E_n^{0,8,−8} + 2 S₁S₇ E_n^{1,7,−8} + 2 S₂S₆ E_n^{2,6,−8} + 2 S₃S₅ E_n^{3,5,−8} + S₄² E_n^{4,4,−8},
```

当 `n < 8` 时只有前 `n+1` 个方程成立。

这些方程有代数解,尽管未必是实解。给定 `n` 后,解 `S = $S₀, S₁, …, S_n$` 并不唯一;事实上,有时可以预先指定 `S` 的 `n+1` 个分量中的 `n` 个,再让剩下的那个分量在保持其模不变的条件下变动。求解时取 `S₁ = 0`,因为在任何一个 `S₁ ≠ 0` 的解中,总可以旋转坐标轴,把变换后的解中的 `S₁` 分量消去,而这样做并不改变物理解。

可以看到,所得的解中有一些取负值。应当记住,这些解表示的是对球面的偏离。量纲在某种程度上是任意的,但只要参照适当的生物物种,就可以在函数 `U` 的振荡幅度与初始球的半径之间取得正确的配比。

### 2. 联立方程组的解(Solutions of the simultaneous equations)

**〔印刷页 110〕**

这些方程组的解大体上遵循一个固定的模式。如果在某个解中 `S_r` 不为零,那么 `S_{2r}`、`S_{3r}` 等也会在该解中出现。于是会有一个 `S₀, S₃, S₆` 等全不为零的解;同样也会有 `S₀, S₂, S₄, S₆` 等不为零的解。若各个积分 `L_n^{p,q,r}` 的数值之间出现某种巧合,还会有附加的解。

方程组是对 `n = 2, 4, 6` 求解的,并加上前文提到的那条限制,即 `S₁ = 0`。

**情形 n = 2.** 方程为〔译注7:第一个方程(`S₀` 的方程)在 OCR 中几乎完全破碎,只余指标碎片 `0,0,0`、`1,−1,0`(?)、`2,−2,0`;现按通式补足。`S₂` 方程末项的系数 `E₂^{1,1,−2}` 印刷值 OCR 作 `√35/7`,但按本文归一化约定数值积分给出 `√30/7`(= 0.7825),疑 OCR 误读;其余三个系数均经数值验证无误。〕

```
S₀ = S₀² E₂^{0,0,0} + 2 |S₁|² E₂^{1,−1,0} + 2 |S₂|² E₂^{2,−2,0}

S₁ = 2 S₁S₀ E₂^{0,1,−1} + 2 S₂S_{−1} E₂^{2,−1,1}                      (III.2.1)

S₂ = 2 S₂S₀ E₂^{2,0,−2} + S*₁² E₂^{1,1,−2}
```

而诸系数 `E₂` 的数值为:

```
E₂^{0,0,0} = 2√5/7,          E₂^{1,−1,0} = √5/7,
E₂^{2,−2,0} = −2√5/7,        E₂^{1,1,−2} = √30/7.
```

这一组方程 (III.2.1) 的最简单的解,是 `S₀` 为唯一非零变量的解。这个解就是

```
S₀ = (E₂^{0,0,0})^{−1} = 7/(2√5),
```

从而

```
U = S₀ P₂⁰(cosθ) = (7/4)(3cos²θ − 1),

V = S₀² = 49/20.
```

**〔印刷页 111〕**

这给出一个长球体(prolate spheroid),其长轴与方向 `θ = 0` 重合。这组方程的所有其他解都不引入新的物理解,只不过使这个球体绕不同的轴转过不同的角度而已。例如,考虑 `S₀ ≠ 0`、`S₂ ≠ 0` 的解。不妨取 `S₂` 为正,因为 `S₂` 为负的情形可由绕 `θ = 0` 轴旋转 π/2 得到,这是由于

```
−S₂ P₂²(μ) cos2φ = S₂ P₂²(μ) cos2(θ ± π/2).
```

此时的解为

```
U = (7/8)[(1 + 3cos2θ) − 3μ²(1 + cos2θ)],

V = 49/20.
```

可以看出,这正是原来的那个长球体,只不过是绕 `θ = π/2` 处的轴转过了 π/2 而已。

**情形 n = 4.** (i) 这里最简单的解仍然是一个基本的物理解,即 `S₀` 为唯一非零系数的解。它是

### 3. 与物理物种的比较(Comparison with physical species)

**〔印刷页 114〕**(页码在 OCR 中残损)

最能体现球面调和花样的生物类群当属放射虫(Radiolaria)。这些海洋生物是单细胞的,周身包有一种起支撑与保护作用的骨骼,后者一般由二氧化硅构成。这些小小的放射虫细胞直径约一毫米,在世界各大洋、各种气候带、各种深度都有发现,但不见于淡水。从当前的观点看,它们最有趣的性质是拥有从骨骼外壳向外辐射的放射状骨针(radial spines)。从形态学的角度看,骨针的数目、排列与配置通常正是决定骨架总体形状的因素;从生理学的角度看,它们作为保护与支撑器官行使着明确的职能。

单个细胞的生活本质上是独立的,其生长受环境影响。因此可以设想,形形色色繁多的类型乃源于各种扩散物质——无论有机还是无机——的不同浓度。水体的盐度或二氧化硅含量即可比附于毒物形态原(poison morphogen),因为已知这些东西会影响生长。〔译注13:"毒物形态原"呼应第二部反应系统中抑制性物质的提法;把海水中盐度、硅质浓度看作影响反应-扩散参数的环境变量,正与本部 §1 的模型框架相合。〕

为了生物分类的目的,放射虫分为两个亚纲:"孔口亚纲"(Porulosa)与"裂口亚纲"(Osculosa),再细分为四个军团(legion)。〔译注14:本节的分类体系与术语("基型"、Porulosa/Osculosa、四军团、Centrostigma 等)悉承 Haeckel——恩斯特·海克尔(Ernst Haeckel)1862 年《放射虫》专著及其 1887 年挑战者号报告;海克尔正是以放射虫骨架的几何"基型"(Grundform)与正多面体构型闻名,D'Arcy Thompson《论生长与形态》亦大篇幅引述。文中大写的类群名称系海克尔的拉丁学名,习惯汉译为:SPUMELLARIA 泡沫虫类,ACANTHARIA 等辐骨虫类,NASSELARIA 门孔虫类,PHAEODARIA 稀孔虫类;"军团"(legion)为其分类等级名,介于亚纲与目之间。〕孔口亚纲包括泡沫虫类(SPUMELLARIA)与等辐骨虫类(ACANTHARIA)两个军团,其特征如下:

(1) 中央囊是球形的,而且在大多数物种中始终保持这一形状。

(2) 漂浮的单细胞体的平衡或是泛稳的(pantostatic,随遇平衡)或是多稳的(polystatic,多重稳定),因为竖直的主轴或者不存在,或者即使存在,其两极的构造也彼此相同。

(3) 因此骨骼的基型(ground form)几乎总是球型的(spherotypic)或等极单轴型的(isopolar-monaxon),很少是左右型的(zygotypic)。

裂口亚纲(Osculosa)包含门孔虫类(NASSELARIA)与稀孔虫类(PHAEODARIA)两个军团,它们具有相似而恒定的特征:

(1) 中央囊是球形的,并在大多数物种中保持这一基型。

(2) 漂浮体的平衡是单稳的(monostatic and unistable),因为主轴的两极总是多少彼此不同。

(3) 因此骨骼的基型大部分是中轴型的(grammotypic,centrax)或左右型的(zygotypic),很少有球型的。

放射虫的四个主要类群——即所谓"军团"——是自然的单元;然而,当人们试图把它们全部纳入一个系统发生的关联之中时,毫无疑问泡沫虫类显得是原始的主干。其余三类大概都各自独立地从泡沫虫类最古老的主干型——球形的"Actissa"——发展而来。〔译注15:Actissa 系海克尔拟构的放射虫原始理想型:一个光裸的球形细胞,无骨架,由它派生出各式骨架类型。〕

既然我们的主要兴趣在于各种基型的个体发育,那么纵览一下各种类型便是合宜的。我们可以把五花八门的几何基型归入四个主群:"中心点型"(Centrostigma)即球型,"中心轴型"(Centraxonia)即中轴型,"中心面对"(Centroplana)即左右型,以及"无中心型"(Acentrica)即非典型(atypic)。身体的自然中心——其各部分规则地围绕它排布——在第一群里是一个点(stigma),在第二群里是一条直线(主轴),在第三群里是一个平面(矢状面),而在第四群里当然就没有中心了。

**〔印刷页 115〕**

球形基型(Spherical 或 Homaxon)是唯一绝对规则的基型,因为只有在这种基型里,过中心的所有的轴才都彼此相等。它在放射虫中极为常见,尤其在泡沫虫类与等辐骨虫类之中,在那里它提供了共同的原始基型;但在许多稀孔虫类的壳中也常可见到。另一方面,它在门孔虫类中从未出现。

内接多面体基型(endospherical polyhedron)或多轴基型(polyaxon)自然地继球形基型之后:举凡各顶角落在一个球面上的多面体皆属于此;这种基型在泡沫虫类中特别常见,但也见于等辐骨虫类。严格说来,那些被不恰当地称作"球形"的网格壳(lattice shell)全都属于这一范畴,因为没有一个是几何意义上的真球,而是内接多面体,其顶角由网格壳的节点或由节点发出的放射骨针标示。这些多面体可分为三群:规则的、次规则的与不规则的。真正称得上规则的多面体只有五种能够存在,即正四面体、立方体、正十二面体、正八面体与正二十面体。所有这些都确实显现于放射虫之中,尽管次规则的内接多面体要常见得多。

以正二十面体(由二十个正三角形围成)为几何原型的基型见于稀孔虫类(如 "Circongonia"),也见于某些 Aulosphaerida(管壳虫类)。这一基型也可以认为出现在那些球形网格壳生有十二根等距等长放射骨针的泡沫虫类(Sphaeroidea)之中;这些骨针的基部恰好标示出正二十面体的十二个顶点。〔译注16:这正是 §2 情形 n = 6 解 (ii) 所解出的构型——十二根骨针落在正二十面体的顶点上,其中两个顶点恰在两极;模型与化石形态在此直接对上了。〕

正八面体基型(由八个正三角形围成)常见于泡沫虫类。在这些泡沫虫类中,典型的基型通常由位于三条互相垂直的轴上的六根等长放射骨针标示。有时网格壳的球形会过渡为正八面体形。同样的形状也再现于稀孔虫类的 "Circoporus"。

正立方体基型与正四面体基型也有出现。前者可以认为出现在那些球形网格壳生有八根等距等长放射骨针的物种之中。

等极单轴基型(isopolar-monaxon)的特征在于拥有一条两极相等的主轴,而没有分化的横轴。凡与该轴正交相交的水平面都是圆。这一群最重要的基型是"透镜型"(phacoids,即扁豆形或扁球体)与椭球体(或长球体),例如 Phacodiscus rotula 与 Cromyactractus tetracelyphus。

函数 `P_n^m$cosθ$` 是归一化的连带勒让德函数,定义为

```
P_n^m(μ) = A_n^m · P̄_n^m(μ),
```

其中以 μ 记 cosθ,`P̄_n^m$μ$` 表示通常的连带勒让德函数,并附加条件 `P_n^m$μ$ = P_n^{−m}$μ$`(即不取康登–肖特莱相位);`A_n^m` 的选取使得〔译注17:归一化条件的精确表述(是否含 `1/2π` 因子、右端是 1 还是 δ)在 OCR 中不可辨;按下述取法一切正文数值均可复原:`$1/2π$∫∫ P_n^{m₁}$μ$ P_n^{m₂}$μ$ e^{i$m₁+m₂$φ} dμ dφ = 1`(当 `m₁ + m₂ = 0` 时),否则为 0,亦即 `∫_{−1}^{1} [P_n^m]² dμ = 1`。〕

```
(1/2π) ∫_0^{2π} ∫_{−1}^{1} P_n^{m₁}(μ) P_n^{m₂}(μ) e^{i(m₁+m₂)φ} dμ dφ = 1   (m₁ + m₂ = 0).
```

于是人们求得

```
A_n^m = √[(2n+1)(n−m)!/(n+m)!]
```

(见 Hobson(1931)第 162 页)。〔译注18:E. W. Hobson,*The Theory of Spherical and Ellipsoidal Harmonics*,Cambridge University Press,1931;此书是当时球谐函数的标准参考书。`A_n^m` 的表达式已由数值验证:E₂⁰ = √5、E₄⁰ = 3、A₆⁰ = √13。〕

为方便起见,引入由下式定义的函数 `L_n^{p,q,r}` 与 `E_n^{p,q,r}`:

```
L_n^{p,q,r} = (1/4π) ∫_0^{2π} ∫_{−1}^{1} P_n^p(μ) P_n^q(μ) P_n^r(μ) e^{i(p+q+r)φ} dμ dφ.
```

由此可得

```
E_n^{p,q,r} = 2π · L_n^{p,q,r},   当 p+q+r = 0;
E_n^{p,q,r} = 0,                  当 p+q+r ≠ 0.
```

(亦即 `E_n^{p,q,r} = (1/2)∫_{−1}^{1} P_n^p P_n^q P_n^r dμ`,当 `p+q+r = 0`;此式已用于复核正文全部系数。)

由于 `L_n^{p,q,r}` 的定义不依赖于坐标轴的选取,可以旋转坐标轴而保持积分不变。这使得人们能为诸 `L` 导出一组递推关系〔译注19:递推关系及其系数表在 OCR 中完全破碎,仅可辨认形如 "= −W(N−P)(N+P+L)"、"除非 |P−Q| = 1" 的片段,无法复原;其大意是:利用坐标轴旋转下的不变性,把指标 `$m₁, m₂, m₃$`(满足 `m₁+m₂+m₃ = 0`)之一升降一格,得到诸 `L` 之间的线性关系,系数由若干含 N、P、Q、W 的因式给出。此类关系今称 Gaunt 系数递推。〕,约束条件为 `m₁ + m₂ + m₃ = 0`;有关的常数由下列表达式给出(原文如此,排版失落):

```
L^{…} = −W(N−P)(N+P+L),
L^{…} =  W(N−P)(N+P+L),
……,除非 |P−Q| = 1.
```
