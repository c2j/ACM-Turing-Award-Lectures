## 边界与编排说明

- PDF 第 134 页（印刷第 107 页）是共享边界页：上半仍属第二部，随后在同页开始第三部。两个拟定文件均须以清晰的来源页标记处理该页，不能漏掉或把文字重复译两次。
- PDF 第 75 页和第 77 页均为独立图版，不应因正文提取量少而跳过。前者为向日葵照片，后者为带编号的向日葵示意图。
- PDF 第 7、27、151、155 页均印有 “This page intentionally left blank”。翻译文件中应保留来源页占位说明，但不虚构正文。
- PDF 第 28–63 页保留原论文页眉中的原刊页码 37–72，同时本卷另以 1–36 编页；引用时优先同时注明两套页码。
- 计划文件名中的编号只表达翻译工程顺序，不改动源 PDF，也不表示已经完成翻译。
