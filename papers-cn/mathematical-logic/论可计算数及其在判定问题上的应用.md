## 开篇(PLMS pp. 230–231)

<!-- 论文无节号的开篇四段,PDF 31–32;三条脚注(†、‡、§)为原刊脚注,引文照录原文 -->

"可计算数"可以简要地描述为:其小数表达式可凭有穷手段算出的那些实数。虽然本文表面上以可计算数为题,但定义并研究以整变量、实变量或可计算变量为变元的可计算函数、可计算谓词等等,几乎同样容易。不过,每种情形所涉及的根本问题都是相同的,而我选择可计算数作专门处理,因为它所需的技巧最少累赘。我希望不久后给出关于可计算数、可计算函数等彼此间关系的一个叙述,其中将包括以可计算数表述的实变量函数论的一个发展。按照我的定义,一个数是可计算的,如果它的小数可以由一台机器写出来。

在 §§9、10 中,我将给出一些论证,意在表明:可计算数包括了所有自然地会被视为可计算的数。特别地,我证明了某些庞大的数类是可计算的,例如:所有代数数的实部、贝塞尔函数零点的实部,以及数 π、e 等。然而,可计算数并不包括全部可定义数,文中还给出了一个可定义而不可计算的数的例子。

尽管可计算数类如此之大,并且在许多方面与实数类相似,它仍然是可枚举的。在 §8 中,我考察了某些看来会证明相反结论的论证。通过正确地应用其中之一,得到了一些表面上与哥德尔[^1]的结果相似的结果。这些结果有重要的应用;特别地,文中证明(§11):希尔伯特的判定问题不可能有解。

在最近的一篇论文中,阿隆佐·丘奇[^2]引入了"能行可计算性"(effective calculability)的观念,它与我的"可计算性"等价,但定义方式大不相同。丘奇关于判定问题也得到了类似的结论[^3]。"可计算性"与"能行可计算性"二者等价的证明,将在本文附录中给出梗概。

[^2]: ‡ Alonzo Church, "An unsolvable problem of elementary number theory", American J. of Math., 58 (1936), 345–363.
[^3]: § Alonzo Church, "A note on the Entscheidungsproblem", J. of Symbolic Logic, 1 (1936), 40–41.

## §1 计算机器

<!-- 本节内容译自 PLMS pp. 230–232(PDF 31–33) -->

我们说过,可计算数就是其小数可凭有穷手段算出的那些数。这需要相当明确的定义。在讲到 §9 之前,我不会真正尝试为所给的定义作辩护;眼下我只想说:辩护的依据在于,人的记忆必然是有限的。

我们可以把一个正在计算实数的人,比作一台只能处于有穷多个状态 q₁, q₂, …, q_R 的机器;这些状态将称为"m-格局"。机器配有一条贯穿其中的"纸带"(纸的类似物),纸带被分成一节一节(称为"方格"),每个方格可承载一个"符号"。任一时刻,恰好有一个方格——比如说第 r 个——载有符号 S(r),它正处于"机器中"。我们可以把这个方格称为"被注视的方格"。被注视方格上的符号可以称为"被注视的符号"。"被注视的符号"是机器——不妨这样说——"直接觉察"到的唯一符号。不过,通过改变自己的 m-格局,机器可以有效地记住它先前"看过"(注视过)的某些符号。机器在任一时刻的可能行为,由 m-格局 q_n 和被注视的符号 S(r) 确定。这一对 q_n, S(r) 将称为"格局":这样,格局确定了机器的可能行为。在被注视方格为空白(即不载符号)的某些格局中,机器在被注视方格上写下一个新符号;在另一些格局中,它擦去被注视的符号。机器也可以改变被注视的方格,但只能把它向右或向左移动一格。除这些操作之外,m-格局也可以改变。所写下的符号中,有一些将构成数码序列,即正在计算的那个实数的小数;其余的只是"帮助记忆"〔译注1〕的草注。只有这些草注才可能被擦去。

我主张,这些操作包括了数的计算中所要用到的全部操作。等读者熟悉了机器的理论,这一主张的辩护就会容易些。因此在下一节中,我径直展开这个理论,并假定已明白"机器""纸带""注视"等词的含义。

## §2 定义

<!-- PLMS pp. 232–233 -->

**自动机。**

如果在每一阶段,机器(§1 意义下的机器)的运动都完全由格局确定,我们就称这种机器为"自动机"(a-机器)。

出于某些目的,我们可以使用其运动只是部分地由格局确定的机器(选择机,或 c-机器)——这正是 §1 中使用"可能"一词的原因。当这种机器到达这类不确定的格局之一时,除非由外部操作者作出某个任意的选择,它便无法继续运行。若用机器来处理公理系统,便会出现这种情形。本文只处理自动机,因此常将前缀 a- 省去。

**计算机器。**

如果一台 a-机器打印两类符号,其中第一类(称为数码)完全由 0 和 1 组成(其余的称为第二类符号),那么这台机器将称为计算机器。若给这台机器一条空白纸带,并从正确的初始 m-格局起开动,则它所打印的符号中属于第一类者构成的子序列,称为这台机器**所计算的序列**;在此序列之前冠以小数点而得到的二进制小数所表示的实数,称为这台机器**所计算的数**。

在机器运行的任一阶段,被注视方格的号码、纸带上全部符号的完整序列以及 m-格局,合起来称为描述该阶段的**完全格局**。机器与纸带在相继两个完全格局之间的变化,称为机器的**动作**(moves)。

**循环机与非循环机。**

如果一台计算机器写下的第一类符号永远只有有穷多个,则称它为**循环的**;否则称它为**非循环的**。

一台机器是循环的,如果它到达了一个没有任何可能动作的格局,或者如果它继续运行——并可能打印第二类符号——却再也打印不出第一类符号。"循环"一词的含义将在 §8 中解释。

**可计算序列与可计算数。**

一个序列称为可计算的,如果它可以由一台非循环机器计算出。一个数是可计算的,如果它与某台非循环机器所计算的数相差一个整数。

为避免混淆,我们将更多地说可计算序列,而较少说可计算数。

## §3 计算机器的例子

<!-- PLMS pp. 233–235 -->

**I.** 可以构造一台机器来计算序列 010101…。这台机器应具有四个 m-格局,即 "b"、"c"、"z"、"e"〔勘误3〕,并能打印 "0" 和 "1"。机器的行为由下表描述。表中 "R" 意为"机器移动,使其注视紧邻原注视方格右边的方格";"L" 同理;"E" 意为"被注视的符号被擦去";"P" 代表"打印"。本表(以及今后所有同类表格)应按下述方式理解:对于前两列所描述的格局,依次执行第三列中的操作,然后机器进入最后一列所描述的 m-格局。当第二列留空时,理解为第三、四列所描述的行为对任何符号以及对无符号皆适用。机器从 m-格局 b 及一条空白纸带起步。

Configuration(格局)| Behaviour(行为)

| m-格局(m-config.) | 符号(symbol) | 操作(operations) | 最终 m-格局(final m-config.) |
|---|---|---|---|
| b | 无 | P0, R | c |
| c | 无 | R | e |
| e | 无 | P1, R | z |
| z | 无 | R | b |

如果(与 §1 的描述相反)我们允许字母 L、R 在操作列中出现不止一次,便可以把这个表大大简化:

| m-格局 | 符号 | 操作 | 最终 m-格局 |
|---|---|---|---|
| b | 无 | P0 | b |
| | 0 | R, R, P1 | b |
| | 1 | R, R, P0 | b |

〔勘误4:原刊此表中 m-格局列与最终 m-格局列的 "b" 各以竖排居中方式印出一次,此处按行展开补齐。〕

**II.** 作为稍难一些的例子,我们可以构造一台机器来计算序列 001011011101111011111…。这台机器应能处于五个 m-格局,即 "o"、"q"、"p"、"f"、"b",并能打印 "ə"、"x"、"0"、"1"〔译注2〕。纸带上的前三个符号将是 "əə0";其余数码排在相间的方格上。在中间那些方格上,我们从不打印 "x" 以外的任何东西。这些字母替我们"占位",用完之后即行擦去。我们还作了这样的安排,使得相间方格上的数码序列中没有空格。

Configuration | Behaviour

| m-格局 | 符号 | 操作 | 最终 m-格局 |
|---|---|---|---|
| b | 无 | Pə, R, Pə, R, P0, R, R, P0, L, L | o |
| o | 1 | R, Px, L, L, L | o |
| | 0 | | q |
| q | 任意(0 或 1) | R, R | q |
| | 无 | P1, L | p |
| | x | E, R | q |
| p | 1 | R | f |
| | 无 | L, L | p |
| f | 任意 | R, R | f |
| | 无 | P0, L, L | o |

为展示这台机器的工作过程,下面给出最初若干完全格局的表。这些完全格局的写法是:写下纸带上的符号序列,而把 m-格局写在被注视符号的下方。相继的完全格局以冒号分隔。

```
: əə0      0 : əə0      0 : əə0    0 : əə0      0 : əə0      0    1 :
  b         o          q          q          q             p
  əə0      0    1 : əə0      0 1 : əə0    0           1 : əə0      0    1 :
       p          p         f                      f
  əə0      0    1 : əə0      0 1  : əə0          0    1    0 :
            f          f                 o
  əə0      0    1 x 0 : ....
           o
```

〔勘误6:原刊以宽窄不一的空格表示 E-方格空位,m-格局字母对准被注视符号下方;此处按原刊折中复现,间隔非逐字符对应。〕

此表也可以写成如下形式

```
b : əə0        0 : əəq0        0 : …,                        (C)
```

即在被注视符号的左边空出一个位置,m-格局就写在这个空位里。这种形式较不易读,但我们以后将出于理论上的目的用到它。

只在相间的方格上写数码,这一约定非常有用,我将始终沿用。我把相间方格中的一列称为 **F-方格**,另一列称为 **E-方格**。E-方格上的符号可能被擦去。F-方格上的符号构成一个连续的序列,直到末尾为止没有空格。每两个 F-方格之间无需多于一个 E-方格:表面上看需要更多 E-方格之处,可以用足够丰富的、可打印在 E-方格上的符号品种来满足。若一个 F-方格 S 上有符号 β,而紧邻 S 右边的 E-方格上有符号 α,则称 S 与 β **被 α 标记**;打印这个 α 的过程称为**用 α 标记** β(或 S)。

## §4 缩写表

<!-- PLMS pp. 235–239 -->

几乎所有机器都要用到某些类型的进程,而且在有些机器里,这些进程又用于许多场合。这些进程包括:抄写符号序列、比较序列、擦去某一给定形式的全部符号,等等。凡涉及这类进程之处,我们可以借助"骨架表"把各个 m-格局的表大为缩写。骨架表中出现大写德文字母〔译注3〕和小写希腊字母,它们具有"变量"的性质:把每个大写德文字母全程替换为某个 m-格局,把每个小写希腊字母替换为某个符号,我们就得到一个 m-格局的表。

骨架表只应看成缩写,并非本质所在。只要读者明白如何从骨架表得出完整的表,这方面就无需给出任何确切的定义。

来看一个例子:

| m-格局 | 符号 | 行为 | 最终 m-格局 |
|---|---|---|---|
| f(ℭ, 𝔅, α) | ə | L | f₁(ℭ, 𝔅, α) |
| | 非 ə | L | f(ℭ, 𝔅, α) |
| f₁(ℭ, 𝔅, α) | α | | ℭ |
| | 非 α | R | f₁(ℭ, 𝔅, α) |
| | 无 | R | f₂(ℭ, 𝔅, α) |
| f₂(ℭ, 𝔅, α) | 非 α | R | f₁(ℭ, 𝔅, α) |
| | 无 | R | 𝔅 |

> 从 m-格局 f(ℭ, 𝔅, α) 出发,机器找到形如 α 的符号当中最靠左边的那个(即"第一个 α"),然后 m-格局变为 ℭ。如果没有 α,则 m-格局变为 𝔅。

如果我们把 ℭ 全程替换为 q(比如说),𝔅 替换为 r,α 替换为 x,我们就得到 m-格局 f(q, r, x) 的一个完整的表。f 称为"m-格局函数"或"m-函数"。

在 m-函数中可容许代入的表达式,只有机器的 m-格局和符号。它们必须或多或少明确地加以枚举;其中可以包括诸如 pe₁(ℭ, x)〔勘误8〕这样的表达式——如果当真用到了任何 m-函数,那就必定如此。如果不坚持这种明确的枚举,而只是说:机器具有某些(枚举出的)m-格局,再加上把 m-格局代入某些 m-函数所能得到的一切 m-格局,那么我们通常就会得到无穷多个 m-格局。例如,我们可以规定机器具有 m-格局 q,再加上把 m-格局代入 p(ℭ) 中的 ℭ 所能得到的全部 m-格局;于是它就将具有 q, p(q), p(p(q)), p(p(p(q))), … 这些 m-格局。

于是,我们的解释规则如下。给定机器各 m-格局的名字——它们大多以 m-函数表达——又给定各骨架表;我们所要的只是机器各 m-格局的完整表,它由对骨架表的反复代入而得到。

**进一步的例子。**(说明中使用符号 "→" 表示"机器进入某某 m-格局"。)

**e(ℭ, 𝔅, α)** = f(e₁(ℭ, 𝔅, α), 𝔅, α);其中 **e₁(ℭ, 𝔅, α)**:E → ℭ。
从 e(ℭ, 𝔅, α) 出发,第一个 α 被擦去,→ ℭ;若没有 α,则 → 𝔅。

**e(𝔅, α)** = e(e(𝔅, α), 𝔅, α)。
从 e(𝔅, α) 出发,所有的字母 α 都被擦去,→ 𝔅。

最后一个例子看起来比大多数例子都更难解释。设某台机器的 m-格局清单中出现 e(b, x)(称之为 q)。其表为:

```
e(b, x)    e(e(b, x), b, x)
```

即

```
q          e(q, b, x)
```

或写得更详细些:

```
q             e(q, b, x)
e(q, b, x)    f(e₁(q, b, x), b, x)
e₁(q, b, x)   E    q
```

在这里,我们可以把 e₁(q, b, x) 换成 q′,然后给出 f 的表(取正确的代入),最终得到一个不含任何 m-函数的表。

**pe(ℭ, β)** = f(pe₁(ℭ, β), ℭ, α);其中 **pe₁(ℭ, β)**:

| m-格局 | 符号 | 行为 | 最终 m-格局 |
|---|---|---|---|
| pe₁(ℭ, β) | 任意 | R, R | pe₁(ℭ, β) |
| | 无 | Pβ | ℭ |

从 pe(ℭ, β) 出发,机器在符号序列的末尾打印 β,→ ℭ。

**l(ℭ)**:L → ℭ;**r(ℭ)**:R → ℭ。
从 f′(ℭ, 𝔅, α) 出发,机器所做的与 f(ℭ, 𝔅, α) 情形相同,只是在 → ℭ 之前先向左移动。

**f′(ℭ, 𝔅, α)** = f(l(ℭ), 𝔅, α)。
**f″(ℭ, 𝔅, α)** = f(r(ℭ), 𝔅, α)。

**c(ℭ, 𝔅, α)** = f′(c₁(ℭ), 𝔅, α);其中 **c₁(ℭ)**:β → pe(ℭ, β)。
c(ℭ, 𝔅, α):机器在末尾写下第一个被 α 标记的符号,→ ℭ。

末行代表把 β 替换为有关机器的纸带上可能出现的每一个符号后所得的全体行。

**ce(ℭ, 𝔅, α)** = c(e(ℭ, 𝔅, α), 𝔅, α)。
**ce(𝔅, α)** = ce(ce(𝔅, α), 𝔅, α)。
ce(𝔅, α):机器在末尾按次序抄下所有被 α 标记的符号,并擦去字母 α;→ 𝔅。

**re(ℭ, 𝔅, α, β)** = f(re₁(ℭ, 𝔅, α, β), 𝔅, α);其中 **re₁(ℭ, 𝔅, α, β)**:E, Pβ → ℭ。
re(ℭ, 𝔅, α, β):机器把第一个 α 换成 β,→ ℭ;若没有 α,则 → 𝔅。

**re(𝔅, α, β)** = re(re(𝔅, α, β), 𝔅, α, β)。
re(𝔅, α, β):机器把所有的字母 α 换成 β;→ 𝔅。

**cr(ℭ, 𝔅, α)** = c(re(ℭ, 𝔅, α, α), 𝔅, α)。
**cr(𝔅, α)** = cr(cr(𝔅, α), re(𝔅, α, α), α)。
cr(𝔅, α) 与 ce(𝔅, α) 的差别仅在于:字母 α 不被擦去。当纸带上没有任何字母 α 时,便进入 m-格局 cr(𝔅, α)。

**cp(ℭ, 𝔘, ℌ, α, β)** = f′(cp₁(ℭ, ℌ, β), f(ℭ, 𝔘, β), α);其中:

| m-格局 | 符号 | 行为 | 最终 m-格局 |
|---|---|---|---|
| cp₁(ℭ, 𝔘, β) | γ | | f′(cp₂(ℭ, 𝔘, γ), 𝔘, β) |
| cp₂(ℭ, 𝔘, γ) | γ | | ℭ |
| | 非 γ | | 𝔘 |

第一个被 α 标记的符号与第一个被 β 标记的符号相比较:若 α 与 β 二者皆无,→ ℌ;若二者都有且符号相同,→ ℭ;否则 → 𝔘。

**cpe(ℭ, 𝔘, ℌ, α, β)** = cp(e(e(ℭ, ℭ, β), ℭ, α), 𝔘, ℌ, α, β)。
cpe(ℭ, 𝔘, ℌ, α, β) 与 cp(ℭ, 𝔘, ℌ, α, β) 的差别在于:当出现相同情形时,第一个 α 和 β 被擦去。

**cpe(𝔘, ℌ, α, β)** = cpe(cpe(𝔘, ℌ, α, β), 𝔘, ℌ, α, β)。
cpe(𝔘, ℌ, α, β):被 α 标记的符号序列与被 β 标记的符号序列相比较,相同则 → ℌ,否则 → 𝔘;有一些 α 和 β 会被擦去。

**q(ℭ)**、**q₁(ℭ)**:

| m-格局 | 符号 | 行为 | 最终 m-格局 |
|---|---|---|---|

## §6 通用计算机器

## §8 对角线法的应用

或有人以为,证明实数不可枚举的那些论证,也能证明可计算数与可计算序列不可枚举。\* 例如,或许会以为可计算数序列的极限必定可计算。显然,只有当可计算数序列由某种规则定义时,这才成立。

> \* 参见 Hobson, *Theory of functions of a real variable* (2nd ed., 1921), 87, 88。

这类论证之一可以表述如下:\[设可计算序列可枚举,\]令 `αₙ` 为第 n 个可计算序列,令 `φₙ(m)` 为 `αₙ` 的第 m 位数码。令 `β` 为以 `1 − φₙ(n)` 为其第 n 位数码的序列。既然 `β` 是可计算的,就存在一个数 K,使得对一切 n 有 `φ_K(n) = 1 − φₙ(n)`。取 n = K,得 `1 = 2φ_K(K)`,即 1 是偶数。这不可能。因此可计算序列不可枚举。

这个论证的谬误在于假定 `β` 是可计算的。如果我们能用有穷手段枚举可计算序列,`β` 确实就是可计算的;但枚举可计算序列的问题,等价于判定一个给定的数是不是某台非循环机器的 D.N 的问题,而对这个问题,我们没有能在有穷步数内完成的一般过程。事实上,正确地运用对角线法论证,我们可以证明不可能有这种一般过程。

最简单也最直接的证明是:如果存在这个一般过程,那么就有一台计算出 `β` 的机器。这个证明虽然完全可靠,却有这样一个缺点:它可能使读者觉得"准是哪里出了毛病"。我将给出的证明没有这个缺点,并且对"非循环"这一观念的意义给出某种洞察。它不靠构造 `β`,而靠构造 `β′`——其第 n 位数码为 `φₙ(n)`。

**〔印刷页 35|PLMS 247〕**

设真有这样一个过程;也就是说,我们能造出一台机器 `ℋ`,当把任一计算机器 `ℳ` 的 S.D 提供给它时,`ℋ` 检验这个 S.D:若 `ℳ` 是循环的,就把 S.D 标以符号 "u",若 `ℳ` 是非循环的,就标以 "s"。把机器 `ℋ` 与 `𝒰` 组合起来,我们可以构造一台计算序列 `β′` 的机器 `ℒ`。机器 `ℒ` 可能需要一条纸带。可以设想它使用 F-方格上全部符号之外的 E-方格,并且当它作出裁定后,`ℋ` 所做的全部草稿都被擦去。

机器 `ℒ` 的运行分为若干段。在前 N−1 段中,机器(除其他事项外)已把整数 1, 2, …, N−1 写下并由机器 `ℋ` 检验完毕。其中被发现是非循环机器之 D.N 者,设有 `R(N−1)` 个。在第 N 段中,机器 `ℒ` 检验数 N。若 N 是满意数,即它是某台非循环机器的 D.N,则 `R(N) = R(N−1) + 1`,并且把 D.N 为 N 的那个序列的前 `R(N)` 位数码计算出来;这个序列的第 `R(N)` 位数码被写下,作为 `ℒ` 所计算的序列 `β′` 的一位数码。若 N 不是满意数,则 `R(N) = R(N−1)`,机器接着进入其运行的第 (N+1) 段。

从 `ℒ` 的构造可以看出 `ℒ` 是非循环的。`ℒ` 的每一段运行都在有穷步数后结束。因为,按我们关于 `ℋ` 的假定,对 N 是否满意的判定在有穷步数内作出。若 N 不满意,第 N 段即告结束。若 N 满意,这意味着 D.N 为 N 的机器 `ℳ(N)` 是非循环的,因此它的第 `R(N)` 位数码能在有穷步数内算出。当这一位数码算出并写为 `β′` 的第 `R(N)` 位数码后,第 N 段结束。故 `ℒ` 是非循环的。

现在令 K 为 `ℒ` 的 D.N。`ℒ` 在其运行的第 K 段里做什么呢?它必须检验 K 是否满意,给出裁定 "s" 或 "u"。既然 K 是 `ℒ` 的 D.N 而 `ℒ` 是非循环的,裁定不能是 "u"。另一方面,裁定也不能是 "s"。因为若是 "s",那么 `ℒ` 在其运行的第 K 段中就必须计算以 K 为 D.N 的机器所算序列的前 `R(K−1)+1 = R(K)` 位数码,并把第 `R(K)` 位写下作为 `ℒ` 所算序列的一位数码。前 `R(K)−1` 位的计算可以照常完成,但计算第 `R(K)` 位的指令就相当于"计算 `ℒ` 所算的前 R(K) 位数码,并写下第 R(K) 位"。这第 `R(K)` 位数码永远找不到。就是说,`ℒ` 是循环的——这既与上一段的结论矛盾,也与裁定 "s" 矛盾。两个裁定都不可能,于是我们断定:不可能有机器 `ℋ`。

**〔印刷页 36|PLMS 248〕**

我们还可以进一步证明:不可能有这样的机器 `𝒮`——当把任一机器 `ℳ` 的 S.D 提供给它时,它能判定 `ℳ` 是否打印某个给定符号(比如 0)。

我们先证明:如果有一台机器 `𝒮`,那么就有一个一般过程,能判定一台给定的机器 `ℳ` 是否无穷多次地打印 0。设 `ℳ₁` 是一台与 `ℳ` 打印同一序列的机器,只是:在 `ℳ` 打印第一个 0 的位置,`ℳ₁` 打印 `0̄`;`ℳ₂` 则把前两个 0 都换成 `0̄`,依此类推。于是,若 `ℳ` 打印

`ABA01AAB0010AB…`

则 `ℳ₁` 打印

`ABA0̄1AAB0010AB…`

`ℳ₂` 打印

`ABA0̄1AAB0̄010AB…`

〔勘误:三行中 0 上之横线(0̄)在 OCR 中全部失落;横线的归属(ℳ 无横线,ℳᵢ 将前 i 个 0 加横线)系按定义与后文 𝒥/𝒮 论证之逻辑复原。〕现在设 `𝒢` 是这样一台机器:把 `ℳ` 的 S.D 提供给它,它就相继写下 `ℳ`、`ℳ₁`、`ℳ₂`、… 的 S.D(这样的机器是有的)。把 `𝒢` 与 `𝒮` 组合,得到一台新机器 `𝒥`。`𝒥` 的运行中,先用 `𝒢` 写下 `ℳ` 的 S.D,然后 `𝒮` 检验它;若发现 `ℳ` 从不打印 0,就写下 ":0:";然后 `𝒢` 写下 `ℳ₁` 的 S.D,再检验之,当且仅当 `ℳ₁` 从不打印 0 时打印 ":0:",依此类推。现在用 `𝒮` 来检验 `𝒥`。若发现 `𝒥` 从不打印 0,则 `ℳ` 无穷多次打印 0;若 `𝒥` 有时打印 0,则 `ℳ` 并非无穷多次打印 0。

类似地,有一个一般过程判定 `ℳ` 是否无穷多次打印 1。把这两个过程组合起来,我们就得到判定 `ℳ` 是否打印无穷多个数码的过程,也就是判定 `ℳ` 是否非循环的过程。因此,不可能有机器 `𝒮`。

"存在判定……的一般过程"这一说法,本节中一直当作与"存在一台能判定……的机器"等价来使用。这种用法,当且仅当我们能为我们对"可计算"的定义辩护时,才能得到辩护。因为这类"一般过程"问题,每一个都可表达为:对于给定的整数 n 是否具有性质 G(n)\[例如 G(n) 可以是 "n 是满意数",或 "n 是某个可证公式的哥德尔表示"\],是否存在判定它的一般过程的问题;而这等价于计算这样一个数:当 G(n) 为真时其第 n 位数码为 1,当 G(n) 为假时其第 n 位数码为 0。

## §9 可计算数的范围(起始)

**〔印刷页 37|PLMS 249〕**

至今还没有人尝试证明,"可计算的"数包括了所有自然会被视为可计算的数。一切能给出的论证,归根到底都是对直觉的诉求,因而在数学上颇不令人满意。真正的问题在于:"在计算一个数时,可能用到的过程是哪些?"

我将使用的论证有三类:

(a) 直接诉诸直觉;

(b) 证明两个定义等价(当新定义具有更大的直觉吸引力时);

(c) 给出可计算的大类数的例子。

至今还没有人尝试证明,"可计算的"数包括了所有自然会被视为可计算的数。一切能给出的论证,归根到底都是对直觉的诉求,因而在数学上颇不令人满意。真正的问题在于:"在计算一个数时,可能用到的过程是哪些?"

我将使用的论证有三类。

(a) 直接诉诸直觉;

(b) 证明两个定义等价(当新定义具有更大的直觉吸引力时);

(c) 给出可计算的大类数的例子。

一旦承认可计算数全都是"可计算的",便可得出若干同类的命题。特别地,由此可得:如果对希尔伯特函数演算中的一个公式是否可证明,存在一个判定的一般过程,那么这个判定就可以由一台机器完成。

**I.\[类型 (a)\]** 这个论证不过是 §1 中思想的细化。计算通常是通过在纸上写某些符号来完成的。我们可以设想这张纸像小学生的算术本一样划分成方格。初等算术中有时会用到纸的二维特征,但这种用法总是可以避免的,而且我想人们会同意:纸的二维特征不是计算的本质所在。于是我假定计算是在一维的纸上,即划分成方格的纸带上进行的。我还要假定,可以打印的符号的个数是有穷的。倘若允许无穷多个符号,那么就会有彼此差异小到任意程度的符号†。把符号个数作这一限制,影响不很严重:总可以用符号序列来代替单个符号。

> †如果我们把符号看成是字面上印在一个方格上的,可以设方格为 0<x<1, 0<y≤1。符号定义为这个方格内的一个点集,即印刷油墨占据的点集。如果把这些点集限制为可测,我们就可以定义两个符号之间的"距离":把一个符号变换成另一个符号所需的代价——其中,把单位面积油墨移动单位距离的代价取为 1,并且在 x=2, y=0 处存有无限油墨供应。在这个拓扑下,诸符号构成一个条件紧空间。

于是,像 17 或 999999999999999 这样的一个阿拉伯数码,通常就被当作单独一个符号来对待。类似地,在任何一种欧洲语言里,词都被当作单个符号(汉语则试图使用可枚举的无穷多个符号)。从我们的观点看,单个符号与复合符号的差别在于:复合符号若太长,就无法一眼看尽。这与经验相符:我们无法一眼看出 9999999999999999 与 999999999999999 是否相同。

**〔印刷页 38|PLMS 250〕**

计算员(computer)在任何时刻的行为,由他此刻注视着的符号以及他此刻的"心态"(state of mind)决定。我们可以设想,计算员在同一时刻所能注视的符号或方格的数目有一个上界 B。若他想注视更多,就必须相继地进行多次观察。我们还假定,需要计入的心态的数目是有穷的。理由与限制符号数目的理由性质相同:倘若承认无穷多种心态,其中一些就会"任意接近"而彼此混淆。同样,这一限制也不至于严重影响计算,因为更复杂的心态可以通过在纸带上多写些符号来避免。

让我们把计算员执行的操作设想为分解成若干"简单操作",它们初等到令人难以想象还能再分。每一个这样的操作都由"计算员连同他的纸带"这个物理系统的某种变化组成。如果我们知道纸带上符号的序列、其中哪些正被计算员观察着(可能还带有某种特殊次序)、以及计算员的心态,我们就知道这个系统的状态。我们可以设想,在一个简单操作中被改变的符号不多于一个。任何其他变化都可以分解成这种性质的简单变化。至于其符号可能被这样改变的方格,情形与被观察的方格相同。因此,我们可以不失一般性地假定:符号被改变的方格永远是"被注视的"方格。

除了这些符号变化之外,简单操作还必须包括被观察方格分布的变化。新的被观察方格必须能被计算员立即辨认出来。我认为可以合理地设想:它们只能是那些与紧邻的前一次被观察方格之一的距离不超过某个固定量的方格。换句话说,设每个新的被观察方格都在某一紧邻先前被观察方格的 L 格范围之内。

围绕"立即的可辨认性",或许有人认为还有别种方格也是立即可辨认的。特别是,由特殊符号标记出来的方格可能被视为立即可辨认的。可是,如果这些方格只用单个符号来标记,它们的数目就只能是有穷的,而把这些带标记的方格并入被观察方格,并不会打乱我们的理论。反过来,如果它们是由一串符号来标记的,那么识别的过程就不能再看作简单过程。这是一个根本性的问题,值得举例说明。在大多数数学论文里,方程和定理都编了号。编号通常不超出(比如说)1000,因此凭号码就能一眼认出一条定理。但假如论文非常长,我们也许会碰到定理 157767733443477;再往后,也许又会看到"……于是(应用定理 157767733443477)得……"。为了确证所引究竟是哪条定理,我们必须把两个数逐位比较,可能还得用铅笔逐位打钩,以免有的数字被数了两遍。即便如此,若仍有人认为存在其他"立即可辨认"的方格,那也不要紧:只要这些方格能够经由某种我的那种类型的机器力所能及的过程找到,我的论点就不受损害。这一想法将在下文 III 中展开。

**〔印刷页 39|PLMS 251〕**

因此,简单操作必须包括:

(a) 改变某个被观察方格上的符号;

(b) 把被观察的方格之一改换成另一方格,后者在某一先前被观察方格的 L 格范围之内。

上述变化中的某些,或许必然伴随着心态的改变。因此,最一般的单一操作必须取为下列情形之一:

(A) 符号的一种可能变化 (a),连同心态的一种可能改变;

(B) 被观察方格的一种可能变化 (b),连同心态的一种可能改变。

实际执行的操作,正如 p. 250 处已经提示过的,由计算员的心态与被观察的符号共同决定。特别地,它们也决定操作执行完毕之后计算员的心态。

现在我们可以构造一台机器,来做这位计算员的工作。计算员的每一种心态,对应于机器的一个"m-格局"。机器注视 B 个方格,与计算员所观察的 B 个方格相对应。在任一动作中,机器或者改变某个被注视方格上的符号,或者把被注视方格之一改换到另一方格,后者与另一被注视方格之一的距离不超过 L 格。执行哪一个动作、以及后继的格局是什么,由被注视的符号和 m-格局决定。刚才描述的这类机器,与 §2 中定义的计算机器并没有本质的差异;而且,对应于任何一台这种类型的机器,都能构造出一台计算机器去计算同一个序列——也就是说,算出由那位计算员所算出的序列。

**〔印刷页 40|PLMS 252〕**

**II.\[类型 (b)\]**

如果把希尔伯特函数演算的记法加以修改,使之系统化,并且只涉及有穷多个符号ᵗ,就有可能构造出一台自动机 ℳ‡,它将找出该演算的所有可证公式¶。

> ᵗ"函数演算"(the functional calculus)一词在全文中均指受限的希尔伯特函数演算(restricted Hilbert functional calculus)。
>
> ‡最自然的做法是先造一台选择机(§2)来做这件事。但要再造出所需的自动机却很容易。我们可以设想,选择永远是在 0 与 1 两种可能之间作的选择。于是每个证明都将由一列选择 i₁, i₂, …, iₙ(i₁=0 或 1,i₂=0 或 1,……,iₙ=0 或 1)确定,从而数 2ⁿ + i₁2ⁿ⁻¹ + i₂2ⁿ⁻² + … + iₙ 就完全确定了这个证明。自动机则相继执行证明 1、证明 2、证明 3、……。
>
> ¶作者本人已经找到一台这样的机器的描述。

现在设 α 是一个序列,并用 G(x) 表示命题"α 的第 x 位数码是 1",于是 ∼G(x) 的意思便是"α 的第 x 位数码是 0"。再进一步假设:我们能找到一组性质,它们定义了序列 α,并且能够借助 G(x)、以及两个命题函项——N(x),意即"x 是非负整数"——与 F(x, y),意即"y=x+1"——表达出来。把所有这些公式合取地连接起来,我们就得到一个公式——设为 𝔉——它定义了 α。𝔉 的诸项必须包含皮亚诺公理中必要的部分,即

$$
(\exists u)\,N(u)\ \&\ (u)\bigl(N(u)\supset(\exists v)\,F(u,v)\bigr)\ \&\ (u,v)\bigl(N(u)\,\&\,N(v)\,\&\,F(u,v)\supset u=v\bigr)\ \cdots
$$

我们将其缩写为 P。

当我们说"𝔉 定义 α"时,意思是:∼𝔉 不是可证公式,并且,对每一个 n,下列公式 (An) 或 (Bn) 中有一个是可证的:

$$
\text{(An)}\qquad \&\ F(u^{(n)})\supset G(u^{(n)}),\qquad\qquad \text{(Bn)}\qquad F(u^{(n)})\supset(\sim G(u^{(n)})),
$$

其中 F(u⁽ⁿ⁾) 代表 F(u, u′) & F(u′, u″) & …… F(u⁽ⁿ⁻¹⁾, u⁽ⁿ⁾)。

> ‖否定号写在表达式之前,而不是写在表达式上方。
>
> \*\*r 个撇号的序列记作 ⁽ʳ⁾。

**〔印刷页 41|PLMS 253〕**

我要断言:α 于是就是一个可计算序列——对 ℳ 作相当简单的修改,即可得到一台计算 α 的机器 𝒯。

我们把 𝒯 的运行分成若干节(section)。第 n 节的任务是求出 α 的第 n 位数码。第 (n−1) 节结束后,在全部符号之后打印一个双冒号 ::,此后的工作完全在这个双冒号右侧的方格上进行。第一步是写下字母"A",其后写上公式 (An);然后写"B",其后写上 (Bn)。接着机器 𝒯 开始做 ℳ 的工作;每当找到一个可证公式,就拿它与 (An) 和 (Bn) 相比较。若它与 (An) 是同一个公式,则打印数码"1",第 n 节宣告完成;若它是 (Bn),则打印"0",这一节同样宣告完成;若它与两者都不同,那么 𝒯 就从先前搁置之处继续它的工作。(An) 或 (Bn) 迟早会被遇到——这一点由我们关于 α 和 𝔉 的假设以及 ℳ 的已知性质所保证。因此第 n 节终将完成。𝒯 是非循环的(circle-free);α 是可计算的。

还可以证明:凡以这种方式借助公理定义出来的数,也包括了全部可计算数。做法是用函数演算的语言来描述计算机器。

必须记住,"𝔉 定义 α"这个说法,我们所赋予的是相当特殊的含义。可计算数并不包括(通常意义上的)一切可定义的数。设 δ 是这样一个序列:它的第 n 位数码是 1 还是 0,视 n 是不是满意数(satisfactory number)而定。由 §8 的定理立即可得:δ 不是可计算的。就目前所知,有可能 δ 的任意指定个数的数码都可以算出来,但不存在一个一致的过程;当 δ 的足够多的数码已经被算出之后,要再往下求得更多数码,就需要本质上全新的方法。

**III.** 这一部分既可以看作 I 的变形,也可以看作 II 的推论。

我们像在 I 中那样,假定计算是在一条纸带上进行的;但我们不再引入"心态",而是考虑它的一个更物理、更明确的对应物。计算员随时可以中断手头的工作,走开,把这件事整个忘掉,过一会儿再回来接着干。他若这样做,就必须留下一张(以某种标准格式写成的)指令便条,说明工作该如何继续下去。这张便条就是"心态"的对应物。我们设想计算员干活的方式十分散漫(desultory),每坐下一次至多执行一步。

**〔印刷页 42|PLMS 254〕**

这张指令便条必须能使他完成一步,并写出下一条便条。于是,计算在任一阶段的进展状态,都完全由指令便条与纸带上的符号决定。也就是说,系统的状态可以用单独一个表达式(一个符号序列)来描述:它由纸带上的符号、其后跟着的字母 A(我们约定 A 不出现在其他任何地方)、再其后跟着的指令便条组成。这个表达式可以称作"状态公式"(state formula)。我们知道,任一给定阶段的状态公式,由前一步执行之前的状态公式决定;而我们假定,这两个公式之间的关系可以在函数演算中表达出来。换句话说,我们假定存在一条公理 𝔄,它借助任一阶段的状态公式对前一阶段状态公式的关系,表达了支配计算员行为的种种规则。倘若果真如此,我们就能构造出一台机器,让它依次写下各个状态公式,从而计算出所要的数。

## §10 可计算数的一些大类之例

先给出整变元的可计算函数与可计算变元的可计算函数之类的定义,将会是有用的。定义整变元的可计算函数有许多彼此等价的方式。最简单的或许是这样:设 γ 是一个 0 无穷多次出现的†可计算序列,n 为一整数,令 ξ(γ, n) 表示 γ 中第 n 个与第 (n+1) 个数码 0 之间数码 1 的个数。那么,若对所有的 n 及某个 γ 有 φ(n) = ξ(γ, n),则称 φ 是可计算的。

一个等价的定义是这样的:令 H(x, y) 意谓"φ(x) = y"。若我们能找到一个无矛盾的公理 ℭ,使得 ℭ → P,并且对每个整数 n 都存在整数 N,使得

$$\mathfrak{C}\ \&\ F(N)\rightarrow H\bigl(u(n),\,u(\varphi(n))\bigr),$$

而且当 m ≠ n 时,存在某个 N′,使〔译注1〕

$$\mathfrak{C}\ \&\ F(N')\rightarrow\bigl(G\bigl(u(\varphi(m)),\,u(\varphi(n))\bigr)\ \vee\ G\bigl(u(\varphi(n)),\,u(\varphi(m))\bigr)\bigr),$$

则可以说 φ 是一个可计算函数。

> † 若机器 𝒥 计算 γ,则"𝒥 是否无穷多次打印 0"这一问题,与"该机器是否非循环"的问题性质相同。

我们不能定义实变元的一般可计算函数,因为描述一个实数并无一般方法;但我们可以定义可计算变元的可计算函数。若 n 是满意数,令 βₙ 为机器 𝒩(n) 所计算的数,并令

$$a_n=\sum_{i=0}^{\infty}\beta_{n,i}\,2^{-(i+1)},$$

除非 βₙ = 0 或 βₙ = 1——在这两种情形下一律规定 aₙ = 0。于是,当 n 取遍诸满意数时,aₙ 取遍诸可计算数\*。今设 φ(m) 是一个可计算函数,且可以证明它对任何满意的自变量给出的值也是满意的‡。那么,由 f(aₘ) = a_{φ(m)} 定义的函数 f 就是一个可计算函数,而且可计算变元的一切可计算函数都可以表成这种形式。

> \* 使 αₙ 如此地取遍可计算数的定义方式还有很多。
>
> ‡ 虽然不可能找到一个判定给定的数是否满意的一般过程,但往往能够证明某些类的数是满意的。

多个变元的可计算函数、取可计算值为函数值的整变元函数等等,均可类似地定义。

我将列举若干关于可计算性的定理,但只证明 (ii) 与一个类似于 (iii) 的定理。

(i) 整变元或可计算变元的可计算函数之可计算函数是可计算的。

(ii) 凡借助于可计算函数递归地定义出的整变元函数都是可计算的。也就是说,若 φ(m, n) 可计算,r 为某个整数,则 ν(n) 可计算,其中

$$\nu(0)=r,\qquad \nu(n)=\varphi\bigl(\nu(n-1),\,n\bigr).$$

(iii) 若 φ(m, n) 是两个整变元的可计算函数,则 φ(f(n), n) 是 n 的可计算函数。

(iv) 若 φ(n) 是一个值恒为 0 或 1 的可计算函数,则以 φ(n) 为第 n 个数码的序列是可计算的。

如果我们把"实"通盘替换为"可计算",Dedekind 定理并不以其通常的形式成立。但它成立如下形式:

(v) 若 G(α) 是关于可计算数的命题函数,且〔译注2〕

$$\text{存在判定 } G(\alpha) \text{ 真假的一般过程,}$$

则存在一个可计算数 ξ,使得〔译注2〕

$$G(\alpha)\ \equiv\ [\alpha\leqslant\xi].$$

换言之,这条定理对可计算数的任何一个截节都成立,只要存在一个一般过程,能判定一个给定的数属于哪一类。

由于 Dedekind 定理受到这一限制,我们不能断言:可计算数的可计算有界递增序列必有可计算的极限。考虑这样一个序列或有助于理解这一点:

$$-1,\ -\tfrac{7}{8},\ -\tfrac{3}{4},\ -\tfrac{1}{2},\ \ldots\ ^{〖译注3〗}$$

另一方面,(v) 使我们得以证明:

(vi) 若 α 与 β 可计算,α < β,而 φ 是可计算的递增连续函数,且 φ(α) < 0 < φ(β),则存在唯一的可计算数 γ,满足 α < γ < β 且 φ(γ) = 0。

**可计算收敛**

若有这样一个取整值的、以可计算数 ε 为变元的可计算函数 N(ε),使我们能够证明:凡 ε > 0 且 n > N(ε)、m > N(ε),便有 |βₙ − βₘ| < ε,则称可计算数序列 βₙ **可计算地收敛**。

于是可以证明:

(vii) 一个幂级数,若其系数构成可计算数的可计算序列,则它在收敛区间内部的一切可计算点处都可计算地收敛。

(viii) 可计算收敛序列的极限是可计算的。

再加上"一致可计算收敛"的显然定义,则有:

(ix) 一个一致可计算收敛的可计算序列(其各项为可计算函数)的极限是一个可计算函数。因此:

(x) 一个幂级数,若其系数构成可计算序列,则其和函数在收敛区间内部是可计算函数。

由 (viii) 与

$$\pi=4\left(1-\tfrac{1}{3}+\tfrac{1}{5}-\tfrac{1}{7}+\cdots\right)$$

推知 π 可计算。由

$$e=1+1+\tfrac{1}{2!}+\tfrac{1}{3!}+\cdots$$

推知 e 可计算。

由 (vi) 推知一切实代数数皆可计算。由 (vi) 与 (x) 推知 Bessel 函数的实零点皆可计算。

**(ii) 之证明**

令 H(x, y) 意谓"ν(x) = y",K(x, y, z) 意谓"φ(z, y) = x"〔译注4〕。ℭ 是关于 φ(x, y) 的公理;取 ℭ 为

〔原刊此处印有一长行公理式,本卷文本层完全失落——按其职能,当为陈述 ν 的基例与归纳步(即上节递归式)并刻画自然数次序 G 之基本性质的合取式。兹从略,详见译注4。〕

我不拟给出 ℭ 一致性的证明。这样的证明可以按 Hilbert 与 Bernays《Grundlagen der Mathematik》(Berlin, 1934) 第 209 页以下所用的方法构造出来;由含义看,一致性也是清楚的。

设对某个 n、N 我们已经证得

$$\mathfrak{C}\ \&\ F(N)\rightarrow H\bigl(u(\nu(n-1)),\,u(\nu(n-1))\bigr),$$

则对某个 M 有

$$\mathfrak{C}\ \&\ F(M)\rightarrow K\bigl(u(\nu(n-1)),\,u(n),\,u(\nu(n))\bigr),$$

$$\mathfrak{C}\ \&\ F(M)\rightarrow F\bigl(u(\nu(n-1)),\,u(\nu(n))\bigr)\ \&\ H\bigl(u(\nu(n-1)),\,u(\nu(n-1))\bigr)\ \&\ K\bigl(u(\nu(n-1)),\,u(n),\,u(\nu(n))\bigr),$$

以及〔译注4〕

$$\mathfrak{C}\ \&\ F(M)\rightarrow\bigl[F\bigl(u(\nu(n-1)),\,u(n)\bigr)\ \&\ H\bigl(u(\nu(n-1)),\,u(\nu(n-1))\bigr)\rightarrow K\bigl(u(\nu(n-1)),\,u(n),\,u(\nu(n))\bigr)\rightarrow H\bigl(u(n),\,u(\nu(n))\bigr)\bigr].$$

故得

$$\mathfrak{C}\ \&\ F(M)\rightarrow H\bigl(u(n),\,u(\nu(n))\bigr).$$

又有

$$\mathfrak{C}\ \&\ F(r')\rightarrow H\bigl(u,\,u(r)\bigr).$$

于是对每个 n,都有形如

$$\mathfrak{C}\ \&\ F(M)\rightarrow H\bigl(u(n),\,u(\nu(n))\bigr)$$

的公式可证。此外,若 M′ ⩾ M、M′ ⩾ m 且 m 满足某一次序条件〔译注5〕,则有

$$\mathfrak{C}\ \&\ F(M')\rightarrow\bigl(G\bigl(u(\nu(n)),\,u(m)\bigr)\ \vee\ G\bigl(u(m),\,u(\nu(n))\bigr)\bigr),$$

且

$$\mathfrak{C}\ \&\ F(M')\rightarrow\bigl[\bigl(G\bigl(u(\nu(n)),\,u(m)\bigr)\vee G\bigl(u(m),\,u(\nu(n))\bigr)\bigr)\rightarrow\cdots\bigr],$$

从而

$$\mathfrak{C}\ \&\ F(M')\rightarrow H\bigl(u(n),\,u(m')\bigr).$$

于是,"可计算函数"第二个定义的条件全部得到满足。故 ν 是可计算函数。

**(iii) 之一个变形的证明**

设给定机器 𝒩:纸带起始时在 F-方格上印有 ə,其后跟着任意多个字母 "F",机器处于 m-格局 b;它将计算出一个序列 γₙ,γₙ 依赖于字母 "F" 的个数 n。若 tₙ(m) 是 γₙ 的第 m 个数码,则以 tₙ(n) 为第 n 个数码的序列 β 是可计算的。

我们假定 𝒩 的表已经写成这样的样子:每一行的操作列里只出现一个操作。我们还假定表中不出现 ə、0 与 1,并把全文中的 D 代之以 ə、0 代之以 0、1 代之以 1。然后再作进一步的替换。凡形如

| 𝔅 | α | Pβ | β |

的行,代之以

| 𝔅 | α | P0 | re(𝔅, β, h, k) |

而凡形如

的行,代之以〔译注6〕

| 𝔅 | α | P1 | re(𝔅, β, h, k) |

再向表中添入下列各行〔译注6〕:

| u  |                    |                  | re(u₁, u₂, k, h) |
| u₁ | R, Pk, R, Pə, R, Pə |                  | u₂               |
| u₂ |                    |                  | re(u₃, u₃, k, h) |

这样我们便得到了计算机器 𝒩′ 的表;𝒩′ 计算序列 β。初始 m-格局为 c,初始被注视符号为第二个 ə。

## §11 对判定问题的应用

§8 的结果有一些重要的应用。特别地,可以用它们来证明希尔伯特的判定问题(Hilbertian Entscheidungsproblem)不可能有解。目前我只限于证明这一个定理。关于这个问题的提法,必须请读者查阅 Hilbert 与 Ackermann 的《Grundzüge der theoretischen Logik》(Berlin, 1931)第三章。

因此,我打算证明:不存在一个一般过程,用以判定函数演算 K 中任一给定的公式 𝔄 是否可证;也就是说,不存在这样一台机器——喂给它这些公式中的任何一个 𝔄,它终会说出 𝔄 是否可证。

或许应当指出,我要证明的东西与 Gödel 的著名结果颇不相同†。Gödel 已证明(在《Principia Mathematica》的形式体系中)存在命题 𝔄,使得 𝔄 与 ¬𝔄 均不可证。作为这一结果的推论,可以表明:《Principia Mathematica》(或 K)的一致性在该形式体系内部是不可能给出证明的。另一方面,我将证明:没有一般方法可以告知给定的公式 𝔄 在 K 中是否可证;或者——这与此是一回事——由 K 附加 ¬𝔄 作为一条额外公理而成的系统是否一致。

> † Loc. cit.(见前引文)

倘若得到证明的竟是 Gödel 所证结果的否定,即对每个 𝔄,𝔄 或 ¬𝔄 至少其一可证,那么我们立刻就能解决判定问题。因为我们不妨造一台机器 𝒦,它会接连不断地证明一切可证的公式。𝒦 迟早会遇到 𝔄 或 ¬𝔄。若遇到的是 𝔄,便知 𝔄 可证;若遇到的是 ¬𝔄,则由于 K 是一致的(Hilbert 与 Ackermann,p. 65),便知 𝔄 不可证。

由于 K 中没有整数,这里的证明显得有些冗长;但其背后的想法十分直截了当。

对应于每台计算机器 𝒜,我们构造一个公式 Uₙ(𝒜),并证明:若存在判定 Uₙ(𝒜) 是否可证的一般方法,则存在判定 𝒜 是否终会打印 0 的一般方法。

所涉及的诸命题函数的解释如下:

Rₛ(x, y):解释为"在(𝒜 的)完全格局 x 中,方格 y 上的符号是 S"。

I(x, y):解释为"在完全格局 x 中被注视的方格是 y"。

K_qm(x):解释为"在完全格局 x 中,m-格局是 q_m"。

F(x, y):解释为"y 是 x 的紧后继"。

Inst{qi Sj Sk L ql} 是下式的缩写〔译注7〕:

$$(x,\,y,\,x',\,y')\Bigl\{\bigl(R_{s_j}(x,y)\ \&\ I(x,y)\ \&\ K_{q_i}(x)\ \&\ F(x,x')\bigr)\rightarrow\bigl(F(y',y)\ \&\ I(x',y')\ \&\ R_{s_k}(x',y)\ \&\ K_{q_l}(x')\bigr)\Bigr\}$$

Inst{qi Sj Sk R ql} 与 Inst{qi Sj Sk N ql} 则是类似地构造出来的其他表达式的缩写。

把 𝒜 的描述化为 §6 的第一种标准形式。这一描述由一批诸如 "qi Sj Sk L ql"(或以 R、N 替代 L)的表达式组成。作出所有与之对应的表达式,如 Inst{qi Sj Sk L ql},并取它们的逻辑和;称之为 Des(𝒜)。

公式 Uₙ(𝒜) 即

$$(u)\,N(u)\ \&\ (y,z)\bigl(F(y,z)\rightarrow N(y)\ \&\ N(z)\bigr)\ \&\ (y)\,R_{s_0}(u,y)$$

$$\&\ I(u,u)\ \&\ K_{q_1}(u)\ \&\ \mathrm{Des}(\mathcal{A})\rightarrow(\exists s)(\exists t)\,[\,N(s)\ \&\ N(t)\ \&\ R_{s_1}(s,t)\,].$$

[N(u) & … & Des(𝒜)] 可缩写为 A(𝒜)。

当我们代入 pp. 259–260 上所提示的含义便会发现,Uₙ(𝒜) 的解释是:"在 𝒜 的某个完全格局中,S₁(即 0)出现在纸带上"。与之相应,我证明:

(a) 若 S₁ 出现在 𝒜 某个完全格局的纸带上,则 Uₙ(𝒜) 可证。

(b) 若 Uₙ(𝒜) 可证,则 S₁ 出现在 𝒜 某个完全格局的纸带上。

做到这一步之后,定理的余下部分便是平平无奇的了。

**引理 1.** 若 S₁ 出现在 𝒜 某个完全格局的纸带上,则 Uₙ(𝒜) 可证。

我们要说明 Uₙ(𝒜) 如何证明。设在第 n 个完全格局中,纸带上的符号序列是

$$S_{r(n,0)},\ S_{r(n,1)},\ \ldots,\ S_{r(n,n)},$$

其后除空白外别无他物;被注视符号是第 i(n) 个,m-格局是 q_{k(n)}。那么我们可以构成命题

$$R_{s_{r(n,0)}}(u(n),u)\ \&\ R_{s_{r(n,1)}}(u(n),u')\ \&\ \cdots\ \&\ R_{s_{r(n,n)}}(u(n),u^{(n)})$$

$$\&\ I(u(n),u(i(n)))\ \&\ K_{q_{k(n)}}(u(n))$$

$$\&\ (y)\bigl[F(u(n),y)\vee F(u,y)\vee F(u',y)\vee\cdots\vee F(u^{(n-1)},y)\vee R_{s_0}(u(n),y)\bigr],$$

可将其缩写为 CCₙ。

与前一样,F(u, u′) & F(u′, u″) & … & F(u^(r−1), u^(r)) 缩写为 F(r)。

我将证明,一切形如 A(𝒜) & F(n) → CCₙ(缩写为 CFₙ)的公式都是可证的。CFₙ 的含义是:"𝒜 的第 n 个完全格局如此这般",其中"如此这般"就代表 𝒜 实际的第 n 个完全格局。因此 CFₙ 应当是可证的——这本在意料之中。

CF₀ 当然可证:在该完全格局中符号全是空白,m-格局是 q₁,被注视方格是 u,即 CC₀ 为

$$(y)\,R_{s_0}(u,y)\ \&\ I(u,u)\ \&\ K_{q_1}(u).$$

于是 A(𝒜) → CC₀ 是平凡的。

其次证明:对每个 n,CFₙ → CF₍ₙ₊₁₎ 可证。须分三种情形讨论,视机器在从第 n 个到第 (n+1) 个格局的一步中向左移、向右移抑或原地不动而定。设是第一种情形,即机器向左移;其余情形论证类似。若 r(n, i(n)) = a,r(n+1, i(n+1)) = c,k(i(n)) = b,k(i(n+1)) = d〔译注7〕,则 Des(𝒜) 必以 Inst{qb Sa Sc L qd} 为其一项之一,即

$$\mathrm{Des}(\mathcal{A})\rightarrow \mathrm{Inst}\{q_b\,S_a\,S_c\,L\,q_d\}.$$

故

$$A(\mathcal{A})\ \&\ F(n+1)\rightarrow \mathrm{Inst}\{q_b S_a S_c L q_d\}\ \&\ F(n+1).$$

但是

$$\mathrm{Inst}\{q_b S_a S_c L q_d\}\ \&\ F(n+1)\rightarrow(CC_n\rightarrow CC_{n+1})$$

可证,从而

$$(A(\mathcal{A})\ \&\ F(n)\rightarrow CC_n)\rightarrow(A(\mathcal{A})\ \&\ F(n+1)\rightarrow CC_{n+1})$$

也可证,即

$$CF_n\rightarrow CF_{n+1}.$$

CFₙ 对每个 n 都可证。现在,依本引理的假设,S₁ 出现在 𝒜 所打印符号序列中的某处、某个完全格局之中;就是说,对某两个整数 N、K,CC_N 以 Rs₁(u(N), u(K)) 为其一项之一,因而 CC_N → Rs₁(u(N), u(K)) 可证。于是我们有

$$CC_N\rightarrow R_{s_1}(u(N),u(K)),$$

以及

$$A(\mathcal{A})\ \&\ F(N)\rightarrow CC_N.$$

我们还有

$$(\exists u)\,A(\mathcal{A})\rightarrow(\exists u)(\exists u')\cdots(\exists u^{(N')})\,\bigl(A(\mathcal{A})\ \&\ F(N')\bigr),$$

其中 N′ = max(N, K)。从而

$$(\exists u)\,A(\mathcal{A})\rightarrow(\exists u)(\exists u')\cdots(\exists u^{(N')})\,R_{s_1}(u(N),u(K)),$$

$$(\exists u)\,A(\mathcal{A})\rightarrow(\exists u(N))(\exists u(K))\,R_{s_1}(u(N),u(K)),$$

$$(\exists u)\,A(\mathcal{A})\rightarrow(\exists s)(\exists t)\,R_{s_1}(s,t),$$

即 Uₙ(𝒜) 可证。引理 1 得证。

**引理 2.** 若 Uₙ(𝒜) 可证,则 S₁ 出现在 𝒜 某个完全格局的纸带上。

若在一个可证公式中以任何命题函数代入其函数变元,便得到一个真命题。特别地,若在 Uₙ(𝒜) 中代入 pp. 259–260 上所列的含义,便得到一个真命题,其含义为:"S₁ 出现在 𝒜 某个完全格局的纸带上的某处"。

现在我们可以证明判定问题不可解了。试设不然:存在判定 Uₙ(𝒜) 是否可证的一般(机械)过程。由引理 1 与引理 2,这就蕴含存在一个过程,用以判定 𝒜 是否终会打印 0;而由 §8,这是不可能的。故判定问题不可解。

鉴于对量词系统受限制的公式,判定问题已有大量的特例解,把 Uₙ(𝒜) 表成一个量词全部置于开头的形式是有趣的。事实上,Uₙ(𝒜) 可以表成形式

$$(u)(\exists x)(\cdots)_n\quad\text{(I)}$$

其中母式不含量词,而 n = 6〔译注8〕。经过一些不重要的修改,可以得到一个具有 Uₙ(𝒜) 的一切本质性质、且为 n = 5 的形式 (I) 的公式。

## 附录 可计算性与能行可计算性

> 〔1936 年 8 月 28 日增补。〕

「一切能行可计算的(λ-可定义的〔译注1〕)序列都是可计算的」这一定理及其逆定理,下面给出其证明的梗概。文中假定读者已理解丘奇与克林尼所用「良构公式」(W.F.F.)与「变换」(conversion)二词的含义。在这两个证明的第二个中,若干公式的存在性未经证明而径直假定;借助诸如克林尼《形式逻辑中的正整数理论》(A theory of positive integers in formal logic,*American Journal of Math.*,57 (1935),153–173,219–244)中的结果,这些公式都可以直接构造出来。

代表整数 n 的良构公式将记作 N_n。设序列 γ 的第 n 位数字为 φ(n)。若 φ(n)〔译注2〕是 n 的 λ-可定义函数,则称序列 γ 是 **λ-可定义的**或**能行可计算的**;也就是说,若存在良构公式 M_γ,使得对一切整数 n,

{M_γ}(N_n) conv N_{φ(n)+1},

即 {M_γ}(N_n) 可变换为 λxy.x(x(y)) 或 λxy.x(y),视 γ 的第 n 位数字为 1 还是 0 而定〔译注3〕。

为了证明每个 λ-可定义的序列 γ 都可计算,必须说明如何构造一台机器来计算 γ。为便于配合机器使用,对变换演算作一处平凡的改动是有益的:这个改动就是用 x,x′,x″,… 作变元,以代替 a,b,c,…。现在构造一台机器 `𝒢`:当供给它公式 M_γ 时,它便写出序列 γ〔译注4〕。`𝒢` 的构造方式与 §11 中那台找出函数演算全部可证公式的机器颇为相仿。我们首先构造一台选择机 `𝒞₁`:若供给它一个良构公式(设为 M)并施以适当操纵,它便能得出任何一个可与 M 相变换的公式。`𝒞₁` 又可以改造成为一台自动机 `𝒞₂`,它依次得出一切可与 M 相变换的公式(参见第 252 页脚注)。机器 `𝒢` 把 `𝒞₂` 作为自己的一个组成部分。供给公式 M_γ 之后,机器 `𝒢` 的运动划分为若干段,其中第 n 段专门用来求出 γ 的第 n 位数字。这一段的第一步是造出公式 {M_γ}(N_n);然后把这个公式供给机器 `𝒞₂`,`𝒞₂` 将把它相继变换成种种别的公式。每一个与之可变换的公式迟早都会出现;每出现一个,就拿来与

λx[λx′[x(x(x′))]],即 N₂〔译注5〕

以及与

λx[λx′[x(x′)]],即 N₁

相比较。若与上列第一式相同,机器便印出数字 1,第 n 段至此完结;若与第二式相同,则印出 0,本段同样完结;若与两式都不相同,则继续进行变换。由假设,{M_γ}(N_n) 可变换为 N₁ 或 N₂ 两式之一;因此第 n 段终将完结,也就是说,γ 的第 n 位数字终将被写出。

为了证明每个可计算的序列 γ 都是 λ-可定义的,必须说明如何找出公式 M_γ,使得对一切整数 n,

{M_γ}(N_n) conv N_{φ(n)+1}。

设 `𝔄` 是计算 γ 的一台机器〔译注6〕,并为其完全格局选取某种借助于数的描述,例如可以采用 §6 中所述完全格局的描述数(D.N)。令 θ(n) 为 `𝔄` 的第 n 个完全格局的描述数。机器 `𝔄` 的表给出 θ(n+1) 与 θ(n) 之间形如

θ(n+1) = p_𝔄(θ(n))

的关系,其中 p_𝔄 是一种类型受到极大限制的函数,尽管通常并不简单:它由 `𝔄` 的表确定。p_𝔄 是 λ-可定义的(此点的证明从略),也就是说,存在良构公式 A_𝔄,使得对一切整数 n,

{A_𝔄}(N_{θ(n)}) conv N_{θ(n+1)}。

令 U 代表〔译注7〕

λx[{{x}(A_𝔄)}(N_r)],

其中 r = θ(0);于是,对一切整数 n,

{U}(N_n) conv N_{θ(n)}。

可以证明,存在公式 V,使得〔译注8〕

{V}(N_{θ(n+1)})(N_{θ(n)}) conv N₁,若从第 n 个完全格局进到第 (n+1) 个完全格局时印出的是数字 0;

conv N₂,若印出的是数字 1;

conv N₃,在其他情形。

再令 W_𝔄 代表〔译注9〕

λx[{{V}({A_𝔄}({U}(x)))}({U}(x))],

于是对每个整数 n 都有

{{V}(N_{θ(n+1)})}(N_{θ(n)}) conv {W_𝔄}(N_n);

又设 Q 是满足如下条件的公式〔译注10〕:

{{Q}(N_s)} conv N_{r(s)},

其中 r(s) 是这样一个整数列:q = r(s) 是使 {W_𝔄}(N_q) 可变换为 N₁ 或 N₂ 之一的第 s 个整数 q。于是,若取 M_γ 为〔译注11〕

λx[{ {W_𝔄}({Q}(x)) }],

则它便具有所要求的性质†。

> † 在一个关于可计算序列之 λ-可定义性的完备证明中,最好的做法是对上述方法加以修改:不再用数值方式描述完全格局,而是换成一种更便于用我们这套工具来处理的描述。选定若干个特定的整数,用来表示机器的各个符号与各个 m-格局。设在某个完全格局中,纸带上相继各符号所代表的数依次为 s₁,s₂,…,s_n,此时被注视的是第 m 个符号,且该 m-格局的编号为 t;那么这个完全格局便可用公式〔译注12〕
>
> E[N_{s₁},…,N_{s(m−1)}],[N_t,N_{s_m}],[N_{s(m+1)},…,N_{s_n}]]
>
> 来表示,其中
>
> [a,b] 代表 λu[{{u}(a)}(b)],
>
> [a,b,c] 代表 λu[{{{u}(a)}(b)}(c)],
>
> 等等。
