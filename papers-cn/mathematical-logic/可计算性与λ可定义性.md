## 引言(JSL pp. 153–154)

<!-- 开篇三段;脚注 †、2、3、4 为原刊脚注 -->

已经有若干种定义被提出来,为"能行可计算性"(effective calculability)这一直观观念给出确切的含义——例如应用于正整数函数时的情形。本文的目的在于证明:作者所引入的可计算函数[^1]与丘奇的 λ-可定义函数[^2]以及源于埃尔布朗与哥德尔、经克林尼发展的[^3]一般递归函数是同一的。文中证明:每个 λ-可定义函数都是可计算的,且每个可计算函数都是一般递归的。λ-可定义性有一种经过修改的形式,称为 λ-K-可定义性;把"每个 λ-可定义函数都可计算"这一证明表述为"每个 λ-K-可定义函数都可计算"的证明形式是自然的,而每个 λ-可定义函数都是 λ-K-可定义的则是平凡的。若把这些结果与一个已有的[^4]"每个一般递归函数都是 λ-可定义的"之证明结合起来,我们便得到可计算性与 λ-可定义性之间所要求的等价性,并且附带地得到 λ-可定义性与 λ-K-可定义性等价的一个新证明。

关于可计算函数的含义是什么,无法在很短的篇幅里给出令人满意的定义。因此我请读者参阅 *Computable* 第 230–235 页及第 254 页。"可计算性蕴含递归性"这一证明所需要的可计算函数知识,不超出其定义背后的观念;技术细节将在 §5 中重述。另一方面,在证明 λ-K-可定义函数可计算时,则假定读者熟悉 *Computable* 第 235–239 页的方法。

把"能行可计算的"函数认同于可计算函数,比起认同于 λ-可定义函数或一般递归函数来,可能更有说服力。对于持这种观点的人,这份等价性的正式证明为丘奇的演算提供了一个正当性论证,并使得生成可计算函数的"机器"可以被更方便的 λ-定义式所取代。

## §1 λ-K-可定义性的定义(JSL pp. 154–155)

本节以一种便于用机器处理的形式引入 λ-K-可定义性这一概念。除区别 λ-K-可定义性与 λ-可定义性的那一处之外,与通行的讲法还有三处不同:其一,只使用方括号 [ ] 一种括号,而非 { }、( )、[ ] 三种;其二,用 x, x₁, x₁₁,…… 作为变元,而不使用单字符符号的无穷清单;其三,对"直接可变换性"的条件 (ii) 的形式作了改动——这只改变该定义的形式,而不影响可变换性本身的定义。

在变换演算的公式中出现的符号共五个:λ、x、1、[ 与 ]。由 x 后跟重复任意多次(可以是零次)的 1 所构成的符号序列称为一个**变元**(variable)。良构公式是符号序列的一个类,它包括所有变元。又,若 M 与 N[^5] 是良构公式,则 [M][N](即由 [、序列 M、]、[、序列 N、最后是 ] 依次连接而成的序列)是良构公式。若 M 是良构公式且 V 是变元,则 λV[M] 是良构公式。任一符号序列若是良构公式,必可由以上已述诸条推出。

若下列三种情形之一成立,则称良构公式 M 可**直接变换**(immediately transformable)为 N:

> (i) M 形如 λV[X],而 N 为 λU[Y],其中 Y 系将 X 中的变元 V 处处替换为变元 U 而得,前提是 U 不在 X 中出现。
>
> (ii) M 形如 [λV[X]][Y],其中 V 是变元,而 N 系将 Y 代入 X 中处处替换 V 而得。此条受如下限制:若 W 是 V 或是 Y 中出现的变元,则 λW 不得在 X 中出现。
>
> (iii) N 依 (ii) 可直接变换为 M。

若 A 可直接变换为 B,或 A 形如 XL[Y] 而 B 形如 XM[Y](其中 L 可直接变换为 M,X 或 Y 可以皆空),则称 A 可**直接变换为**(immediately convertible into)B。若存在一列良构公式,始于 A、终于 B,其中每一个均可直接变换为前一个,则称 A **可变换为** B(记作 A conv B)。

下列公式

```text
λx[λx₁ [x₁]]                (缩写作 0),
λx[λx₁ [[x][x₁]]]           (缩写作 1),
λx[λx₁ [[x][[x][x₁]]]]      (缩写作 2),如此等等,
```

表示自然数。若 n 表示一个自然数,则后继自然数由一个可与 [S][n] 可变换的公式表示,其中 S 为

```text
λx₁₁[λx[λx₁ [[x][[[x₁₁][x]][x₁]]]]]。
```

自然数的一个取自然数值的函数 f(n) 称为 **λ-K-可定义的**,如果存在公式 F,使得当 n 是代表自然数 n 的公式时,[F][n] 可变换为代表 f(n) 的公式。

[F][n] 永远不可能同时可变换为代表两个不同自然数的公式,因为已经有人证明过[^6]:若两个良构公式都处于标准形(即不含形如 [λV[M]][N] 的部分)且彼此可变换,则该变换过程可以只用规则 (i) 完成。代表自然数的公式处于标准形,而代表两个不同自然数的公式当然不可能只靠规则 (i) 彼此变换。

[^5]: ⁵ 粗体大写字母用来代表未定的或作为变元的符号序列。在含括号与粗体字母的表达式中,总理解为:以符号序列代入这些字母时,显式画出的括号的配对关系不得因代入而改变;故在 XL[Y] 中,L 内出现的 [ 的个数必须等于 ] 的个数。
[^6]: ⁶ Alonzo Church and J. B. Rosser, Some properties of conversion, *Transactions of the American Mathematical Society*, vol. 39 (1936), pp. 472–482。此处所用结果是该书定理 1 推论 2 在第 482 页对该修正演算的推广形式。

## §4 λ-K-可定义函数的可计算性(JSL pp. 159–161)

<!-- 骨架表 ψ、ψ′ 与计算机器主表 b、b₁…b₄、cn… -->

现在要证明 λ-K-可定义函数是可计算的,已经比较简单了,也就是说[^7]:若 f(n) 是 λ-K-可定义的,则序列 φ——其中第 n 个 0 与第 (n+1) 个 0 之间恰有 f(n) 个数字 1,而第一个 0 之前有 f(0) 个 1——是可计算的。

为了简化计算机器 φ 的表,我们使用缩略记号 ψ(ℭ, M, a):表示这样一个内部格局,从它出发,机器把符号序列 M 写在末尾,标记以 a,并终止于内部格局 ℭ。于是 ψ(ℭ, λx₁[x₁], a) 的表是

```text
ψ(ℭ, λx₁ [x₁], a)     pe(ψa, a)?
ψa                    Pλ, R, Px, R, P₁, R, P[, R, Px, R, P₁, R, P]
```

我们还要再用一个骨架表:

```text
ψ′(ℭ, ℑ, β)           fun(e(ψ(ℭ, ℑ, a), a), β, a, a)
```

若 u 是 λ-K-定义 f(n) 的公式,则计算机器 φ 的表是:


若 f(n)(n > 1)是 λ-可定义的,即 F 是良构的(*Unsolvable* 第 346 页),那么上面的论证也表明 f(n) 在下述意义上是可计算的:正整数函数 g(n) 称为可计算的,如果存在一个可计算序列,其第 n 个 0 与第 (n+1) 个 0 之间恰有 g(n) 个数字 1。

## §5 可计算函数的递归性(JSL pp. 161–163)

<!-- 本节公式经扫描严重失真,已按上下文与数理结构复原,复原处均加译注 -->

现在将要证明:自然数的每个取自然数值的可计算函数 f(n) 都是一般递归的。我们实际上将找出原始递归函数 j(x) 与 φ(x),使得若 φ(x) 是第 (x+1) 个(x = 0, 1, 2, ……,按大小次序)满足 j(y) = 0 的自然数 y,则 f(x) 由下式给出:

```text
f(x) = ψ(φ(x))
```

容易看出,这样的函数是一般递归的(参看 *Unsolvable* 第 353 页);而且它也不难化成如下形式[^8]:

```text
f(x) = εy[i(x, y) = 0]
```

(其中 εy[i(x, y) = 0] 意为"使 i(x, y) = 0 的最小自然数 y",且 i(x, y) 是原始递归的),这一形式在一般递归函数理论中居于中心地位。[^9]

直接为 f(x) 建立递归方程本来会稍微简单一些,但在那种情形下就必须证明这些方程是相容的;为了避免这一点,我们把自己限制在原始递归(其相容性不大可能有人怀疑)之内,只有从 j(x) 到 φ(x) 这一步除外。

[^8]: ⁸ 这可以如下地定义 i(x, y) 来做到:

    ```text
    ε(0) = 0,
    ε(S(x)) = S(ε(x))    若 j(x) = 0,
            = ε(x)       其他情形,
    i(x, y) = Max(0, x − ε(y)),
    ```

    其中 S(x) 照例表示 x + 1。
[^9]: ⁹ 参看前引克林尼的两篇论文。

设已有计算机器 f(x) 的描述。机器把符号写在纸带上;这些符号中出现数字 0 与 1。第 n 个 0 与第 (n+1) 个 0 之间的数字 1 的个数是 f(n)。任一时刻,纸带上有一个符号要与其他符号区别开来,称为"被注视的符号"。系统在任一时刻的状态(完全格局)由纸带上的符号序列、其中哪一个被注视的指示、以及机器的内部格局(在 *Computable* 中称 m-格局)描述。我们取 S₀, S₁, …, S_{N−1} 作为各符号的名字,q₁, q₂, …, q_R 作为各内部格局的名字。其中有几个是独立于具体机器的确定符号与内部格局的名字;事实上,

```text
S₀ 永远代表"空白",
S₁ 永远代表 0,
S₂ 永远代表 1,
q₁ 永远代表初始内部格局。
```

若任一时刻纸带上载有符号序列

```text
s₁, s₂, ……, s_k, ……, s_l        (k > 0, l ≥ k)
```

其中第 k 个符号被注视,且内部格局为 q_t,则这个完全格局可以用四个数

```text
w = s_{k−1} + N·s_{k−2} + ⋯ + N^{k−2}·s₁,
s_k,t,
v = s_{k+1} + N·s_{k+2} + ⋯ + N^{l−k−1}·s_l
```

来描述,也可以用单个数

```text
u = p(w, s_k, t, v)
```

来描述,其中

```text
p(x₁, x₂, x₃, x₄) = 2^{x₁}·3^{x₂}·5^{x₃}·7^{x₄}。
```

机器的每个完全格局都由前一个完全格局决定。决定的方式载于机器的描述之中,它由若干个表达式组成,每个表达式具有下列形式之一:q_t S_i S_j L q_{t'},或 q_t S_i S_j N q_{t'},或 q_t S_i S_j R q_{t'}。第一个表达式的出现意味着:若在某个完全格局中被注视的符号是 S_i 而内部格局是 q_t,则机器这样进入下一个完全格局——把被注视符号换成 S_j,并使新的被注视符号是其左边的那个符号,新的内部格局为 q_{t'}。换言之,如果一个完全格局由数

```text
p(s_{k−1} + N·s_{k−2} + ⋯ + N^{k−2}·s₁, s_k, t, s_{k+1} + N·s_{k+2} + ⋯ + N^{l−k−1}·s_l)
    = p(s_{k−1} + N·f, s, t, s_{k+1} + N·g)
```

描述(其中 f 与 g 是上式所含尾段与首段的缩写),而表达式 q_t S_i S_j L q_{t'} 出现在机器描述中,那么描述下一个完全格局的数便是

```text
p(f, s_{k−1}, t′, s′ + N·(s_{k+1} + N·g))。
```

若有 q_t S_i S_j N q_{t'},则下一个完全格局将由

```text
p(s_{k−1} + N·f, s′, t′, s_{k+1} + N·g)
```

描述;而有 q_t S_i S_j R q_{t'} 时,则由

```text
p(s′ + N·(s_{k−1} + N·f), s_{k+1}, t′, g)
```

描述。

我们可以定义原始递归函数 d_L(s, t)(相应地 d_N(s, t) 或 d_R(s, t)):当形如 q_t S_i S_j L q_{t'}(相应地 q_t S_i S_j N q_{t'} 或 q_t S_i S_j R q_{t'})的表达式出现或不出现于机器描述之中时,取值 1 或 0。在三种情形的每一种中,z(s, t) 均取值 s′,c(s, t) 均取值 t′。q(x) 与 r(x) 分别是 x 除以 N 的商与余数;e_r(x)(r = 2, 3, 5, 7)是使 r^k 整除 x 的最大整数 k。这些函数都是原始递归的。

于是,若令

```text
Θ(x) = d_L(e₃(u(x)), e₅(u(x))) · p(q(e₂(u(x))), r(e₂(u(x))), c(e₃(u(x)), e₅(u(x))),
                                       z(e₃(u(x)), e₅(u(x))) + N·e₇(u(x)))
     + d_N(e₃(u(x)), e₅(u(x))) · p(e₂(u(x)), z(e₃(u(x)), e₅(u(x))),
                                   c(e₃(u(x)), e₅(u(x))), e₇(u(x)))
     + d_R(e₃(u(x)), e₅(u(x))) · p(z(e₃(u(x)), e₅(u(x))) + N·e₂(u(x)), r(e₇(u(x))),
                                   c(e₃(u(x)), e₅(u(x))), q(e₇(u(x))))。
```

以及

```text
u(0) = p(0, 0, 1, 0) = 5,
u(S(x)) = Θ(u(x)),
```

则 u(x) 就是描述机器第 (x+1) 个完全格局的数。

g(x, y) 定义如下:

```text
g(S(x), y) = 2        (一切 x, y > 0),
g(0, 1) = 0,
g(0, 0) = 2,
g(0, 2) = 1,
g(0, x) = 2           (x > 3)〔译注:疑为 x > 2 之误,见译文注〕,
```

而 j(x) 由下式定义:

```text
j(x) = g(e₃(u(x)), z(e₃(u(x)), e₅(u(x))))。
```

于是 j(x) = 0 意味着:机器在从第 (x+1) 个完全格局进到第 (x+2) 个完全格局时打印一个数字 0;若 j(x) = 1 则打印 1;j(x) = 2 则两者皆非。φ(x) 定义为第 (x+1) 个满足 j(y) = 0 的自然数 y,ψ 则定义如下:

```text
ψ(0) = 0,
ψ(S(x)) = 0          若 j(x) = 0,
         = ψ(x)      若 j(x) = 2,
         = S(ψ(x))   若 j(x) = 1。
```

于是 ψ(x) 就是在第 (x+1) 个完全格局时结算的、自上一个 0 以来已打印的 1 的个数。ψ(φ(x)) 是第 x 个 0 与第 (x+1) 个 0 之间出现的 1 的个数,x = 0 时其值为先于所有 0 的数字 1 的个数。而这些正是定义 f(x) 的性质。
