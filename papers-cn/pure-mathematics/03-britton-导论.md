# 导论

**Introduction**

> 作者:J. L. 布里顿(J. L. Britton)〔译注1〕
> 原载:*Collected Works of A.M. Turing: Pure Mathematics* 卷首,书页 ix–xv
> 译自 `papers/Pure Mathematics. 2-North Holland $1992$.pdf` 第 9–15 页(个人学习用途)

本卷是涵盖图灵数学著作的四卷之一。其余各卷分别讨论数理逻辑、计算机科学与数学生物学。

把图灵的工作划分为这样四个部分,在某种程度上是任意的。例如,本卷中关于矩阵的论文(1948)与关于泽塔函数的论文(1953)都同计算机科学有紧密的联系(后一篇甚至包含对硬件的技术性描述),而关于字问题的论文(1950 与 II)〔译注2〕和那篇科普文章(1954)本也可以收入数理逻辑卷。当然,图灵的杰作《论可计算数及其在判定问题上的应用》(1937)归入数理逻辑或计算机科学,同样都说得通。

安德鲁·霍奇斯所著的优秀图灵传记(HODGES 1983)可与这四卷对照阅读,相得益彰。

可以说,图灵最早问世的"发表"工作——尽管流传范围有限——是他 1935 年的研究员职位论文。有意思的是,它的主题是统计学。此后,他总是留意手头问题可能有的任何统计侧面。例如,初等统计就出现在论文(1948、III 与 V)中。

此外,他还对统计学作出了进一步的贡献。这些贡献在本卷中由 I. J. 古德教授撰写专节介绍;战争期间曾有一段时期,古德是图灵的主要统计助手。〔译注3〕这一统计部分分为两块:他 1979 年关于图灵统计工作的论文,以及专为本卷撰写的该文导言。它们为战时的密码分析工作提供了一些有趣的新线索。

关于置换群的论文(III)同样与密码分析有关;从它使用的术语可以看出,这项研究源于对 Enigma 密码机的钻研(参见传记)。从今天的眼光看,这或许是未刊论文中最有趣的一篇。

未刊论文(I)–(IV)与研究员职位论文的原件,都保存在剑桥大学国王学院档案馆。我一直未能找到(V)的原件,尽管传记的注(3.40)提示它也在国王学院——这可能是把(IV)与(V)混淆所致,两者讨论的都是素数分布。

不过,我得以见到(V)的复印件;遗憾的是,复印件上有些地方未能录全页面内容。

除研究员职位论文的字迹相当工整外,这些原件在许多地方都难以辨认。我亲手抄录了(I)–(IV),然后为排版打出了一份打字稿。

下面我们简要评述本卷所收图灵的各篇论文,以及布恩(BOONE 1958)与科恩、梅休(COHEN and MAYHEW 1968)的两篇相关论文。图灵较长论文的技术性摘要,见本卷后文。

## 左右概周期性的等价性(1935)

图灵称本文的结果为一项"小规模的发现",但能注意到连当时已功成名就的冯·诺依曼都未曾察觉的东西,无疑是一个充满希望的开端。〔译注4〕

概周期性这个课题有多个侧面,这里考虑的是抽象群上的复值函数。

这是一篇短小而易读的论文。

## 李群的有限逼近(1938 A)

设 G 是一个抽象群,同时是度量空间,且群运算(乘积与逆)连续。已知可以不失一般性地选取度量,使得

$$D(ax, ay) = D(x, y)$$

对 G 中所有 \(x, y, a\) 成立。若对每个 \(\varepsilon > 0\),都存在一个有限群 H,它是 G 的子集(一般并非子群),且 (i) G 中每个 \(x\) 与 H 的某个元素距离不超过 \(\varepsilon\);(ii) 若 \(a, b\) 属于 H,则 \(D(a \circ b, ab) < \varepsilon\),其中 \(a \circ b\) 是 H 中的乘积,而 \(ab\) 是 G 中的乘积——则称 G **可逼近**(approximable)。

S. 乌拉姆曾提出问题:哪些群是可逼近的?〔译注5〕本文中,图灵证明:若一个连通李群可逼近,则它是紧致且阿贝尔的。

这个证明很有意思;它牵涉有限群表示与紧群表示之间的交互作用。

## 群的扩张(1938 B)

回忆定义:若 N 是 G 的正规子群,且 G/N 同构于 B,则称群 G 是群 N 经由群 B 的**扩张**(extension)。设 A 是 N 的自同构群,I 是(由内自同构组成的)正规子群。〔译注6〕这时存在同态

$$\theta\colon G/N \to A/I,\qquad gN \mapsto \bar{g}I \ \ (g \in G),$$

其中 \(\bar{g}\) 是由 \(\bar{g}(n) = g^{-1}ng\)( \(n \in N\) )所定义的 N 的自同构。

现在设给定群 N、群 B 和同态 \(\chi\colon B \to A/I\)。〔译注7〕何时存在 N 经由 B 的扩张 G,使得(把同构的 G/N 与 B 等同视之之后)θ 恰为 χ?这就是本文所考虑的问题。

就当时未必阿贝尔的群的扩张理论而言,这是一项重要的贡献。

## 计算泽塔函数的一种方法(1943)、黎曼泽塔函数的一些计算(1953)

人们大概并不广泛知晓:除了在计算方面的工作,图灵对黎曼泽塔函数还做过重要的理论研究。

回忆:黎曼泽塔函数 \(s \mapsto \zeta(s)\)( \(s = \sigma + it\) )在 \(\mathbb{C}\) 上解析,仅在 \(s = 1\) 处有一个极点。当 \(\sigma > 1\) 时,

$$\sum_{n=1}^{\infty} n^{-s} = \zeta(s) \qquad \text{与} \qquad \prod_p (1 - p^{-s})^{-1} = \zeta(s),$$

其中乘积遍历所有素数 p。该函数在带形区域 \(0 < \sigma < 1\) 内有无穷多个零点;在这条带之外,它的零点只有 \(s = -2, -4, -6, \ldots\)。黎曼假设(猜想)是说:带内所有零点都落在直线 \(\sigma = \tfrac{1}{2}\) 上。

第一篇论文(写于 1939 年,但直到 1943 年才发表)的目标,是给出计算 \(\zeta(\tfrac{1}{2} + it)\) 的实用方法。(其中有一大段手笔华丽的围道积分。)

另一篇论文(1953)描述了 1950 年如何用曼彻斯特大学的计算机考察泽塔函数在 \(2\pi \cdot 63^2 \le t \le 2\pi \cdot 64^2\) 以及 \(0 < t < 1540\) 范围内的零点,希望找到(带内)位于临界线之外的零点。〔译注8〕论文第一部分给出该方法的理论基础,第二部分简要描述硬件并陈述若干实际计算策略。它让人得以窥见计算技术襁褓期的兴奋与挫折。

感谢 D. R. 希思-布朗博士对图灵泽塔函数工作的评估;该文刊于本卷后文、1953 年论文的技术性摘要与注释之后。(另见 EDWARDS 1974。)〔译注9〕

## 矩阵过程中的舍入误差(1948)

这是一篇读来愉快的数值分析论文:图灵在其中"边想边说",从零开始探讨线性方程组的求解与矩阵求逆。

关注点在于 n 很大时 \(n \times n\) 矩阵的求逆,以及在使用任何一种标准求逆方法时,误差是否会随 n 指数式累积。文中考虑了误差的统计界,但重点放在绝对界上。

我的同事弗兰克·伯戈因这样写道:"图灵的这篇论文,是对解线性方程组与矩阵求逆的各种方法进行误差分析的最早尝试之一。他的分析基本正确。这篇论文的主要意义在于它发表在现代计算时代破晓之时,并且指明了在计算机上求解此类问题时哪些方法是'安全'的。"〔译注10〕

## 具有消去律的半群中的字问题(1950)

半群是定义了结合乘积的集合。**具有消去律的半群**(semi-group with cancellation,SWC)是这样的半群 S:对 S 中所有 \(a, b, c\),\(ab = ac\) 蕴含 \(b = c\),且 \(ba = ca\) 蕴含 \(b = c\)。用 K 泛指"半群、SWC 或群"。一个 **K-呈现**(K-presentation)是一个对 \((S, D)\),其中 S 是有限符号集 \(S_1, \ldots, S_n\),D 是有限个形式方程 \(U_i = V_i\)( \(i = 1, \ldots, r\) ),\(U_i\) 与 \(V_i\) 是这些符号上的**字**(word);在半群与 SWC 的情形,字指符号的有限串,而在群的情形,字指形如 \(s_{j_1}^{\varepsilon_1} \cdots\, s_{j_k}^{\varepsilon_k}\)(其中 \(\varepsilon_j = \pm 1\),\(j = 1, \ldots, k\))的表达式。设 \(W_1\)、\(W_2\) 是字:若每当 X 是一个含有元素 \(S_1, \ldots, S_n\) 的 K,且对所有 i 在 X 中都有 \(U_i = V_i\),便也有 \(W_1 = W_2\) 在 X 中成立,则称 \(W_1 = W_2\) 是 \((S, D)\) 的一个**关系**(relation)。特别地,每个 \(U_i = V_i\) 称为**定义关系**(defining relation,或称基本关系 fundamental relation,F.R.)。

若存在一个算法,能对任意一对字 \(W_1\)、\(W_2\) 判定 \(W_1 = W_2\) 是否为 \((S, D)\) 的关系,则称 \((S, D)\) 的**字问题可解**(solvable)。

对任意 \((S, D)\),可以构造 \([S, D]\):它是一个 K,且在同构意义下唯一;它含有元素 \(S_1, \ldots, S_n\),它的每个元素都是 \(S_1, \ldots, S_n\) 上的字,而且 \(W_1 = W_2\) 是 \((S, D)\) 的关系,当且仅当在 \([S, D]\) 中有 \(W_1 = W_2\)。

1947 年,波斯特与马尔可夫独立地证明了:存在字问题不可解的半群呈现。〔译注11〕把这一结果推广到群,受到广泛关注,却屡攻不克。本文中,图灵考虑的是具有消去律的半群这一"中途驿站";它无疑影响了后来终于在 1955 年得到群上结果的诺维科夫,以及大约同期独立证明该结果的布恩。

## 可解与不可解问题(1954)

这是发表在企鹅《科学新闻》(Science News)上的一篇文章;这份刊物面向的读者群与《科学美国人》相仿,只是以平装本形式按季出版。〔译注12〕本文是一篇引人入胜而且相当成功的科普作品。

## 关于正规数的札记(未刊 I)

正规数的定义如下。设 \(\alpha\) 是实数,\(t \ge 2\) 是整数。考虑 \(\alpha\) 的 t 进制展开,设小数点后的部分为 \(. \alpha_1 \alpha_2 \alpha_3 \ldots\)。设 \(\gamma\) 是从 \(\{0, 1, \ldots, t-1\}\) 中取数组成的一个有序组,记 \(l(\gamma)\) 为 \(\gamma\) 中元素的个数。用 \(S(\alpha, t, \gamma, R)\) 表示块 \(\gamma\) 在 \(\alpha_1 \alpha_2 \ldots \alpha_R\) 中出现的次数。若对所有 \(\gamma\)、t 都有

$$R^{-1} S(\alpha, t, \gamma, R) \to t^{-r} \qquad (R \to \infty),$$

其中 \(r = l(\gamma)\),则称 \(\alpha\) 是**正规的**(normal)。

已知几乎所有数都是正规的,但要给出一个具体例子却不容易。在这篇未刊论文中,图灵讨论了正规数的构造。

## 紧群中的字问题(未刊 II)

如前所述,若 \((S, D)\) 是群呈现,相应的群 \([S, D]\) 可能具有不可解的字问题。然而,若把注意力限于使 \([S, D]\) 为紧群的呈现,字问题是否总可解?图灵借助数理逻辑中塔斯基的一条重要定理(TARSKI 1948),对这个问题给出了肯定回答。〔译注13〕

## 论置换群(未刊 III)

尽管这篇论文显然源自图灵对 Enigma 密码机的研究(见 HODGES 1983),它本质上是一项重要的纯数学工作。图灵由此考虑了置换群中一个后来被证明十分艰深的问题,陈述如下。

考虑对象 \(a_1, \ldots, a_r\) 上的置换。〔译注14〕设 R 为 T-循环 \((a_1\, a_2 \ldots a_r)\)。对任意置换 U,令 H(U) 表示全体形如

$$R^{t_1} U R^{t_2} \cdots U R^{t_k}, \qquad \sum t_i = 0$$

的置换所构成的群。

若 H(U) 既非对称群也非交错群,则称它是**例外的**(exceptional)。问题在于找出所有例外群,或者至少找出所有使 H(U) 例外的 U。

图灵除了施展他惯常的巧思,还进行了规模着实可观的计算,才把问题解决了 \(T = 1, 2, \ldots, 8\) 的情形。

显然,这个问题对当今从事置换群研究的人是一个挑战。计算机科学家也可能有兴趣检验图灵的结果,并把他的计算推进到 \(T > 8\)。

## 差 ψ(x) − x(未刊 IV)

回忆:切比雪夫 ψ 函数定义为 \(\psi(x) = \sum \log p\),其中和式遍历所有满足 \(p^m \le x\) 的素数 p 与正整数 m。当 \(x \to \infty\) 时 \(\psi(x) \sim x\);这等价于素数定理:\(x \to \infty\) 时 \(\pi(x) \sim x/\log x\),其中 \(\pi(x)\) 是不超过 x 的素数个数。本文证明了:存在某个 x(exp 99 < x < exp \(10^{428}\))使

$$(\psi(x) - x)/x^{1/2} > 1.0001 \text{。}$$

已知 \(\psi(x) - x\) 变号无穷多次。〔译注15〕

## A. M. 图灵与 S. 斯丘斯:论利特尔伍德的一个定理(未刊 V)

尽管是联名,这篇未刊论文很可能出自图灵一人之手。

设 \(\pi(x)\) 如通常表示不超过 x 的素数个数,并设

$$\operatorname{li} x = \lim_{h \to 0+} \left( \int_0^{\,1-h} + \int_{1+h}^{\,x} \right) \frac{du}{\log u} \text{。}$$

当 \(x \to \infty\) 时 \(\pi(x) \sim \operatorname{li} x\)。黎曼假设等价于:\(x \to \infty\) 时 \(\pi(x) - \operatorname{li} x = O(x^{1/2} \log x)\);但这里关注的是 \(\pi(x) - \operatorname{li} x\) 的**符号**。利特尔伍德证明了

$$\frac{\pi(x) - \operatorname{li} x}{(x^{1/2}/\log x)\, \log \log \log x}$$

当 \(x \to \infty\) 时上极限为正、下极限为负;因而 \(\pi(x) - \operatorname{li} x\) 变号无穷多次。在 \(2 < x < 10^4\) 的范围内它是负的。〔译注16〕本文的主体部分致力于证明:存在某个 x(\(2 < x < \exp\exp 661\))使 \(\pi(x) - \operatorname{li} x\) 为正。

论文的后半部分无疑由图灵独力写成,除一条内容充实的定理外,还包含若干随想式的推测段落。那里的注意力集中于:倘若借助计算机真的找到泽塔函数位于临界线之外的一个实零点,将对 \(\pi(x) - \operatorname{li} x\) 的理论产生何种后果。

这是对图灵 1950 年论文的一项细致研究,作者确认图灵的证明本质上是正确的。

## A. M. 科恩与 M. J. E. 梅休:论差 π(x) − li x(1968)

这是图灵-斯丘斯论文(V)第一部分的一个经大幅修正与扩充的版本。他们证明该文中的论证本质上是正确的,但得到的结论是:\(\pi(x) - \operatorname{li} x\) 在某个 x 处为正,\(2 < x < \exp\exp 1236\)(而非 \(\exp\exp 661\))。〔译注17〕
